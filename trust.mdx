Xquik publishes its usage, reviews, speed & security numbers on 1 live page.
Each number links to its source and shows the day Xquik read it.

- [Benchmarks](https://xquik.com/en/benchmarks) shows every number with its source.
- [Trust data](https://xquik.com/trust.json) holds the same numbers as JSON.

<section>

## What the page covers

- Package downloads on npm, PyPI, RubyGems, NuGet, Packagist & the Terraform Registry
- Apify Store users, runs, ratings & review counts
- Skill installs on skills.sh & ClawHub
- Registered Xquik accounts & GitHub stars
- Measured read speed & published benchmarks
- OpenSSF Best Practices results
- Xquik's listings on GitHub, Apify, package registries & MCP directories
- Daily uptime, API requests, accounts & read times for up to 90 days

</section>

<section>

## How Xquik keeps the numbers honest

Xquik reads each number from its source every hour.
Counts round down, so "10,000+" means at least 10,000.
Read times round up, so they never look faster than measured.
A number drops out when its source has not answered for 3 days.
API requests & read times leave out Xquik's own traffic, such as its tests.

</section>

<section>

## Use the numbers in your own tools

Agents & scripts can read `https://xquik.com/trust.json` without an API key.
Each entry has the value, display text, unit, date, source & badge URL.
Each trend lists 1 point per day with its unit & source.
