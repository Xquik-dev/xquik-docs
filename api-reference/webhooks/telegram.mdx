Get your monitor events in Telegram with no server of your own. The call
returns a link to @XquikBot. Open it and press Start. The chat is connected.

## How it works

1. Call this endpoint. It returns a `url` like `https://t.me/XquikBot?start=...`.
2. Open the link on a phone or computer with Telegram, then press **Start**.
3. @XquikBot answers "Connected." Each alert then arrives as a message. It shows
   the account and the event in bold, the post's text or the profile change, and
   a link.

- Alerts that wait together come as 1 digest.
- A busy chat gets 5 quick messages, then 1 every 30 seconds. A quiet chat gets
  each alert at once.
- Only the first message of a minute rings. The rest arrive silently.
- A post that is new and has media is 1 alert, titled "New post with media".

- A link works once, within 15 minutes. Make a new one if it expires.
- The chat appears in [List webhooks](/api-reference/webhooks/list) with the URL
  `telegram:<chat ID>`. [Deliveries](/api-reference/webhooks/deliveries),
  retries, [Resume](/api-reference/webhooks/resume) and
  [Test webhook](/api-reference/webhooks/test) work as for any webhook.
- In the chat, send `/stop` to pause alerts and `/status` to check them. A new
  link turns them on again.
- When Telegram asks Xquik to slow down, the retry waits as long as it asks.
- @XquikBot works in private chats. It answers in English, Turkish or Spanish,
  by your Telegram language.

<CodeGroup>

```bash cURL
curl -X POST "https://xquik.com/api/v1/webhooks/telegram" \
  -H "x-api-key: xq_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"eventTypes": ["tweet.new", "tweet.reply"]}' \
  | jq -r '.url'
```

```javascript Node.js
const response = await fetch("https://xquik.com/api/v1/webhooks/telegram", {
  method: "POST",
  headers: {
    "x-api-key": "xq_YOUR_KEY_HERE",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ eventTypes: ["tweet.new", "tweet.reply"] }),
});
const link = await response.json();
console.log(`Open ${link.url} before ${link.expiresAt}`);
```

```python Python
import requests

response = requests.post(
    "https://xquik.com/api/v1/webhooks/telegram",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
    json={"eventTypes": ["tweet.new", "tweet.reply"]},
)
link = response.json()
print(f"Open {link['url']} before {link['expiresAt']}")
```

## Body

<ParamField body="eventTypes" type="string[]">

The event types the chat gets, like `tweet.new` or `tweet.reply`. Omit the body
or this field to get new posts only.

</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>

Your API key.

</ParamField>

## Response

### 201 Created

```json
{
  "url": "https://t.me/XquikBot?start=Q2hhdExpbmtDb2RlRXhhbXBsZTAx",
  "expiresAt": "2025-01-15T12:15:00.000Z"
}
```

<ResponseField name="url" type="string">

Opens @XquikBot with the link's code. Open it and press Start.

</ResponseField>

<ResponseField name="expiresAt" type="string">

When the link stops working, 15 minutes after it was made.

</ResponseField>

### 400 Invalid input

```json
{
  "error": "invalid_input",
  "message": "Pick at least 1 valid event type, like tweet.new."
}
```

An event type is unknown. Use the types the monitor endpoints list.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key. Check the `x-api-key` header value.

### 503 Telegram unavailable

```json
{
  "error": "telegram_unavailable",
  "message": "Telegram alerts are off right now. Try again later."
}
```

Telegram delivery is off for now. Try again later.
