## How a tweet performs

Use `GET /x/tweets/{id}/insights` to see how fast a tweet draws engagement. It also shows how far the tweet spreads. Name the tweet by ID
or URL.

Engagements are likes, replies, reposts, and quotes. `amplification` is reposts and quotes per like, and
`conversation` is replies per like. A rate is `null` when nothing divides it, such as a tweet without views.

</section>

## Response

### 200 OK

| Field                         | Type             | Description                                            |
| ----------------------------- | ---------------- | ------------------------------------------------------ |
| `insights`                    | `object`         |                                                        |
| `insights.tweetId`            | `string`         | ID of the tweet.                                       |
| `insights.authorId`           | `string \| null` | ID of the author.                                      |
| `insights.authorUserName`     | `string \| null` | Username of the author.                                |
| `insights.createdAt`          | `string \| null` | When the tweet went up.                                |
| `insights.ageHours`           | `number \| null` | Hours since the tweet went up.                         |
| `insights.metrics`            | `object`         | Likes, replies, reposts, quotes, bookmarks, and views. |
| `insights.engagements`        | `number`         | Likes, replies, reposts, and quotes.                   |
| `insights.engagementsPerHour` | `number \| null` | Engagements per hour since the tweet went up.          |
| `insights.engagementPerView`  | `number \| null` | Engagements as a percent of views.                     |
| `insights.engagementRate`     | `number \| null` | Engagements as a percent of the author's followers.    |
| `insights.amplification`      | `number \| null` | Reposts and quotes per like.                           |
| `insights.conversation`       | `number \| null` | Replies per like.                                      |

### 400 Invalid input

`{"error":"invalid_tweet_id"}`

Send a tweet ID or a tweet URL.

### 404 Tweet not found

A tweet X doesn't have is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
