## How a tweet performs

Use `GET /x/tweets/{id}/insights` to see how fast a tweet draws engagement and how far it spreads. Name the tweet by ID
or URL.

Engagements are likes, replies, reposts, and quotes. `amplification` is reposts and quotes per like, and
`conversation` is replies per like. A rate is `null` when nothing divides it, such as a tweet without views.

## Path parameters

<ParamField path="id" type="string" required>

Tweet ID or URL-encoded tweet URL, such as `x.com/nasa/status/20`. See [path IDs](/api-reference/overview#path-ids).

</ParamField>

## Headers

<ParamField header="x-api-key" type="string">

Full account key. Sessions and OAuth also work.

</ParamField>

<ParamField header="Authorization" type="string">

`Bearer xq_your_guest_key_here` for `paid_reads`.

</ParamField>

### 400 Invalid input

```json
{ "error": "invalid_tweet_id" }
```

Send a tweet ID or a tweet URL.

### 404 Tweet not found

```json
{ "error": "tweet_not_found" }
```

A tweet X doesn't have is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
