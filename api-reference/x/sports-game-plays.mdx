## Read every drive & play of a game

Use `GET /x/sports/{league}/games/{id}/plays` for a game's full play-by-play. Find the game ID with
[List football games](/api-reference/x/sports-games).

- `quarters` lists each quarter in order. Each quarter lists its `drives`, and each drive its `plays`.
- A drive has its clock, how it started & ended, its first downs & its net yards.
- A play has its clock, down & distance, description & the score after it.
- `details` lists each step of a play, with its players, yards & any penalty.
- `post` is the post X links to the play. `videoPostId` & `videoReplyPostId` point to its video.

Each player appears once in `players`, keyed by ID. Steps name players by `playerId`, with a
`playerRole` such as `Pass` or `Tackle`. Pass a post ID to [Get tweet](/api-reference/x/get-tweet)
to read it.

A whole game fits 1 response, so there are no pages. `quarters` is empty before kickoff.

NFL games name a side as `Home` or `Away` in `offense`, `defense`, `possession` & `yardlineSide`.
College games name it by the team's `alternateId` from `teams`.

### 400 Invalid game ID

```json
{
  "error": "invalid_game_id",
  "message": "Send a numeric game ID, such as 2055084502741811200."
}
```

The game ID is not a number. A league other than `nfl` or `ncaafb` gets `invalid_league`. Both
answers are free.

### 404 Game not found

```json
{
  "error": "game_not_found",
  "message": "Game not found. Find game IDs with GET /x/sports/nfl/games."
}
```

X knows no game with this ID in the league. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
