## Who writes a Community Note?

X names each Community Notes contributor by an alias, never by their X account. Use
`GET /x/`<span className="cn"><wbr /><span className="nw">`community-notes/`</span><wbr />`contributors/`<wbr />`{alias}`</span> to read 1 contributor's record.

- `notesCount` says how many notes they wrote, by X's current rating.
- `ratingsCount` says how their ratings of other notes went.
- `deletedNotesCount` counts the notes they deleted.

Read what they wrote with [contributor notes](/api-reference/x/community-notes-contributor-notes). Read what they
deleted with [deleted notes](/api-reference/x/community-notes-contributor-deleted-notes).

</section>

## Response

### 200 OK

X leaves out a field it does not send. Only `alias` is always present.

| Field                           | Type      | Description                                                                                                                                                                                                                   |
| ------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `contributor`                   | `object`  | The contributor's record.                                                                                                                                                                                                     |
| `contributor.alias`             | `string`  | The alias X gives the contributor.                                                                                                                                                                                            |
| `contributor.isTopWriter`       | `boolean` | Whether X marks the contributor as a top writer.                                                                                                                                                                              |
| `contributor.isApiContributor`  | `boolean` | Whether the contributor writes notes through X's API.                                                                                                                                                                         |
| `contributor.deletedNotesCount` | `number`  | Notes the contributor deleted.                                                                                                                                                                                                |
| `contributor.notesCount`        | `object`  | How many notes the contributor wrote, by X's current rating. It holds `awaitingMoreRatings`, `currentlyRatedHelpful`, `currentlyRatedNotHelpful` & `updatedAt`.                                                               |
| `contributor.ratingsCount`      | `object`  | How the contributor's ratings of other notes went. It holds `awaitingMoreRatings`, `ratedAfterDecision`, `successful`, `unsuccessful` & `updatedAt`. `successful` counts the ratings that matched the rating X gave the note. |

### 400 Invalid alias

The path named no contributor. This answer is free.

### 404 Contributor not found

No contributor holds the alias. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: `<span className="cn"><wbr />`Bearer`</span> and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
