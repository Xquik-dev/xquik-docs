## Who writes a Community Note?

X names each Community Notes contributor by an alias, never by their X account. Use
`GET /x/community-notes/contributors/{alias}` to read 1 contributor's record.

- `notesCount` says how many notes they wrote, by X's current rating.
- `ratingsCount` says how their ratings of other notes went.
- `deletedNotesCount` counts the notes they deleted.

Read what they wrote with [contributor notes](/api-reference/x/community-notes-contributor-notes). Read what they
deleted with [deleted notes](/api-reference/x/community-notes-contributor-deleted-notes).

## Path parameters

<ParamField path="alias" type="string" required>

Contributor alias, such as `ardent-beach-friarbird`. The URL-encoded contributor URL also works, such as
`x.com/i/communitynotes/u/ardent-beach-friarbird`. Any letter case works.

## Response

### 200 OK

X leaves out a field it does not send. Only `alias` is always present.

<ResponseField name="contributor" type="object">

The contributor's record.

<ResponseField name="alias" type="string">
  The alias X gives the contributor.
</ResponseField>
<ResponseField name="isTopWriter" type="boolean">
  Whether X marks the contributor as a top writer.
</ResponseField>
<ResponseField name="isApiContributor" type="boolean">
  Whether the contributor writes notes through X's API.
</ResponseField>
<ResponseField name="deletedNotesCount" type="number">
  Notes the contributor deleted.
</ResponseField>
<ResponseField name="notesCount" type="object">
  How many notes the contributor wrote, by X's current rating. It holds `awaitingMoreRatings`,
  `currentlyRatedHelpful`, `currentlyRatedNotHelpful` & `updatedAt`.
</ResponseField>
<ResponseField name="ratingsCount" type="object">
  How the contributor's ratings of other notes went. It holds `awaitingMoreRatings`,
  `ratedAfterDecision`, `successful`, `unsuccessful` & `updatedAt`. `successful` counts the ratings
  that matched the rating X gave the note.
</ResponseField>

</ResponseField>

### 400 Invalid alias

```json
{
  "error": "invalid_contributor_alias",
  "message": "Send a Community Notes alias or its x.com/i/communitynotes/u URL."
}
```

The path named no contributor. This answer is free.

### 404 Contributor not found

```json
{
  "error": "contributor_not_found",
  "message": "Contributor not found. Check the alias on its x.com/i/communitynotes/u page."
}
```

No contributor holds the alias. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
