## Read who follows a football game

Use <span className="cn">`GET /x/sports/`<wbr />`{league}/`<wbr />`games/`<wbr />`{id}/`<wbr />`audience`</span> for the crowd around 1 game on X. Find the game ID
with [List football games](/api-reference/x/sports-games). Call it again to follow a live game.

- `viewers` has how many people watched the game on X & when X counted them.
- `teamPicks` has how many people picked each team to root for.
- `chat` says whether the game chat is open, or how long until it opens.
- `teams` holds each team once, keyed by ID, with its location.

`viewers` is null until X counts any viewers, as before kickoff. Each `teamId` is a key of `teams`.

</section>

## Response

### 200 OK

| Field              | Type       | Description                                                                                                                                                                     |
| ------------------ | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`               | `string`   | The game ID from your request.                                                                                                                                                  |
| `league`           | `string`   | The league from your request, `nfl` or `ncaafb`.                                                                                                                                |
| `viewers`          | `object`   | People watching the game on X at X's last count. Null before X counts any.                                                                                                      |
| `viewers.count`    | `number`   | How many people watched the game on X.                                                                                                                                          |
| `viewers.asOf`     | `string`   | When X counted them, as an ISO <span className="nw">8601 time</span>.                                                                                                           |
| `teamPicks`        | `object`   | How many people on X picked a team to root for.                                                                                                                                 |
| `teamPicks.total`  | `number`   | Picks for every team in the game.                                                                                                                                               |
| `teamPicks.teams`  | `object[]` | Picks per team. Each has `teamId`, a key of `teams`, & `count`.                                                                                                                 |
| `chat`             | `object`   | The game's live chat on X.                                                                                                                                                      |
| `chat.available`   | `boolean`  | Whether the chat is open now.                                                                                                                                                   |
| `chat.broadcastId` | `string`   | X's ID for the game's chat room, such as `nfl-2055084502741811200`.                                                                                                             |
| `chat.opensIn`     | `object`   | Time left until the chat opens, as `days`, `hours` & `minutes`. Null while it is open & after the game.                                                                         |
| `teams`            | `object`   | The game's teams, keyed by team ID. X sends no short name, alternate ID or X account here. So those are null. [Get football scoreboard](/api-reference/x/sports-game) has them. |

Each value in `teams` has these fields.

### 400 Invalid game ID

<span className="cn">`{ "error": "invalid_game_id", "message": "Send a numeric game ID, such as 2055084502741811200." }`</span>

{"\n"}

The game ID is not a number. A league other than `nfl` or `ncaafb` gets `invalid_league`. Both
answers are free.

### 404 Game not found

<span className="cn">`{ "error": "game_not_found", "message": "Game not found. Find game IDs with GET /x/sports/nfl/`<wbr />`games." }`</span>

{"\n"}

X knows no game with this ID in the league. This answer is free.

### 401 Unauthenticated

Anonymous requests get <span className="cn"><span className="nw">`WWW-Authenticate: `</span><wbr />`Bearer`</span> and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
