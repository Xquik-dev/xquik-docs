## Read who follows a football game

Use `GET /x/sports/{league}/games/{id}/audience` for the crowd around 1 game on X. Find the game ID
with [List football games](/api-reference/x/sports-games). Call it again to follow a live game.

- `viewers` has how many people watched the game on X & when X counted them.
- `teamPicks` has how many people picked each team to root for.
- `chat` says whether the game chat is open, or how long until it opens.
- `teams` holds each team once, keyed by ID, with its location.

`viewers` is null until X counts any viewers, as before kickoff. Each `teamId` is a key of `teams`.

## Path parameters

<ParamField path="league" type="string" required>

`nfl` for the NFL or `ncaafb` for college football, in any case. Another value gets a free
`400 invalid_league`.

</ParamField>

<ParamField path="id" type="string" required>

Game ID, a number up to 19 digits, such as `2055084502741811200`.
[List football games](/api-reference/x/sports-games) returns it as `id`. Another value gets a free
`400 invalid_game_id`.

</ParamField>

### 400 Invalid game ID

```json
{
  "error": "invalid_game_id",
  "message": "Send a numeric game ID, such as 2055084502741811200."
}
```

The game ID is not a number. A league other than `nfl` or `ncaafb` gets `invalid_league`. Both
answers are free.

### 404 Game not found

```json
{
  "error": "game_not_found",
  "message": "Game not found. Find game IDs with GET /x/sports/nfl/games."
}
```

X knows no game with this ID in the league. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
