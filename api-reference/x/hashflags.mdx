Use `GET /x/hashflags` to list X's hashflags.
A hashflag is the custom emoji X shows after a hashtag for a set time.
Each returned hashflag costs 1 credit. Filters and `limit` lower the cost.
An empty result costs nothing.

## Track branded hashtags

The endpoint lists the hashflags that run now.
Send `activeOnly=false` to add ended and upcoming ones.
Use `q` to keep hashtags that contain your text.

`startsAt` and `endsAt` give the time X shows each emoji.
`assetUrl` is the emoji image. `animations` lists the animations X plays, such as on a like.

X lists a few hundred hashflags. Send `limit` when you need only some.

## Query parameters

<ParamField query="q" type="string">

Text the hashtag contains, such as `football`. Case insensitive. A leading `#` is ignored. Alias: `query`.

</ParamField>

<ParamField query="activeOnly" type="boolean" default="true">

Keeps hashflags that run now. Send `false` to add ended and upcoming ones.

</ParamField>

<ParamField query="limit" type="integer">

Maximum hashflags to return, starting at `1`. Omit it for every match. Your credit balance can return fewer. Aliases: `pageSize`, `count`, and `max_results`.

</ParamField>

## Headers

<ParamField header="x-api-key" type="string">

Send a full Xquik account API key.

</ParamField>

<ParamField header="Authorization" type="string">

`Bearer xq_your_guest_key_here` for `paid_reads`.

</ParamField>

## Response

### 200 OK

<ResponseField name="hashflags" type="object[]">

Hashflags that match your filters, in X's order.
**Hashflag object fields.**

<ResponseField name="hashtag" type="string">
  Hashtag text without `#`. X also lists some plain phrases.
</ResponseField>
<ResponseField name="assetUrl" type="string">
  Image of the emoji.
</ResponseField>
<ResponseField name="startsAt" type="string">
  When X starts showing the emoji, in UTC.
</ResponseField>
<ResponseField name="endsAt" type="string">
  When X stops showing the emoji, in UTC.
</ResponseField>
<ResponseField name="isHashfettiEnabled" type="boolean">
  Whether X marks the hashflag for its hashfetti effect.
</ResponseField>
<ResponseField name="animations" type="object[]">
  Animations X plays for the hashtag. Often empty. Each has `context`, such as `Like`, `assetUrl`,
  and `priority`.
</ResponseField>

</ResponseField>
<ResponseField name="count" type="number">Hashflags returned and charged.</ResponseField>
<ResponseField name="total" type="number">Hashflags that match the filters, before `limit`.</ResponseField>
<ResponseField name="message" type="string">
  What to send instead. Present only when no hashflag matches.
</ResponseField>

## Twitter hashflags API questions

### What is a Twitter hashflag?

A hashflag is a custom emoji X shows after a hashtag for a set time.
Brands and events use them. Some people call them hashmoji.

### How do I list the hashflags that run now?

Call `GET /x/hashflags` without parameters.
The response lists every hashflag X shows at that moment.

### How do I find the emoji of 1 hashtag?

Send `q` with the hashtag text, with or without `#`.
Read `assetUrl` from the matching hashflag.

### How much does a hashflags request cost?

Each returned hashflag costs 1 credit. An empty result costs nothing.
Add `q` or `limit` to return fewer hashflags.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
