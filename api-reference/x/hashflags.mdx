Use `GET /x/hashflags` to list X's hashflags.
A hashflag is the custom emoji X shows after a hashtag. It appears for a set time.
Each returned hashflag costs 1 credit. Filters and `limit` lower the cost.
An empty result costs nothing.

<section>

## Track branded hashtags

The endpoint lists the hashflags that run now.
Send `activeOnly=false` to add ended and upcoming ones.
Use `q` to keep hashtags that contain your text.

`startsAt` and `endsAt` give the time X shows each emoji.
`assetUrl` is the emoji image. `animations` lists the animations X plays, such as on a like.

X lists a few hundred hashflags. Send `limit` when you need only some.

</section>

## Query parameters

| Query parameter | Type      | Required | Description                                                                                                                                                                                          |
| --------------- | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `q`             | `string`  | No       | Text the hashtag contains, such as `football`. Case insensitive. A leading `#` is ignored. Also read as `query`.                                                                                     |
| `activeOnly`    | `boolean` | No       | Keeps hashflags that run now. Send `false` to add ended and upcoming ones. Default `true`.                                                                                                           |
| `limit`         | `integer` | No       | Maximum hashflags to return, starting at `1`. Omit it for every match. Your credit balance can return fewer. Also read as `pageSize`, `count`, `max_results`, `maxItems`, `max_items` or `per_page`. |

## Response

### 200 OK

| Field                            | Type       | Description                                                                                                      |
| -------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `hashflags`                      | `object[]` | Hashflags that match your filters, in X's order.                                                                 |
| `hashflags[].hashtag`            | `string`   | Hashtag text without `#`. X also lists some plain phrases.                                                       |
| `hashflags[].assetUrl`           | `string`   | Image of the emoji.                                                                                              |
| `hashflags[].startsAt`           | `string`   | When X starts showing the emoji, in UTC.                                                                         |
| `hashflags[].endsAt`             | `string`   | When X stops showing the emoji, in UTC.                                                                          |
| `hashflags[].isHashfettiEnabled` | `boolean`  | Whether X marks the hashflag for its hashfetti effect.                                                           |
| `hashflags[].animations`         | `object[]` | Animations X plays for the hashtag. Often empty. Each has `context`, such as `Like`, `assetUrl`, and `priority`. |
| `count`                          | `number`   | Hashflags returned and charged.                                                                                  |
| `total`                          | `number`   | Hashflags that match the filters, before `limit`.                                                                |
| `message`                        | `string`   | What to send instead. Present only when no hashflag matches.                                                     |

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 503 Service busy

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

The Xquik tier limit blocked the request.
Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

The opt-in normalized contract returns 424 when the read service fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Twitter hashflags API questions

### What is a Twitter hashflag?

A hashflag is a custom emoji X shows after a hashtag. It appears for a set time.
Brands and events use them. Some people call them hashmoji.

### How do I list the hashflags that run now?

Call `GET /x/hashflags` without parameters.
The response lists every hashflag X shows at that moment.

### How do I find the emoji of 1 hashtag?

Send `q` with the hashtag text, with or without `#`.
Read `assetUrl` from the matching hashflag.

### How much does a hashflags request cost?

Each returned hashflag costs 1 credit. An empty result costs nothing.
Add `q` or `limit` to return fewer hashflags.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
