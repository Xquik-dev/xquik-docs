Read routes that link here accept these optional filters on `tweets[]`. Each route keeps its own target. Xquik filters rows after it fetches each page. Selective filters can return fewer rows than an unfiltered page.

<section>

## Query parameters

| Query parameter     | Type      | Required | Description                                                                                                               |
| ------------------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| `fromUser`          | `string`  | No       | Filter to posts from this username. The `@` prefix is optional.                                                           |
| `toUser`            | `string`  | No       | Filter to replies directed to this username.                                                                              |
| `mentioning`        | `string`  | No       | Filter to posts that mention this username.                                                                               |
| `language`          | `string`  | No       | Only include posts with this language code.                                                                               |
| `sinceDate`         | `string`  | No       | Include posts created on or after this date or timestamp.                                                                 |
| `untilDate`         | `string`  | No       | Include posts up to this date or timestamp. A date is a UTC day, inclusive, so its own posts count.                       |
| `mediaType`         | `string`  | No       | Use `images`, `videos`, `gifs`, `media`, `links`, or `none`.                                                              |
| `minLikes`          | `integer` | No       | Require this minimum like count.                                                                                          |
| `minRetweets`       | `integer` | No       | Require this minimum repost count.                                                                                        |
| `minReplies`        | `integer` | No       | Require this minimum reply count.                                                                                         |
| `minQuotes`         | `integer` | No       | Require this minimum quote count.                                                                                         |
| `minViews`          | `integer` | No       | Require this minimum view count.                                                                                          |
| `minBookmarks`      | `integer` | No       | Require this minimum bookmark count.                                                                                      |
| `maxFaves`          | `integer` | No       | Allow this maximum like count. Missing counts pass.                                                                       |
| `maxRetweets`       | `integer` | No       | Allow this maximum repost count. Missing counts pass.                                                                     |
| `maxReplies`        | `integer` | No       | Allow this maximum reply count. Missing counts pass.                                                                      |
| `maxQuotes`         | `integer` | No       | Allow this maximum quote count. Missing counts pass.                                                                      |
| `blueVerifiedOnly`  | `boolean` | No       | When `true`, only return posts from Blue-verified authors.                                                                |
| `verifiedOnly`      | `boolean` | No       | When `true`, only return posts from verified authors.                                                                     |
| `replies`           | `string`  | No       | Use `include`, `exclude`, or `only` for replies. This setting overrides `includeReplies` when the endpoint supports both. |
| `retweets`          | `string`  | No       | Use `include`, `exclude`, or `only` for reposts.                                                                          |
| `exactPhrase`       | `string`  | No       | Match this literal phrase, including any hyphens.                                                                         |
| `excludeWords`      | `string`  | No       | Exclude comma-separated or whitespace-separated terms.                                                                    |
| `anyWords`          | `string`  | No       | Require at least 1 comma-separated or whitespace-separated term.                                                          |
| `hashtags`          | `string`  | No       | Match these hashtags. Separate values with commas or spaces.                                                              |
| `cashtags`          | `string`  | No       | Match these cashtags. Separate values with commas or spaces.                                                              |
| `quotes`            | `string`  | No       | Use `include`, `exclude`, or `only` for quote posts.                                                                      |
| `url`               | `string`  | No       | URL substring or domain that must appear in tweet URL entities.                                                           |
| `conversationId`    | `string`  | No       | Filter to tweets in this conversation thread.                                                                             |
| `inReplyToTweetId`  | `string`  | No       | Only include replies to this tweet ID.                                                                                    |
| `quotesOfTweetId`   | `string`  | No       | Filter to quote tweets of this tweet ID.                                                                                  |
| `retweetsOfTweetId` | `string`  | No       | Filter to retweets of this tweet ID.                                                                                      |
