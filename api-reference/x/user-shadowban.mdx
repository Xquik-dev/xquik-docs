## Is an account shadowbanned on X (Twitter)?

Use <span className="cn">`GET /x/users/`<wbr />`{id}/`<wbr />`shadowban`</span> to run 4 checks on 1 account. Name the account by user ID, username, or profile URL.

- `account` reads whether the account is active, protected, or suspended.
- `search` looks for the account's recent posts in X (Twitter) search. It uses `from:username`, sorted by Latest.
- `suggestion` looks for the account among the accounts X (Twitter) suggests for its username.
- `replies` opens the threads of up to <span className="nw">3 recent</span> replies to other accounts. It finds where each reply shows.

Each check answers `pass`, `fail`, or `unknown`. It adds a `reason` and the evidence it read. The reply check answers `pass`
or `unknown`, since X ranks replies for each viewer. A protected account gets the suggestion check only. A suspended
account gets the account check only.

## Response

### 200 OK

| Field               | Type             | Description                                                                                                                                                      |
| ------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `username`          | `string \| null` | Username of the account. `null` for a suspended account named by user ID.                                                                                        |
| `userId`            | `string \| null` | ID of the account. `null` for a suspended account named by username.                                                                                             |
| `account`           | `string`         | `active`, `protected`, or `suspended`.                                                                                                                           |
| `checks`            | `object`         | The <span className="nw">4 checks</span>. Each has `verdict`, `reason`, and `evidence`.                                                                          |
| `checks.account`    | `object`         | `pass` with `active` or `protected`, or `fail` with `suspended`. `evidence.profileUrl` opens the profile on X.                                                   |
| `checks.search`     | `object`         | `pass` with `listed` or `fail` with `missing`. `evidence` holds `query`, `searchUrl`, `recentPostIds`, and `foundPostIds`.                                       |
| `checks.suggestion` | `object`         | `pass` with `suggested` or `fail` with `not_suggested`. `evidence` holds `query` and `suggestedUsernames`.                                                       |
| `checks.replies`    | `object`         | `pass` with `in_thread`, or `unknown` with `more_replies` or `not_found`. `evidence.replies` lists each reply with its `placement`, `replyUrl`, and `parentUrl`. |

### 400 Invalid input

<span className="cn">`{ "error": "invalid_user_id" }`</span>

{"\n"}

Send a user ID, a username, or a profile URL.

### 404 User not found

A user X does not know is free of charge.

### 401 Unauthenticated

Anonymous requests get <span className="cn"><span className="nw">`WWW-Authenticate: `</span><wbr />`Bearer`</span> and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
