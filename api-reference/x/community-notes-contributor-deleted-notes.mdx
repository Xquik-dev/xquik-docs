```javascript Node.js
const alias = "ardent-beach-friarbird";
const url = `https://xquik.com/api/v1/x/community-notes/contributors/${alias}/deleted-notes`;
```

<section>

## What does X keep of a deleted note?

X keeps each deleted note's ID, time, rating status, rater tags & scoring model. It shows a notice in place of the
note's text. So `text`, `classification` & `post` are left out. `tombstone` holds that notice.

A contributor who deleted no note returns an empty list, which is free.

[Get notes contributor](/api-reference/x/community-notes-contributor) returns the count in `deletedNotesCount`.

</section>

<section>

## Page through deleted notes

Each page returns `has_next_page` and `next_cursor`. Send `next_cursor` back as `cursor`. Stop when `has_next_page` is
`false`.

A cursor X never issued returns `400 invalid_cursor`, which is free. Start again without `cursor`, then use
`next_cursor`.

</section>

## Response

### 200 OK

X leaves out a field that a note lacks. Only `id` is always present.

| Field                         | Type       | Description                                                                       |
| ----------------------------- | ---------- | --------------------------------------------------------------------------------- |
| `notes`                       | `object[]` | The contributor's deleted notes, newest first.                                    |
| `notes[].id`                  | `string`   | Note ID.                                                                          |
| `notes[].createdAt`           | `string`   | When the contributor wrote the note, as ISO 8601.                                 |
| `notes[].ratingStatus`        | `string`   | X's rating of the note, such as `NeedsMoreRatings` or `CurrentlyRatedNotHelpful`. |
| `notes[].helpfulTags`         | `string[]` | Why raters called the note helpful.                                               |
| `notes[].notHelpfulTags`      | `string[]` | Why raters called the note not helpful.                                           |
| `notes[].decidedBy`           | `string`   | The X scoring model that set the rating.                                          |
| `notes[].fullyVisibleModel`   | `boolean`  | Whether X marks that scoring model as fully visible.                              |
| `notes[].abovePcrhThreshold`  | `boolean`  | Whether the note scores above X's bar for a possible helpful rating.              |
| `notes[].appealStatus`        | `string`   | Whether the rating is under appeal.                                               |
| `notes[].deleted`             | `boolean`  | `true` for a deleted note.                                                        |
| `notes[].tombstone`           | `string`   | X's notice in place of the note, such as `This note has been deleted`.            |
| `notes[].isApiAuthor`         | `boolean`  | Whether the note came through X's API.                                            |
| `notes[].isMediaNote`         | `boolean`  | Whether the note was about a post's media.                                        |
| `notes[].mediaNoteMatchCount` | `number`   | Other posts X matched a media note to.                                            |
| `notes[].isUrlNote`           | `boolean`  | Whether the note was on a link.                                                   |
| `has_next_page`               | `boolean`  | Whether more notes follow.                                                        |
| `next_cursor`                 | `string`   | Cursor for the next page. Empty at the end of the list.                           |

### 400 Invalid alias or cursor

A cursor X never issued returns `invalid_cursor`. Start again without `cursor`. Both answers are free.

### 404 Contributor not found

No contributor holds the alias. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

The normalized v1 response contract can return 424 when the read service is unavailable.
