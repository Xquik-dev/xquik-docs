```bash cURL
curl https://xquik.com/api/v1/x/users/discord/affiliates \
  -H "x-api-key: xq_your_api_key_here" | jq

# Page 2
curl -G https://xquik.com/api/v1/x/users/discord/affiliates \
  --data-urlencode "cursor=abc123" \
  -H "x-api-key: xq_your_api_key_here" | jq
```

```javascript Node.js
const user = "discord";
let pageCursor = "";
let position = 0;

for (let pageIndex = 0; pageIndex < 3; pageIndex += 1) {
  const params = pageCursor === "" ? "" : `?${new URLSearchParams({ cursor: pageCursor })}`;
  const response = await fetch(`https://xquik.com/api/v1/x/users/${user}/affiliates${params}`, {
    headers: { "x-api-key": "xq_your_api_key_here" },
  });
  const page = await response.json();
  if (!response.ok) throw new Error(JSON.stringify(page));

  for (const account of page.users) {
    position += 1;
    const affiliateRow = {
      source_user: user,
      position,
      user_id: account.id,
      username: account.username,
      name: account.name,
      followers: account.followers ?? null,
      verified: account.verified ?? false,
    };
    process.stdout.write(`${JSON.stringify(affiliateRow)}\n`);
  }

  if (!page.has_next_page || page.next_cursor === "") break;
  pageCursor = page.next_cursor;
}
```

```python Python
import json
import requests

user = "discord"
page_cursor = ""
position = 0

for page_index in range(3):
    params = {"cursor": page_cursor} if page_cursor else {}
    response = requests.get(
        f"https://xquik.com/api/v1/x/users/{user}/affiliates",
        params=params,
        headers={"x-api-key": "xq_your_api_key_here"},
    )
    page = response.json()
    if not response.ok:
        raise RuntimeError(page)

    for account in page["users"]:
        position += 1
        affiliate_row = {
            "source_user": user,
            "position": position,
            "user_id": account["id"],
            "username": account["username"],
            "name": account["name"],
            "followers": account.get("followers"),
            "verified": account.get("verified", False),
        }
        print(json.dumps(affiliate_row, separators=(",", ":")))

    if not page["has_next_page"] or not page["next_cursor"]:
        break
    page_cursor = page["next_cursor"]
```

## Affiliates in X's order

Use `GET /x/users/{id}/affiliates` for the accounts an organization lists as its affiliates. Rows arrive in X's order, & each row is a
full profile. The examples above save that order as `position`.

{"\n"}

An account without affiliates returns an empty list, not an error.

{"\n"}

Stop paging when `has_next_page` is `false`.

</section>

### 400 Invalid user ID

`{ "error": "invalid_user_id", "message": "Send a user ID, @username or profile URL, such as x.com/nasa." }`

{"\n"}

The user ID is empty or invalid.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

{"\n"}

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

The normalized v1 response contract can return 424 when the read service is unavailable.
