## Read the answer

The answer says whether the account reposted the post.

- `isRetweeted: true` names the repost in `retweetId` and its time in
  `retweetedAt`.
- `isRetweeted: false` with `complete: true` means the account never reposted
  the post.
- `isRetweeted: false` with `complete: false` means no repost among the newest
  posts. An older repost can exist.

A protected account returns 403 `x_account_protected`. Xquik charges nothing.

</section>

## Response

### 200 OK

| Field          | Type             | Description                                            |
| -------------- | ---------------- | ------------------------------------------------------ |
| `isRetweeted`  | `boolean`        | Whether the account reposted the post.                 |
| `retweetedAt`  | `string \| null` | When the account reposted it, else `null`.             |
| `retweetId`    | `string \| null` | The ID of the account's repost, else `null`.           |
| `tweetId`      | `string`         | The post checked.                                      |
| `userId`       | `string`         | The account checked.                                   |
| `checkedPosts` | `number`         | How many of the account's newest posts the check read. |
| `complete`     | `boolean`        | Whether the check read the account's whole timeline.   |
