## How the check reads

X keeps no list of the reposts one account made of one post. So the check reads
the account's newest posts, up to 3 pages, and stops at the first repost of the
post. `checkedPosts` says how many posts it read.

- `isRetweeted: true` names the repost in `retweetId` and its time in
  `retweetedAt`.
- `isRetweeted: false` with `complete: true` means the account never reposted
  the post.
- `isRetweeted: false` with `complete: false` means no repost among the newest
  posts. An older repost can exist.

A protected account returns 403 `x_account_protected`. Xquik charges nothing.

## Response

### 200 OK

<ResponseField name="isRetweeted" type="boolean">

Whether the account reposted the post.

</ResponseField>
<ResponseField name="retweetedAt" type="string | null">

When the account reposted it, else `null`.

</ResponseField>
<ResponseField name="retweetId" type="string | null">

The ID of the account's repost, else `null`.

</ResponseField>
<ResponseField name="tweetId" type="string">

The post checked.

</ResponseField>
<ResponseField name="userId" type="string">

The account checked.

</ResponseField>
<ResponseField name="checkedPosts" type="number">

How many of the account's newest posts the check read.

</ResponseField>
<ResponseField name="complete" type="boolean">

Whether the check read the account's whole timeline.

</ResponseField>

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The normalized v1 response contract can return 424 when the read service is unavailable.
