## Find NFL & college football games

Use `GET /x/sports/{league}/games` to list a league's games & find their IDs.
Send `nfl` for the NFL or `ncaafb` for college football.

- `id` is the game ID that the scoreboard, plays & box score routes take.
- `home` & `away` name each team by `teamId`, with its points so far.
- `teams` holds each team once, by team ID, with its name, colors & logos.
- `status` tells games apart, such as `Scheduled`, `InProgress` or `Closed`.

Games come earliest first. Without `from` or `to`, X picks about 5 weeks around today.
Send 1 of them & the window spans 7 days from it.

To follow 1 team, send its ID in `team`. Copy the ID from `teamIds` of any game.

## Path parameters

<ParamField path="league" type="string" required>

`nfl` for the NFL or `ncaafb` for college football, in any case. Another value gets a free
`400 invalid_league`.

</ParamField>

## Query parameters

<ParamField query="from" type="string">

Start of the window. Send an ISO 8601 date or time, such as `2026-10-01`, or Unix seconds. A time
without a zone reads as UTC. Defaults to 7 days before `to`. Also read as `sinceTime`.

</ParamField>

<ParamField query="to" type="string">

End of the window, in the forms `from` takes. Defaults to 7 days after `from`. Also read as
`untilTime`.

</ParamField>

<ParamField query="team" type="string">

Keeps 1 team's games, by team ID, such as `689566294702555136` for the San Francisco 49ers. Each
game lists its `teamIds`. Also read as `teamId` or `team_id`.

</ParamField>

### 400 Invalid input

```json
{
  "error": "invalid_league",
  "message": "Send nfl or ncaafb as the league, such as /x/sports/nfl/games."
}
```

The league is not `nfl` or `ncaafb`. This answer is free. A `from`, `to` or `team` Xquik cannot read
gets `invalid_input`, and its message says what to send.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
