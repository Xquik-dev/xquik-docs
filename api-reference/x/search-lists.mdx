```javascript Node.js
const query = "space news";
const params = new URLSearchParams({ q: query });
const response = await fetch(`https://xquik.com/api/v1/x/lists/search?${params}`, {
  headers: { "x-api-key": "xq_your_api_key_here" },
});
const data = await response.json();
const nextCursor = data.has_next_page ? data.next_cursor : null;
const listRows = data.lists.map((list, index) => ({
  search_query: query,
  result_rank: index + 1,
  list_id: list.id,
  list_name: list.name,
  member_count: list.memberCount ?? null,
  follower_count: list.subscriberCount ?? null,
  owner_username: list.owner?.username ?? null,
  list_url: list.url ?? null,
  next_cursor: nextCursor,
}));
```

```python Python

query = "space news"
response = requests.get(

data = response.json()
next_cursor = data["next_cursor"] if data["has_next_page"] else None
list_rows = [

        "member_count": item.get("memberCount"),
```

## Find Lists before you read them

Use `GET /x/lists/search` when you know a topic but not a List ID. It returns
the public Lists X finds for your keywords, in X's order. X may rank the Lists
differently per request. Each List carries the
`id` that [List members](/api-reference/x/list-members),
[List followers](/api-reference/x/list-followers) and
[List tweets](/api-reference/x/list-tweets) take.

Compare `memberCount`, `subscriberCount` and the owner profile to pick a List.
A List with many followers is often a well-kept source. Store the List `id`,
since a List name can change.

An empty `lists` with `has_next_page: false` means X has no more Lists
for your keywords. It costs nothing.

</section>

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 503 Service busy

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

The Xquik tier limit blocked the request.
Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

The opt-in normalized contract returns 424 when the read service fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Twitter List search questions

### How do I search Twitter Lists by keyword?

Call `GET /x/lists/search` with your keywords in `q`. Each result is a public
List with its ID, counts and owner.

### How much does a List search cost?

Each returned List costs 1 credit. An empty page costs nothing. Lower
`pageSize` to return fewer Lists.

### Does List search return private Lists?

No. It returns only public Lists. Private Lists stay out of every answer.

### Why do 2 searches return Lists in another order?

X may rank the Lists differently per request. Store each List `id` and dedupe
by it when you merge pages or runs.

### How do I get the members of a List I found?

Pass the List `id` to [List members](/api-reference/x/list-members). Use
[List tweets](/api-reference/x/list-tweets) for its timeline.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
