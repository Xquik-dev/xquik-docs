## How did an X news story change?

X writes a news story for each topic under Explore and News, and rewrites it as the topic moves.
Use `GET /x/news/{id}/versions` to read every version of 1 story, oldest first.

- `headline` is the story's headline in that version.
- `text` is the story's text in that version.
- `createdAt` is when X wrote the version, in UTC.

X lists every version at once, so 1 request returns the whole history. A story from 2 hours ago may
have 1 version, and a story that ran all day may have 8 or more.

### 400 Invalid story ID

```json
{
  "error": "invalid_news_id",
  "message": "Send a story ID or link, such as x.com/i/trending/2110209733533598095."
}
```

The path named no story. This answer is free.

### 404 Story not found

```json
{
  "error": "news_not_found",
  "message": "Story not found. Copy its ID from its x.com/i/trending link."
}
```

X lists no version for the ID. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
