## A profile's engagement at a glance

Use `GET /x/users/{id}/insights` to size up an account before you work with it. Name the user by user ID, username, or
profile URL.

The report reads the profile's counts and its 20 most recent posts. Set `limit` to read more. It still costs 1 credit.
A read stops at your count or the end of the timeline. It also stops after about 40 seconds. `sample.posts` says how
many posts it read. Reposts and the pinned post stay out of the averages. So the averages describe the account's own
recent posts. Engagements are likes, replies, reposts, and quotes.

A rate is `null` when nothing divides it. One case is a profile without posts of its own.

A protected account's posts are private. Its report has counts and account age, `postsPrivate: true`, and a
`message` that says so. It costs the same 1 credit.

</section>

## Response

### 200 OK

| Field                        | Type             | Description                                                                                                         |
| ---------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------- |
| `insights`                   | `object`         |                                                                                                                     |
| `insights.userId`            | `string`         | ID of the profile.                                                                                                  |
| `insights.userName`          | `string`         | Username of the profile.                                                                                            |
| `insights.followers`         | `number`         | Followers.                                                                                                          |
| `insights.following`         | `number`         | Accounts the user follows.                                                                                          |
| `insights.posts`             | `number`         | Posts the user has made.                                                                                            |
| `insights.accountAgeDays`    | `number \| null` | Whole days since the account joined X.                                                                              |
| `insights.postsPrivate`      | `boolean`        | `true` when only the account's followers see its posts. The report then has its counts only.                        |
| `insights.sample`            | `object`         | The posts the averages read. `posts` counts them. `oldestAt` and `newestAt` say when the oldest and newest went up. |
| `insights.averages`          | `object \| null` | Likes, replies, reposts, quotes, bookmarks, views, and engagements per post. `null` without posts.                  |
| `insights.engagementRate`    | `number \| null` | Average engagements per post, as a percent of followers.                                                            |
| `insights.engagementPerView` | `number \| null` | Engagements as a percent of views across the sample.                                                                |
| `insights.postsPerDay`       | `number \| null` | Sampled posts per day, from the oldest one until now.                                                               |
| `insights.topPostId`         | `string \| null` | The sampled post with the most engagements.                                                                         |
| `message`                    | `string`         | Says why the report has counts only, for a protected account.                                                       |

### 400 Invalid input

`{ "error": "invalid_user_id" }`

Send a user ID, a username, or a profile URL.

### 404 User not found

A user X doesn't know is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
