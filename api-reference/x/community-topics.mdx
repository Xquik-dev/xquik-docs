import requests

response = requests.get(
    "https://xquik.com/api/v1/x/communities/topics",
    headers={"x-api-key": "xq_your_api_key_here"},
)
for topic in response.json()["topics"]:
    subtopics = ", ".join(subtopic["name"] for subtopic in topic["subtopics"])
    print(topic["id"], topic["name"], subtopics)

</CodeGroup>

Use `GET /x/communities/topics` to list the topics X groups Communities under.
Each topic carries its subtopics. Pass a topic or subtopic to
[Popular communities](/api-reference/x/community-popular) as `topicId` or `topic`.

Each top-level topic costs 1 credit, its subtopics included. X changes the
list rarely, so store it. An empty list costs nothing.

## Response

### 200 OK

| Field                | Type       | Description                                               |
| -------------------- | ---------- | --------------------------------------------------------- |
| `topics`             | `object[]` | Every topic, in X's order.                                |
| `topics[].id`        | `string`   | Topic ID. Pass it as `topicId` to Popular communities.    |
| `topics[].name`      | `string`   | Topic name. Popular communities also takes it as `topic`. |
| `topics[].subtopics` | `object[]` | Narrower topics, each with its own `id` and `name`.       |
| `count`              | `number`   | Top-level topics returned.                                |
| `message`            | `string`   | What to do next. Present only when X lists no topic.      |

```json
{
  "topics": [
    {
      "id": "301",
      "name": "Technology",
      "subtopics": [
        { "id": "302", "name": "Artificial Intelligence" },
        { "id": "303", "name": "Software" }
      ]
    },
    { "id": "701", "name": "Gaming", "subtopics": [] }
  ],
  "count": 2
}
```

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read failed. Retry after a short delay.

### 503 Service busy

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

The opt-in normalized contract returns 424 when the read fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## X Community topics questions

### How much does the topic list cost?

1 credit per top-level topic. Its subtopics come free. Send `limit` for fewer topics.

### Do subtopics work with Popular communities?

Yes. Send a subtopic's `id` as `topicId` or its `name` as `topic`.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
