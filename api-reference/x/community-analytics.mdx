Use the X community analytics API to see how active a community is. One call returns 5 activity counts for the latest period. Each has its change in percent from 1 day earlier.

## What each call returns

- `likes` counts likes on the community's posts.
- `newMembers` counts the accounts that joined.
- `posts` counts the posts in the community.
- `replies` counts the replies to those posts.
- `uniquePosters` counts the distinct accounts that posted.

Each metric has a `count` and a `changePercent`. A negative `changePercent` means the count fell. `periodEndsAt` gives the end of the period in UTC.

## Track community growth over time

Call the endpoint once a day for each community you follow. Store `periodEndsAt` with the 5 counts. A new `periodEndsAt` means a new period, so you can chart each metric over time.

Compare communities with the same 5 metrics. `uniquePosters` against `posts` shows whether a few accounts write most posts.

<Callout icon="coins" color="#5c3327">
  Each successful call costs 1 credit. A refused ID, a missing community or a failed read costs
  nothing.
</Callout>

<CodeGroup>

```bash cURL
curl "https://xquik.com/api/v1/x/communities/1493446837214187523/analytics" \
  -H "x-api-key: $XQUIK_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://xquik.com/api/v1/x/communities/1493446837214187523/analytics",
    headers={"x-api-key": os.environ["XQUIK_API_KEY"]},
    timeout=30,
)
response.raise_for_status()
analytics = response.json()
print(analytics["periodEndsAt"], analytics["metrics"]["posts"]["count"])
```

## Response

### 200 OK

<ResponseField name="id" type="string">
  The community ID from your request.
</ResponseField>
<ResponseField name="periodEndsAt" type="string">
  ISO 8601 end of the latest period, in UTC.
</ResponseField>
<ResponseField name="metrics" type="object">
  The period's activity. Each metric holds `count` & `changePercent`.

<Expandable title="metrics">
  <ResponseField name="likes" type="object">
    Likes on the community's posts.
  </ResponseField>
  <ResponseField name="newMembers" type="object">
    Accounts that joined the community.
  </ResponseField>
  <ResponseField name="posts" type="object">
    Posts in the community.
  </ResponseField>
  <ResponseField name="replies" type="object">
    Replies to the community's posts.
  </ResponseField>
  <ResponseField name="uniquePosters" type="object">
    Distinct accounts that posted.
  </ResponseField>
</Expandable>

</ResponseField>

Each metric object has these fields.

<ResponseField name="count" type="integer">
  The total for the period. It is never negative.
</ResponseField>
<ResponseField name="changePercent" type="number">
  The change in percent from the same figure 1 day earlier, unrounded. A fall is negative.
</ResponseField>

### 400 Invalid community ID

```json
{ "error": "invalid_community_id" }
```

The ID is not a numeric Community ID. Send the number from the community's link. The call costs nothing.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
Anonymous calls get a direct MPP `WWW-Authenticate: Payment` challenge.
They also get a guest wallet creation action.
No checkout starts automatically. Confirm any payment action.

### 404 Community not found

```json
{ "error": "not_found" }
```

No community has this ID. Check the ID. The call costs nothing.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 503 Read unavailable

```json
{ "error": "x_api_unavailable" }
```

The read failed. Retry shortly. The call costs nothing.
