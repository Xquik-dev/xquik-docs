```text
GET https://xquik.com/api/v1/x/communities/{id}/analytics
```

Use the X community analytics API to see how active a community is. One call returns 5 activity counts for the latest period. Each has its change in percent from 1 day earlier.

<section>

## What each call returns

- `likes` counts likes on the community's posts.
- `newMembers` counts the accounts that joined.
- `posts` counts the posts in the community.
- `replies` counts the replies to those posts.
- `uniquePosters` counts the distinct accounts that posted.

Each metric has a `count` and a `changePercent`. A negative `changePercent` means the count fell. `periodEndsAt` gives the end of the period in UTC.

</section>

<section>

## Track community growth over time

Call the endpoint once a day for each community you follow. Store `periodEndsAt` with the 5 counts. A new `periodEndsAt` marks a new period. That lets you chart each metric over time.

{"\n"}

Compare communities with the same 5 metrics. `uniquePosters` against `posts` shows whether a few accounts write most posts.

<Callout icon="coins" color="#5c3327">
  Each successful call costs 1 credit. A refused ID, a missing community or a failed read costs
  nothing.
</Callout>

```bash cURL
curl "https://xquik.com/api/v1/x/communities/1493446837214187523/analytics" \
  -H "x-api-key: $XQUIK_API_KEY"
```

```python Python
import os

import requests

response = requests.get(
    "https://xquik.com/api/v1/x/communities/1493446837214187523/analytics",
    headers={"x-api-key": os.environ["XQUIK_API_KEY"]},
    timeout=30,
)
response.raise_for_status()
analytics = response.json()
print(analytics["periodEndsAt"], analytics["metrics"]["posts"]["count"])
```

## Response

### 200 OK

| Field                   | Type     | Description                                                            |
| ----------------------- | -------- | ---------------------------------------------------------------------- |
| `id`                    | `string` | The community ID from your request.                                    |
| `periodEndsAt`          | `string` | ISO <span className="nw">8601 end</span> of the latest period, in UTC. |
| `metrics`               | `object` | The period's activity. Each metric holds `count` & `changePercent`.    |
| `metrics.likes`         | `object` | Likes on the community's posts.                                        |
| `metrics.newMembers`    | `object` | Accounts that joined the community.                                    |
| `metrics.posts`         | `object` | Posts in the community.                                                |
| `metrics.replies`       | `object` | Replies to the community's posts.                                      |
| `metrics.uniquePosters` | `object` | Distinct accounts that posted.                                         |

Each metric object has these fields.

| Field           | Type      | Description                                                                                                          |
| --------------- | --------- | -------------------------------------------------------------------------------------------------------------------- |
| `count`         | `integer` | The total for the period. It is never negative.                                                                      |
| `changePercent` | `number`  | The change in percent from the same figure <span className="nw">1 day</span> earlier, unrounded. A fall is negative. |

### 400 Invalid community ID

`{ "error": "invalid_`<span className="cn"><wbr />`community_id" }`</span>

{"\n"}

The ID is no Community ID or link. Send the community's link or the number in it. The call costs nothing.

### 401 Unauthenticated

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
Anonymous calls get a direct MPP `WWW-Authenticate: `<span className="cn"><wbr />`Payment`</span> challenge.
They also get a guest wallet creation action.
No checkout starts automatically. Confirm any payment action.

### 404 Community not found

No community has this ID. Check the ID. The call costs nothing.

### 429 Rate limit exceeded

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 503 Read unavailable

The read failed. Retry shortly. The call costs nothing.
