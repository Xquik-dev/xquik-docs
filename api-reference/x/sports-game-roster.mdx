const gameId = "2055084502741811200";
const response = await fetch(`https://xquik.com/api/v1/x/sports/nfl/games/${gameId}/roster`, {

## Read both rosters

Use <span className="cn">`GET /x/sports/`<wbr />`{league}/`<wbr />`games/`<wbr />`{id}/`<wbr />`roster`</span> for the players of both teams. Find the game ID with
[List football games](/api-reference/x/sports-games).

- `rosters` holds each team's `teamId` & its `playerIds`, in X's order.
- `players` holds each player once, keyed by ID, with jersey, position, headshot & X account.
- A player's `xUser` also says whether the account is `protected`. It also says whether the
  account can offer subscriptions & has a highlighted label.

Rosters carry no college, birth details or large photos, so those fields are null. The
[box score](/api-reference/x/sports-game-box-score) has them for players who recorded stats.

</section>

## Response

### 200 OK

| Field                 | Type       | Description                                                |
| --------------------- | ---------- | ---------------------------------------------------------- |
| `id`                  | `string`   | The game ID from your request.                             |
| `league`              | `string`   | Always `nfl`.                                              |
| `rosters`             | `object[]` | Each team's roster, in X's order.                          |
| `rosters[].teamId`    | `string`   | The team, a key of `teams`.                                |
| `rosters[].playerIds` | `string[]` | The team's players in X's order, keys of `players`.        |
| `teams`               | `object`   | The <span className="nw">2 teams</span>, keyed by team ID. |
| `players`             | `object`   | Every rostered player, keyed by player ID.                 |

### 400 Unsupported league

<span className="cn">`{ "error": "unsupported_`<wbr />`league", "message": "Rosters & player props cover nfl only. Send nfl as the league." }`</span>

{"\n"}

Send `nfl` as the league. A game ID that is not a number gets `invalid_game_id`. Both answers are
free.

### 404 Game not found

<span className="cn">`{ "error": "game_not_found", "message": "Game not found. Find game IDs with GET /x/sports/nfl/`<wbr />`games." }`</span>

{"\n"}

X knows no NFL game with this ID. This answer is free.

### 401 Unauthenticated

Anonymous requests get <span className="cn"><span className="nw">`WWW-Authenticate: `</span><wbr />`Bearer`</span> and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
