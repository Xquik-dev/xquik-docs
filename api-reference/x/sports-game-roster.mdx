## Read both rosters

Use `GET /x/sports/{league}/games/{id}/roster` for the players of both teams. Find the game ID with
[List football games](/api-reference/x/sports-games).

- `rosters` holds each team's `teamId` & its `playerIds`, in X's order.
- `players` holds each player once, keyed by ID, with jersey, position, headshot & X account.
- A player's `xUser` also says whether the account is `protected`, can offer subscriptions & has a
  highlighted label.

Rosters carry no college, birth details or large photos, so those fields are null. The
[box score](/api-reference/x/sports-game-box-score) has them for players who recorded stats.

## Path parameters

<ParamField path="league" type="string" required>
`nfl`, in any case. X has no college rosters, so `ncaafb` gets a free `400 unsupported_league`.
Another value gets a free `400 invalid_league`.

<ParamField path="id" type="string" required>
Game ID, a number up to 19 digits, such as `2055084502741811200`.
[List football games](/api-reference/x/sports-games) returns it as `id`. Another value gets a free
`400 invalid_game_id`.

### 400 Unsupported league

```json
{
  "error": "unsupported_league",
  "message": "Rosters & player props cover nfl only. Send nfl as the league."
}
```

Send `nfl` as the league. A game ID that is not a number gets `invalid_game_id`. Both answers are
free.

### 404 Game not found

```json
{
  "error": "game_not_found",
  "message": "Game not found. Find game IDs with GET /x/sports/nfl/games."
}
```

X knows no NFL game with this ID. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
