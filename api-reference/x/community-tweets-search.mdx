const params = new URLSearchParams({ communityId: "1493446837214187523", q: "launch" });
const response = await fetch(`https://xquik.com/api/v1/x/communities/tweets?${params}`, {

## The same search on another path

<span className="cn">`GET /x/communities/`<wbr />`tweets`</span> searches the tweets in one Community, or across every
Community without `communityId`. It works exactly as [Community search](/api-reference/x/community-search)
does on <span className="cn">`GET /x/communities/`<wbr />`search`</span>. Both take the same
`communityId`, `q`, `queryType`, `cursor`, and `pageSize`. Both answer the same page of tweets.

{"\n"}

Keep this path when your integration already uses it. New integrations can use either.

{"\n"}

To get a Community's posts for a hashtag, search with `q=#tag`
and its `communityId`. An example is `q=#bitcoin`.

</section>

## Query parameters

| Query parameter | Type     | Required | Description                                                                                                                       |
| --------------- | -------- | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `communityId`   | `string` | No       | ID or link of the Community to search, such as `x.com/i/communities/1493446837214187523`. Leave it out to search every Community. |
| `q`             | `string` | Yes      | Search query for the Community's tweets.                                                                                          |
| `queryType`     | `string` | No       | Sort order. `Top` returns the most relevant tweets, `Latest` the most recent. Defaults to `Latest`.                               |
| `cursor`        | `string` | No       | Pagination cursor from a previous response. Omit for the first page.                                                              |
| `pageSize`      | `number` | No       | Upper bound for tweets per page. Accepts <span className="nw">1-100</span>. Defaults to `20`.                                     |
