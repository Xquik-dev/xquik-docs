## Read a football game's live score

Use `GET /x/sports/{league}/games/{id}` for 1 game's score, clock & situation. Find the game ID with
[List football games](/api-reference/x/sports-games). Call it again to follow a live game.

- `home` & `away` hold each team's `teamId`, `points` & `timeoutsLeft`.
- `periods` lists the points of each period, in order.
- `situation` has the down, the yards to go & the team with the ball.
- `lastPlay` is the latest play, with the fields [Get football plays](/api-reference/x/sports-game-plays) returns.
- `teams` & `players` hold each team & player once, keyed by ID.

`situation` & `lastPlay` are null before kickoff. Fields such as `teamId` & `playerId` are keys of
`teams` & `players`.

### 400 Invalid game ID

`{"error":"invalid_game_id","message":"Send a numeric game ID, such as 2055084502741811200."}`

The game ID is not a number. A league other than `nfl` or `ncaafb` gets `invalid_league`. Both
answers are free.

### 404 Game not found

`{"error":"game_not_found","message":"Game not found. Find game IDs with GET /x/sports/nfl/games."}`

X knows no game with this ID in the league. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
