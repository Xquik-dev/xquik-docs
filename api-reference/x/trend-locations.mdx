Use `GET /x/trends/locations` to list the places X offers trends for.
Each location carries the `woeid` that [Get X trends](/api-reference/x/trends) takes.
Each returned location costs 1 credit. Filters and `limit` lower the cost.
An empty result costs nothing.

## Find a WOEID before you read trends

Call this endpoint once and store the list. X changes it rarely.
Filter by `country` to get a country and its towns in 1 call.
Filter by `placeType` to get only countries or only towns.
Use `q` when you know part of a place name.

Pass the `woeid` of a location to `GET /x/trends` as `woeid`.
Worldwide has `woeid` 1, with no country and no parent.

## Query parameters

<ParamField query="country" type="string">

Country name or 2-letter code, such as `Turkey` or `TR`. Case insensitive. Returns the country and its towns.

</ParamField>

<ParamField query="placeType" type="string">

Kind of place: `country`, `town`, `worldwide`, or `unknown`. Case insensitive. X labels a few towns `unknown`.

</ParamField>

<ParamField query="q" type="string">

Text the location name contains, such as `york`. Case insensitive. Alias: `query`.

</ParamField>

<ParamField query="limit" type="integer">

Maximum locations to return, starting at `1`. Omit it for every match. Your credit balance can return fewer. Aliases: `pageSize`, `count`, `max_results`, `maxItems`, `max_items` & `per_page`.

</ParamField>

## Headers

<ParamField header="x-api-key" type="string">

Send a full Xquik account API key.

</ParamField>

<ParamField header="Authorization" type="string">

`Bearer xq_your_guest_key_here` for `paid_reads`.

</ParamField>

## Response

### 200 OK

<ResponseField name="locations" type="object[]">

Locations that match your filters, in X's order.
**Location object fields.**

<ResponseField name="woeid" type="number">
  Location ID. Pass it as `woeid` to `GET /x/trends`.
</ResponseField>
<ResponseField name="name" type="string">
  Place name.
</ResponseField>
<ResponseField name="country" type="string | null">
  Country name. Null for Worldwide.
</ResponseField>
<ResponseField name="countryCode" type="string | null">
  2-letter country code. Null for Worldwide.
</ResponseField>
<ResponseField name="placeType" type="string | null">
  X's kind of place: `Town`, `Country`, `Supername` for Worldwide, or `Unknown`.
</ResponseField>
<ResponseField name="placeTypeCode" type="number | null">
  X's numeric code for the kind of place.
</ResponseField>
<ResponseField name="parentWoeid" type="number | null">
  WOEID of the country or region above it. Null for Worldwide.
</ResponseField>
<ResponseField name="url" type="string | null">
  X's legacy Yahoo GeoPlanet reference. It may not resolve.
</ResponseField>

</ResponseField>
<ResponseField name="count" type="number">Locations returned and charged.</ResponseField>
<ResponseField name="total" type="number">Locations that match the filters, before `limit`.</ResponseField>
<ResponseField name="message" type="string">
  What to send instead. Present only when no location matches.
</ResponseField>

```json

  "locations": [],
  "count": 0,
  "total": 0,
  "message": "Unknown placeType. Use country, town, worldwide or unknown."
}
```

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 503 Service busy

```json
{ "error": "x_api_unavailable" }
```

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

The Xquik tier limit blocked the request.
Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The opt-in normalized contract returns 424 when the read service fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Twitter trend locations API questions

### How do I get a list of Twitter trend locations?

Call `GET /x/trends/locations` without filters.
The response lists every place X offers trends for, with its WOEID.

### How do I find the WOEID of a city or country?

Send `q` with part of the name, or `country` with a name or 2-letter code.
Read `woeid` from the matching location.

### How much does a trend locations request cost?

Each returned location costs 1 credit. An empty result costs nothing.
Add `limit` or a filter to return fewer locations.

### What does an unknown filter value return?

It returns an empty `locations` list and a `message` that says what to send.
The request costs nothing.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
