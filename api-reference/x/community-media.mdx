```javascript Node.js
const response = await fetch("https://xquik.com/api/v1/x/communities/1472105760389668865/media", {
```

```python Python
import requests

response = requests.get(
    "https://xquik.com/api/v1/x/communities/1472105760389668865/media",

for tweet in response.json()["tweets"]:
    urls = [item["mediaUrl"] for item in tweet.get("media", [])]
    print(tweet["id"], " ".join(urls))
```

Use `GET /x/communities/{id}/media` to export the posts on a Community's Media tab.
Each post has a photo or a video. Rows come newest first, like the tab on x.com.
Each tweet costs 1 credit. Filters run before billing, so filtered-out rows cost nothing.

## Media tab or all posts?

| Need                        | Route                        | Rows returned                   |
| --------------------------- | ---------------------------- | ------------------------------- |
| Photo & video posts only    | `/x/communities/{id}/media`  | Media posts, newest first.      |
| Every post of the Community | `/x/communities/{id}/tweets` | All posts, newest first or Top. |

Follow `next_cursor` until `has_next_page` is `false` for the whole tab.

## Path parameters

<ParamField path="id" type="string" required>

Community ID (numeric string).

</ParamField>

## Query parameters

<ParamField query="cursor" type="string">

Pagination cursor from a previous response. Omit for the first page.

</ParamField>

<ParamField query="pageSize" type="number">

Upper bound for tweets per page. Range: 1-100. Default: `20`.

</ParamField>

</ParamField>

</ParamField>

### 400 Invalid community ID

```json
{ "error": "invalid_community_id" }
```

The community ID is empty or invalid.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 404 Community not found

```json
{ "error": "not_found" }
```

Xquik could not resolve the Community. Check the Community ID.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

The request exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The read service was unavailable. Retry after a short delay.

## X Community media questions

### Which posts does the Media tab hold?

The Community's posts that carry a photo or a video, newest first.

### Can I filter the media posts?

Yes. The tweet filters of Community tweets work here too, such as `minLikes` or `mediaType`.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
