```javascript Node.js
const alias = "ardent-beach-friarbird";
const url = `https://xquik.com/api/v1/x/community-notes/contributors/${alias}/notes`;
const response = await fetch(url, {
  headers: { "x-api-key": "xq_your_api_key_here" },
});
const data = await response.json();
if (!response.ok) throw new Error(JSON.stringify(data));

const nextCursor = data.has_next_page ? data.next_cursor : null;
const noteRows = data.notes.map((note) => ({
  contributor_alias: alias,
  note_id: note.id,
  rating_status: note.ratingStatus ?? null,
  text: note.text ?? null,
  post_id: note.postId ?? null,
  post_author: note.post?.author?.username ?? null,
  next_cursor: nextCursor,
}));
```

```python Python
import requests

alias = "ardent-beach-friarbird"
response = requests.get(
```

## Which notes does it return?

It returns every note the contributor wrote, whatever its rating. Only helpful notes show under posts on x.com, so
this list also holds the notes x.com hides.

- `ratingStatus` says how X rates the note now, such as `NeedsMoreRatings` or `CurrentlyRatedHelpful`.
- `helpfulTags` & `notHelpfulTags` say why raters called it helpful or not.
- `timeToHelpfulFromNoteMs` says how long the note took to be rated helpful.
- `post` is the post the note is on, with the same fields as [Get tweet](/api-reference/x/get-tweet).

For a post X no longer shows, `post` is `null`. `postId` still names it, and `postUnavailable.reason` says why when X
gives a reason, such as `Suspended`.

## Page through a contributor's notes

Each page returns `has_next_page` and `next_cursor`. Send `next_cursor` back as `cursor`. Stop when `has_next_page` is
`false`.

A cursor X never issued returns `400 invalid_cursor`, which is free. Start again without `cursor`, then use
`next_cursor`.

Use the note `id` as the key in your store. Overlapping reads then add no duplicates.

### 400 Invalid alias or cursor

```json
{
  "error": "invalid_contributor_alias",
  "message": "Send a Community Notes alias or its x.com/i/communitynotes/u URL."
}
```

A cursor X never issued returns `invalid_cursor`. Start again without `cursor`. Both answers are free.

### 404 Contributor not found

```json
{
  "error": "contributor_not_found",
  "message": "Contributor not found. Check the alias on its x.com/i/communitynotes/u page."
}
```

No contributor holds the alias. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The normalized v1 response contract can return 424 when the read service is unavailable.
