```javascript Node.js
const alias = "ardent-beach-friarbird";
const url = `https://xquik.com/api/v1/x/community-notes/contributors/${alias}/notes`;
const response = await fetch(url, {
  headers: { "x-api-key": "xq_your_api_key_here" },
});
const data = await response.json();
if (!response.ok) throw new Error(JSON.stringify(data));

const nextCursor = data.has_next_page ? data.next_cursor : null;
const noteRows = data.notes.map((note) => ({
  contributor_alias: alias,
  note_id: note.id,
  rating_status: note.ratingStatus ?? null,
  text: note.text ?? null,
  post_id: note.postId ?? null,
  post_author: note.post?.author?.username ?? null,
  next_cursor: nextCursor,
}));
```

```python Python
import requests

alias = "ardent-beach-friarbird"
response = requests.get(
    f"https://xquik.com/api/v1/x/community-notes/contributors/{alias}/notes",
    headers={"x-api-key": "xq_your_api_key_here"},
)
data = response.json()
if not response.ok:
    raise RuntimeError(data)

next_cursor = data["next_cursor"] if data["has_next_page"] else None
note_rows = [
    {
        "contributor_alias": alias,
        "note_id": note["id"],
        "rating_status": note.get("ratingStatus"),
        "text": note.get("text"),
        "post_id": note.get("postId"),

        "next_cursor": next_cursor,
    }
    for note in data["notes"]
```

<section>

## Which notes does it return?

It returns every note the contributor wrote, whatever its rating. Only helpful notes show under posts on x.com. So
this list also holds the notes x.com hides.

- `ratingStatus` says how X rates the note now, such as `NeedsMoreRatings` or `CurrentlyRatedHelpful`.
- `helpfulTags` & `notHelpfulTags` say why raters called it helpful or not.
- `timeToHelpfulFromNoteMs` says how long the note took to be rated helpful.
- `post` is the post the note is on. It has the same fields as [Get tweet](/api-reference/x/get-tweet).

For a post X no longer shows, `post` is `null`. `postId` still names it. `postUnavailable.reason` says why when X
gives a reason, such as `Suspended`.

</section>

<section>

## Page through a contributor's notes

Each page returns `has_next_page` and `next_cursor`. Send `next_cursor` back as `cursor`. Stop when `has_next_page` is
`false`.

{"\n"}

A cursor X never issued returns `400 invalid_cursor`, which is free. Start again without `cursor`, then use
`next_cursor`.

{"\n"}

Use the note `id` as the key in your store. Overlapping reads then add no duplicates.

</section>

## Response

### 200 OK

X leaves out a field that a note lacks. Only `id` is always present.

| Field                             | Type             | Description                                                                                                                                          |
| --------------------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `notes`                           | `object[]`       | The contributor's notes, newest first.                                                                                                               |
| `notes[].id`                      | `string`         | Note ID.                                                                                                                                             |
| `notes[].createdAt`               | `string`         | When the contributor wrote the note, as ISO 8601.                                                                                                    |
| `notes[].language`                | `string`         | Language code of the note.                                                                                                                           |
| `notes[].classification`          | `string`         | What the writer says of the post, such as `MisinformedOrPotentiallyMisleading` or `NotMisleading`.                                                   |
| `notes[].text`                    | `string`         | What the note says.                                                                                                                                  |
| `notes[].entities`                | `object[]`       | Links, tags & accounts inside the text, each with `fromIndex`, `toIndex` & `ref`.                                                                    |
| `notes[].contributor`             | `object`         | The note's writer, with the counts X sends beside a note. [Get notes contributor](/api-reference/x/community-notes-contributor) returns every count. |
| `notes[].ratingStatus`            | `string`         | X's current rating, such as `NeedsMoreRatings`, `CurrentlyRatedHelpful` or `CurrentlyRatedNotHelpful`.                                               |
| `notes[].helpfulTags`             | `string[]`       | Why raters called the note helpful.                                                                                                                  |
| `notes[].notHelpfulTags`          | `string[]`       | Why raters called the note not helpful.                                                                                                              |
| `notes[].decidedBy`               | `string`         | The X scoring model that set the rating.                                                                                                             |
| `notes[].fullyVisibleModel`       | `boolean`        | Whether X marks that scoring model as fully visible.                                                                                                 |
| `notes[].abovePcrhThreshold`      | `boolean`        | Whether the note scores above X's bar for a possible helpful rating.                                                                                 |
| `notes[].appealStatus`            | `string`         | Whether the rating is under appeal.                                                                                                                  |
| `notes[].deleted`                 | `boolean`        | Whether the writer deleted the note.                                                                                                                 |
| `notes[].tombstone`               | `string`         | X's notice in place of a deleted note.                                                                                                               |
| `notes[].isApiAuthor`             | `boolean`        | Whether the note came through X's API.                                                                                                               |
| `notes[].isMediaNote`             | `boolean`        | Whether the note is about the post's media.                                                                                                          |
| `notes[].mediaNoteMatchCount`     | `number`         | Other posts X matched a media note to.                                                                                                               |
| `notes[].isUrlNote`               | `boolean`        | Whether the note is on a link.                                                                                                                       |
| `notes[].displayUrl`              | `string`         | The link a link note is on, as X shows it.                                                                                                           |
| `notes[].isTranslatable`          | `boolean`        | Whether X offers a translation of the note.                                                                                                          |
| `notes[].timeToHelpfulFromNoteMs` | `number`         | Milliseconds from the note's creation to its helpful rating.                                                                                         |
| `notes[].timeToHelpfulFromPostMs` | `number`         | Milliseconds from the post's creation to the note's helpful rating.                                                                                  |
| `notes[].impressionCount`         | `number`         | Views of the note, when X shares them.                                                                                                               |
| `notes[].postId`                  | `string`         | ID of the post the note is on.                                                                                                                       |
| `notes[].post`                    | `object \| null` | The post the note is on, or `null` when X no longer shows it.                                                                                        |
| `notes[].postUnavailable`         | `object`         | Why X shows no post, when X says. It holds `reason`.                                                                                                 |
| `has_next_page`                   | `boolean`        | Whether more notes follow.                                                                                                                           |
| `next_cursor`                     | `string`         | Cursor for the next page. Empty at the end of the list.                                                                                              |

### 400 Invalid alias or cursor

A cursor X never issued returns `invalid_cursor`. Start again without `cursor`. Both answers are free.

### 404 Contributor not found

No contributor holds the alias. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

The normalized v1 response contract can return 424 when the read service is unavailable.
