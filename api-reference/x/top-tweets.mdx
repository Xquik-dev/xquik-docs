```javascript Node.js
const params = new URLSearchParams({ metric: "views", window: "week", country: "US" });
const response = await fetch(`https://xquik.com/api/v1/x/tweets/top?${params}`, {
  headers: { "x-api-key": "xq_your_api_key_here" },

}
```

```python Python
import requests

response = requests.get(
    "https://xquik.com/api/v1/x/tweets/top",
    params={"metric": "views", "window": "week", "country": "US"},
    headers={"x-api-key": "xq_your_api_key_here"},
)
body = response.json()
if not response.ok:
    raise RuntimeError(body)

for tweet in body["tweets"]:
    print(f'@{tweet["author"]["username"]}: {tweet.get("viewCount")} views')
```

## The tweets X ranks highest

Use `GET /x/tweets/top` to list the tweets X ranks highest by one metric. Pick
the metric and how far back to look. Narrow it to one country or one language. Leave both out to cover all of X.

Pages hold up to 20 tweets. Pass `next_cursor` as `cursor` for the next page. The list ends at 100 tweets.

</section>

<section>

## Query parameters

| Query parameter | Type     | Required | Description                                                                                                                           |
| --------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `metric`        | `string` | No       | What to rank tweets by. Use `likes`, `replies`, `quotes`, `bookmarks`, `shares`, or `views`. Singular names work too, such as `like`. |
| `window`        | `string` | No       | How far back to look. Use `day`, `week`, or `month`. Also takes `24h`, `7d`, `30d`, `daily`, `weekly`, and `monthly`.                 |
| `country`       | `string` | No       | Only tweets from one country. Send a 2- or 3-letter ISO 3166 code, such as `US` or `USA`. Send `country` or `language`, not both.     |
| `language`      | `string` | No       | Only tweets in one language, as a 2-letter code, such as `en`. Send `country` or `language`, not both.                                |
| `cursor`        | `string` | No       | `next_cursor` from the previous page.                                                                                                 |
| `pageSize`      | `number` | No       | Tweets per page, from 1 to 100. Your credits can return fewer. Default `20`.                                                          |

## Response

### 200 OK

| Field           | Type       | Description                                                                                                                              |
| --------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `tweets`        | `object[]` | The tweets in X's order. Each has its author, text, media, and metrics, as [Search tweets](/api-reference/x/search-tweets) returns them. |
| `has_next_page` | `boolean`  | `true` while more tweets follow, up to 100.                                                                                              |
| `next_cursor`   | `string`   | Pass it as `cursor` for the next page. Empty on the last page.                                                                           |

### 400 Invalid input

`{"error":"invalid_input","message":"Send country or language, not both."}`

The message says which parameter to fix.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
