## Read player props

Use `GET /x/sports/{league}/games/{id}/player-props` for the prop lines X shows. Find the game ID with
[List football games](/api-reference/x/sports-games).

- `categories` holds each kind of prop, such as passing yards, in X's order.
- Each prop has a `playerId`, the `line`, `odds` & `alternateOdds` in American odds, and
  `openForBetting`.
- `players` holds each player once, keyed by ID, with name, jersey & team.

X (Twitter) lists props before & during a game. A finished game or a game X does not know returns no
categories. Some props have no line, such as the first touchdown scorer. Their `line` is null.

</section>

## Response

### 200 OK

| Field                                 | Type       | Description                                                                                                            |
| ------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| `id`                                  | `string`   | The game ID from your request.                                                                                         |
| `league`                              | `string`   | Always `nfl`.                                                                                                          |
| `sportsbookUrl`                       | `string`   | The sportsbook page X links for these props. Null without props.                                                       |
| `categories`                          | `object[]` | Each kind of prop, in X's order.                                                                                       |
| `categories[].key`                    | `string`   | X's key for the prop, such as `passing_yards`.                                                                         |
| `categories[].name`                   | `string`   | The name X shows, such as `Passing Yards`.                                                                             |
| `categories[].rank`                   | `number`   | The category's place in X's order, from 1.                                                                             |
| `categories[].props`                  | `object[]` | Each player's line, in X's order.                                                                                      |
| `categories[].props[].playerId`       | `string`   | The player, a key of `players`.                                                                                        |
| `categories[].props[].rank`           | `number`   | The line's place in its category, from 1.                                                                              |
| `categories[].props[].line`           | `number`   | The line the odds price, such as `248.5` yards. Null when the prop has no line.                                        |
| `categories[].props[].odds`           | `number`   | The American odds X shows first, such as `-115` or `240`.                                                              |
| `categories[].props[].alternateOdds`  | `number`   | The American odds X shows second. Null for a prop with 1 price.                                                        |
| `categories[].props[].openForBetting` | `boolean`  | Whether the sportsbook takes bets on the line.                                                                         |
| `players`                             | `object`   | The players these props name, keyed by player ID. X sends each player's name, jersey & team, so other fields are null. |

Each value in `players` has these fields.

### 400 Unsupported league

`{ "error": "unsupported_league", "message": "Rosters & player props cover nfl only. Send nfl as the league." }`

{"\n"}

Send `nfl` as the league. A game ID that is not a number gets `invalid_game_id`. Both answers are
free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.
