## Read player props

Use `GET /x/sports/{league}/games/{id}/player-props` for the prop lines X shows. Find the game ID with
[List football games](/api-reference/x/sports-games).

- `categories` holds each kind of prop, such as passing yards, in X's order.
- Each prop has a `playerId`, the `line`, `odds` & `alternateOdds` in American odds, and
  `openForBetting`.
- `players` holds each player once, keyed by ID, with name, jersey & team.

X lists props before & during a game. A finished game or a game X does not know returns no
categories. A prop without a line, such as the first touchdown scorer, has a null `line`.

## Path parameters

<ParamField path="league" type="string" required>
  `nfl`, in any case. X has no college props, so `ncaafb` gets a free `400 unsupported_league`.
  Another value gets a free `400 invalid_league`.
</ParamField>

<ParamField path="id" type="string" required>
  Game ID, a number up to 19 digits, such as `2055084502741929984`. [List football
  games](/api-reference/x/sports-games) returns it as `id`. Another value gets a free `400
  invalid_game_id`.
</ParamField>

### 400 Unsupported league

```json
{
  "error": "unsupported_league",
  "message": "Rosters & player props cover nfl only. Send nfl as the league."
}
```

Send `nfl` as the league. A game ID that is not a number gets `invalid_game_id`. Both answers are
free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
