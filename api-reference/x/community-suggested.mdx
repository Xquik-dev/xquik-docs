Use `GET /x/communities/suggested` to list the Communities X suggests to join.
Each suggestion carries the full Community record: rules, topic, creator, admin, and previewed members.
Each Community costs 1 credit. An empty list costs nothing.

## How X picks suggestions

X picks the suggestions for each request, so 2 calls can return different Communities.
For a list that depends only on your input, use
[Find communities](/api-reference/x/community-find) or
[Popular communities](/api-reference/x/community-popular).

## Query parameters

<ParamField query="limit" type="integer">

Most Communities to return, starting at `1`. Omit it for every suggestion. Your credit balance can return fewer. Aliases: `pageSize`, `count`, and `max_results`.

</ParamField>

## Headers

<ParamField header="x-api-key" type="string">

Send a full Xquik account API key.

</ParamField>

<ParamField header="Authorization" type="string">

`Bearer xq_your_guest_key_here` for `paid_reads`.

</ParamField>

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read failed. Retry after a short delay.

### 503 Service busy

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

The opt-in normalized contract returns 424 when the read fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Suggested X Communities questions

### Why do 2 calls return different Communities?

X picks the suggestions for each request.

### Does the response include my membership?

No. It holds only public Community fields.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
