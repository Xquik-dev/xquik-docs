## Query parameters

| Query parameter     | Type      | Required | Description                                                                                                                                                                          |
| ------------------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `minFollowers`      | `integer` | No       | Require this minimum follower count. Filtering happens before billing.                                                                                                               |
| `maxFollowers`      | `integer` | No       | Allow this maximum follower count. Missing counts pass this filter.                                                                                                                  |
| `minFollowing`      | `integer` | No       | Require this minimum following count.                                                                                                                                                |
| `maxFollowing`      | `integer` | No       | Allow this maximum following count. Missing counts pass this filter.                                                                                                                 |
| `minStatuses`       | `integer` | No       | Require this minimum post count.                                                                                                                                                     |
| `maxStatuses`       | `integer` | No       | Allow this maximum post count. Missing counts pass this filter.                                                                                                                      |
| `minAccountAgeDays` | `integer` | No       | Require this minimum account age in days.                                                                                                                                            |
| `verifiedOnly`      | `boolean` | No       | When `true`, only return verified profiles.                                                                                                                                          |
| `blueVerifiedOnly`  | `boolean` | No       | When `true`, only return profiles X marks as blue verified. X marks many business and government accounts blue too. Use `verifiedType` for <span className="nw">1 badge</span> type. |
| `verifiedType`      | `string`  | No       | Match the exact verification type.                                                                                                                                                   |
| `hasWebsite`        | `boolean` | No       | When `true`, require a profile website.                                                                                                                                              |
| `hasLocation`       | `boolean` | No       | When `true`, require a profile location.                                                                                                                                             |
| `hasEmail`          | `boolean` | No       | When `true`, only return profiles that publish an email.                                                                                                                             |
| `businessEmailOnly` | `boolean` | No       | When `true`, require an email outside free webmail, such as Gmail.                                                                                                                   |
| `emailDomains`      | `string`  | No       | Require an email at one of these domains, such as `acme.com,stanford.edu`. Separate domains with commas. Subdomains match.                                                           |
| `bioContains`       | `string`  | No       | Match any <span className="nw">comma-separated</span> or <span className="nw">line-separated</span> bio term, ignoring case.                                                         |
| `locationContains`  | `string`  | No       | Require this text in the profile location.                                                                                                                                           |
| `usernameContains`  | `string`  | No       | Require this text in the username.                                                                                                                                                   |

</section>
