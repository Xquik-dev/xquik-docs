Use `GET /x/communities/find` to find the X Communities that match a keyword.
Each Community costs 1 credit. A page without Communities costs nothing.
To search the posts inside 1 Community, use [Community tweet search](/api-reference/x/community-search).

<section>

## Find a Community, then read it

1. Send a keyword as `q`, such as `artificial intelligence`.
2. Pick a Community from the list by its `name` and `member_count`.
3. Pass its `id` to [Community details](/api-reference/x/community-info) for its rules, creator, and admin.
4. Pass the same `id` to [Community tweets](/api-reference/x/community-tweets) or [Community media](/api-reference/x/community-media).

Results keep X's order. X may order them differently for each request.
Follow `next_cursor` for more Communities.

</section>

## Query parameters

| Query parameter | Type      | Required | Description                                                                                                                                                             |
| --------------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `q`             | `string`  | Yes      | Keyword to find Communities by, such as `ai`. Also read as `query`.                                                                                                     |
| `cursor`        | `string`  | No       | Pagination cursor from a previous response. Omit it for the first page. A cursor X refuses or that expired returns a free `400 invalid_cursor`. Start again without it. |
| `pageSize`      | `integer` | No       | Most Communities to return on this page. Your credit balance can return fewer. Also read as `limit`, `count`, or `max_results`.                                         |

## Response

### 200 OK

| Field                           | Type       | Description                                                                                                                                  |
| ------------------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `communities`                   | `object[]` | Communities that match the keyword, in X's order.                                                                                            |
| `communities[].id`              | `string`   | Community ID. Pass it to the other Community endpoints.                                                                                      |
| `communities[].name`            | `string`   | Community name.                                                                                                                              |
| `communities[].member_count`    | `number`   | Total member count.                                                                                                                          |
| `communities[].is_nsfw`         | `boolean`  | Whether X marks the Community sensitive.                                                                                                     |
| `communities[].primary_topic`   | `object`   | The topic X files the Community under, with its `name`.                                                                                      |
| `communities[].banner_url`      | `string`   | Banner image URL. Omitted if unavailable.                                                                                                    |
| `communities[].banner`          | `object`   | Banner `url`, `width`, `height`, main `colors`, and the `focus` area X keeps in view. Omitted if unavailable.                                |
| `communities[].membersFacepile` | `object[]` | Members X previews beside the member count. Each has its `id`, `profilePicture` and `profilePictureOriginal`, the same picture at full size. |
| `has_next_page`                 | `boolean`  | Whether another page of Communities follows.                                                                                                 |
| `next_cursor`                   | `string`   | Cursor for the next page. Empty at the end.                                                                                                  |

### 400 Missing keyword or invalid cursor

`{"error":"missing_query","message":"Search query required. Use q."}`

Send a keyword as `q`. A cursor X can't read returns `invalid_cursor`.

`{"error":"invalid_cursor","message":"Cursor invalid or expired. Start again without cursor, then use next_cursor."}`

Start again without `cursor`. Both answers are free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read failed. Retry after a short delay.

### 503 Service busy

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

The opt-in normalized contract returns 424 when the read fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Find X Communities questions

### How do I find Twitter Communities about a topic?

Send the topic as `q`, such as `q=web3`. Or list the most popular Communities of a topic with [Popular communities](/api-reference/x/community-popular).

### How is this different from Community tweet search?

This endpoint returns Communities. [Community tweet search](/api-reference/x/community-search) returns posts inside 1 Community you already know.

### How much does it cost?

Each returned Community costs 1 credit. A page without Communities costs nothing.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
