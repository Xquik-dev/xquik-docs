      view_count: tweet.viewCount ?? null,

## Order and empty results

Use `GET /x/tweets/{id}/hidden-replies` for the replies a post's author hid.
X lists them under "Hidden replies" on the post. Rows arrive oldest first. The
examples above save that order as `hidden_position`.

The list also holds the replies to a hidden reply. Use `inReplyToId` to tell
them apart from replies to the post.

A post without hidden replies returns an empty list, not an error:

```json
{ "tweets": [], "has_next_page": false, "next_cursor": "" }
```

The last page looks the same. Stop paging when `has_next_page` is `false`.

A post X does not have returns 404 `tweet_not_found`. Xquik charges nothing.

## Which reply endpoint?

- Use `GET /api/v1/x/tweets/{id}/hidden-replies` for replies the author hid.
- Use `GET /api/v1/x/tweets/{id}/replies` for the replies X shows under a post.
- Use `GET /api/v1/x/tweets/{id}/thread` for the conversation around a post.

| Reply view     | Route                           | Rows returned                         |
| -------------- | ------------------------------- | ------------------------------------- |
| Hidden replies | `/x/tweets/{id}/hidden-replies` | Replies the author hid, oldest first. |
| Shown replies  | `/x/tweets/{id}/replies`        | Replies X shows under the post.       |
| Thread context | `/x/tweets/{id}/thread`         | The conversation around the post.     |

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

You exceeded your tier rate limit. Wait for the `Retry-After` header before retrying.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The normalized v1 response contract can return 424 when the read service is unavailable.
