## Lists an account created

Use `GET /x/users/{id}/lists` for the public Lists an account made, as the
Lists tab of its profile shows them. Private Lists stay out of every answer.
Each List carries the `id` that [List members](/api-reference/x/list-members),
[List followers](/api-reference/x/list-followers) and
[List tweets](/api-reference/x/list-tweets) take.

An account without public Lists returns an empty `lists` array. It costs
nothing.

A protected account returns 403 `x_account_protected`. Xquik charges nothing.

<ParamField path="id" type="string" required>

User ID, username with or without `@`, or URL-encoded profile URL, such as
`x.com/verge`. See [path IDs](/api-reference/overview#path-ids).

</ParamField>

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json

```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 403 Protected account

```json
{ "error": "x_account_protected", "message": "Account is protected. Choose a public account." }
```

### 404 User not found

```json
{
  "error": "user_not_found",
  "message": "X user not found. Check the username.",
  "reason": "not_found"
}
```

`reason` is `not_found`, or `suspended` when X suspended the account.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 503 Service busy

```json
{ "error": "x_api_unavailable" }
```

Xquik is busy. Wait for `Retry-After`, then retry.

### 429 Rate limit exceeded

```json
{ "error": "rate_limit_exceeded", "retryAfter": 60 }
```

The Xquik tier limit blocked the request.
Use `Retry-After` when present. Otherwise, use the JSON `retryAfter` field.

### 424 Dependency failed

```json
{ "error": "x_api_unavailable" }
```

The opt-in normalized contract returns 424 when the read service fails.
Send `xquik-api-contract: 2026-04-29` to opt in. Default v1 returns 502.

## Twitter user Lists questions

### How do I get the Lists a Twitter account created?

Call `GET /x/users/{id}/lists` with a user ID, username or profile URL. Each
result is a public List with its ID, counts and owner.

### How much does it cost?

Each returned List costs 1 credit. An empty page costs nothing. Lower
`pageSize` to return fewer Lists.

### Does it return private Lists?

No. It returns only public Lists. Private Lists stay out of every answer.

### How do I get the members of a List I found?

Pass the List `id` to [List members](/api-reference/x/list-members). Use
[List tweets](/api-reference/x/list-tweets) for its timeline.

### Does this replace X's official API?

No. This page documents Xquik, an independent third-party service.
It does not document X's official API.
