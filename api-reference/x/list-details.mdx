## One public List

Use `GET /x/lists/{id}` for one public X List as its page on X shows it: its name, description, member and follower
counts, owner, banner, and creation time. Name the List by its ID or its URL-encoded URL, such as
`x.com/i/lists/4143408`.

A private List returns 404 `list_not_found`, as X shows it to nobody but its members.

To read the List's people or posts, use [List members](/api-reference/x/list-members),
[List followers](/api-reference/x/list-followers), or [List tweets](/api-reference/x/list-tweets).

## Path parameters

<ParamField path="id" type="string" required>

List ID, such as `4143408`, or the URL-encoded List URL.

</ParamField>

## Headers

<ParamField header="x-api-key" type="string">

Full account key. Sessions and OAuth also work.

</ParamField>

<ParamField header="Authorization" type="string">

`Bearer xq_your_guest_key_here` for `paid_reads`.

</ParamField>

## Response

### 200 OK

<ResponseField name="list" type="object">

The List.

<ResponseField name="id" type="string">
  List ID.
</ResponseField>
<ResponseField name="name" type="string">
  List name.
</ResponseField>
<ResponseField name="description" type="string">
  List description. Omitted if empty.
</ResponseField>
<ResponseField name="memberCount" type="number">
  Number of accounts on the List.
</ResponseField>
<ResponseField name="subscriberCount" type="number">
  Number of accounts that follow the List.
</ResponseField>
<ResponseField name="owner" type="object">
  The owner's public profile, with `id`, `username`, and `name`.
</ResponseField>
<ResponseField name="url" type="string">
  The List's page on X.
</ResponseField>
<ResponseField name="createdAt" type="string">
  ISO 8601 creation time.
</ResponseField>

</ResponseField>

### 404 List not found

```json
{ "error": "list_not_found" }
```

The List is private, deleted, or never existed.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing or invalid API key.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.
