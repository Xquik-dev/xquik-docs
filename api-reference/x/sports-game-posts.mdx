## Read what X shows about a game

Use `GET /x/sports/{league}/games/{id}/posts` for the posts on a game's page on X. Find the game ID
with [List football games](/api-reference/x/sports-games).

- `queryType=Top` returns the posts X ranks highest. `queryType=Latest` returns the newest first.
- Each post has the same fields as [Search tweets](/api-reference/x/search-tweets) returns.
- `query` is the X search that finds the posts. X builds it from the teams, hashtags, team
  accounts & star players, with the game's time window.

Pass `query` to [Search tweets](/api-reference/x/search-tweets) to add filters such as language,
media or minimum likes. A game has posts before kickoff, during the game & after it.

## Path parameters

<ParamField path="league" type="string" required>

`nfl` for the NFL or `ncaafb` for college football, in any case. Another value gets a free
`400 invalid_league`.

</ParamField>

<ParamField path="id" type="string" required>

Game ID, a number up to 19 digits, such as `2055084502741811200`.
[List football games](/api-reference/x/sports-games) returns it as `id`. Another value gets a free
`400 invalid_game_id`.

</ParamField>

## Query parameters

<ParamField query="queryType" type="string" default="Top">
  `Top` for the posts X ranks highest or `Latest` for the newest, in any case. `Relevance` &
  `Recency` work too, & so do the names `order` & `sort`. Send the same value with each cursor.
</ParamField>
<ParamField query="cursor" type="string">
  `next_cursor` from the previous page.
</ParamField>
<ParamField query="pageSize" type="number" default="20">
  Posts per page, from 1 to 100. X sends at most 20 per page, & your credits can return fewer.
</ParamField>

## Response

### 200 OK

<ResponseField name="tweets" type="object[]">

The posts in X's order, each with its author, text, media & metrics, as
[Search tweets](/api-reference/x/search-tweets) returns them.

</ResponseField>
<ResponseField name="has_next_page" type="boolean">

`true` while more posts follow.

</ResponseField>
<ResponseField name="next_cursor" type="string">

Pass it as `cursor` for the next page. Empty on the last page.

</ResponseField>
<ResponseField name="query" type="string | null">

The X search that finds this game's posts for the order you asked. `null` when X sends a timeline
Xquik cannot read.

</ResponseField>

### 400 Invalid input

```json
{ "error": "invalid_params", "message": "Unknown queryType. Use Latest or Top." }
```

`queryType` is not `Top`, `Latest`, `Relevance` or `Recency`. A league other than `nfl` or `ncaafb`
gets `invalid_league`, & a game ID that is not a number gets `invalid_game_id`. These answers are
free.

### 404 Game not found

```json
{
  "error": "game_not_found",
  "message": "Game not found. Find game IDs with GET /x/sports/nfl/games."
}
```

X knows no game with this ID. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: Bearer` and a guest wallet checkout action. This is not a Payment challenge.

```json
{ "error": "unauthenticated" }
```

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```

The read service returned an error. Retry after a short delay.

### 503 Service busy

```json
{ "error": "x_api_unavailable", "message": "Xquik is busy right now. Retry shortly." }
```

Xquik is busy, or X sent an answer Xquik cannot read. Wait for the `Retry-After` header, then send
the request again. The request costs nothing.
