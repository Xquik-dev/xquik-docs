## Read what X shows about a game

Use `GET /x/sports/`<span className="cn"><wbr />`{league}/`<wbr />`games/`<wbr />`{id}/`<wbr />`posts`</span> for the posts on a game's page on X. Find the game ID
with [List football games](/api-reference/x/sports-games).

- `queryType=Top` returns the posts X ranks highest. `queryType=Latest` returns the newest first.
- Each post has the same fields as [Search tweets](/api-reference/x/search-tweets) returns.
- `query` is the X (Twitter) search that finds the posts. X builds it from the teams, hashtags, team
  accounts & star players. X adds the game's time window.

Pass `query` to [Search tweets](/api-reference/x/search-tweets) to add filters like language,
media or minimum likes. A game has posts before kickoff, during the game & after it.

</section>

## Path parameters

| Path parameter | Type     | Required | Description                                                                                                                                                                                                             |
| -------------- | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `league`       | `string` | Yes      | `nfl` for the NFL or `ncaafb` for college football, in any case. Another value gets a free `400 invalid_league`.                                                                                                        |
| `id`           | `string` | Yes      | Game ID, a number up to <span className="nw">19 digits</span>, such as `2055084502741811200`. [List football games](/api-reference/x/sports-games) returns it as `id`. Another value gets a free `400 invalid_game_id`. |

</section>

<section>

## Query parameters

| Query parameter | Type     | Required | Description                                                                                                                                                                                 |
| --------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `queryType`     | `string` | No       | `Top` for the posts X ranks highest or `Latest` for the newest. Any case works. `Relevance` & `Recency` work too, & so do the names `order` & `sort`. Send the same value with each cursor. |
| `cursor`        | `string` | No       | `next_cursor` from the previous page.                                                                                                                                                       |
| `pageSize`      | `number` | No       | Posts per page, from <span className="nw">1 to</span> 100. X sends at most <span className="nw">20 per</span> page, & your credits can return fewer. Default `20`.                          |

## Response

### 200 OK

| Field           | Type             | Description                                                                                                                          |
| --------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `tweets`        | `object[]`       | The posts in X's order, as [Search tweets](/api-reference/x/search-tweets) returns them. Each has its author, text, media & metrics. |
| `has_next_page` | `boolean`        | `true` while more posts follow.                                                                                                      |
| `next_cursor`   | `string`         | Pass it as `cursor` for the next page. Empty on the last page.                                                                       |
| `query`         | `string \| null` | The X (Twitter) search that finds this game's posts for your order. It's `null` when X sends a timeline Xquik cannot read.           |

### 400 Invalid input

`{ `<span className="cn"><wbr />`"error": "invalid_params", "message": "Unknown queryType. Use Latest or Top." }`</span>

{"\n"}

`queryType` is not `Top`, `Latest`, `Relevance` or `Recency`. A league other than `nfl` or `ncaafb`
gets `invalid_league`. A game ID that is not a number gets `invalid_game_id`. These answers are
free.

### 404 Game not found

`{ "error": "game_not_found", "message": "Game not found. Find game IDs with GET /x/sports/nfl/`<span className="cn"><wbr />`games." }`</span>

{"\n"}

X knows no game with this ID. This answer is free.

### 401 Unauthenticated

Anonymous requests get `WWW-Authenticate: `<span className="cn"><wbr />`Bearer`</span> and a guest wallet checkout action. This is not a Payment challenge.

### 402 Payment required

Account keys get account options. Guest keys get guest top-up only.
No checkout starts automatically. Confirm any payment action.

### 502 X API unavailable

The read service returned an error. Retry after a short delay.

### 503 Service busy

Xquik is busy, or X sent an answer Xquik cannot read. Wait for the `Retry-After` header, then send
the request again. The request costs nothing.
