<LlmsDirective />

Stop a runaway agent's keys in 1 request, then resume them later. Xquik pauses or resumes each
listed key that belongs to your account. It skips revoked, expired & unknown keys. It also skips
other accounts' keys, so a retry is safe.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<CodeGroup>

```bash cURL
curl -X PATCH https://dashboard.xquik.com/api/v1/api-keys \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{"ids": ["42", "43"], "paused": true}' | jq
```

import requests

response = requests.patch(

print(response.json()["keys"])

```go Go
package main

import (
	"bytes"
	"fmt"
	"io"
	"log"
	"net/http"
)

func main() {
	body := bytes.NewBufferString(`{"ids": ["42", "43"], "paused": true}`)
	req, err := http.NewRequest("PATCH", "https://dashboard.xquik.com/api/v1/api-keys", body)
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Origin", "https://dashboard.xquik.com")
	req.Header.Set("Sec-Fetch-Site", "same-origin")
	req.AddCookie(&http.Cookie{Name: "__Host-xquik_session", Value: "YOUR_SESSION_COOKIE"})

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	answer, err := io.ReadAll(resp.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(answer))
}
```

## Headers

<ParamField header="Cookie" type="string" required>
  Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get
  `403 session_required`.
</ParamField>

<ParamField header="Origin" type="string" required>
  Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The
  dashboard sends both.
</ParamField>

<ParamField header="Content-Type" type="string" required>

Must be `application/json`.

</ParamField>

## Body

<ParamField body="ids" type="string[]" required>

IDs of the keys to pause or resume, from 1 to 100. Get them from
[List API keys](/api-reference/api-keys/list).

</ParamField>

<ParamField body="paused" type="boolean" required>

`true` pauses each key, so its calls get `403 api_key_paused`. `false` resumes it. Its next call
goes through. Pausing a paused key keeps its first `pausedAt`.

</ParamField>

## Response

### 200 OK

<ResponseField name="keys" type="array">

Your listed keys in their new state, newest first. Each has the fields of
[List API keys](/api-reference/api-keys/list). A paused key has `pausedAt`. Unknown IDs never
appear. Revoked keys, expired keys & other accounts' keys never appear either.

</ResponseField>

### 400 Invalid input

```json
{
  "error": "invalid_input",
  "message": "Send ids as a list of 1 to 100 API key IDs. Set paused to true or false."
}
```

`ids` was missing, empty, longer than 100, or held a value that is not a numeric ID. `paused` was
missing or not `true` or `false`. Xquik changes nothing.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing, expired, or invalid dashboard session cookie.

### 429 Rate limited

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```

Too many requests. Wait for the `Retry-After` header before retrying.

<Note>

Pausing keeps each key & its settings. To stop a key for good, use
[Revoke API keys](/api-reference/api-keys/bulk-revoke) instead.
