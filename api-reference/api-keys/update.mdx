<LlmsDirective />

Rename a key so its owner is clear, or narrow a key that only reads to `paid_reads`. Pause a key
to stop it for a while, then resume it. Limit a key to your servers with `allowedIps`. Send 1 or
more of `name`, `scope`, `paused` & `allowedIps`. The key keeps its secret, prefix and expiry.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

import (

## Path parameters

<ParamField path="id" type="string" required>

The unique identifier of the API key to update.

</ParamField>

## Headers

<ParamField header="Cookie" type="string" required>
  Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get
  `403 session_required`.
</ParamField>

<ParamField header="Origin" type="string" required>
  Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The
  dashboard sends both.
</ParamField>

<ParamField header="Content-Type" type="string" required>

Must be `application/json`.

</ParamField>

## Body

Send at least 1 field.

<ParamField body="name" type="string">

New display name, up to 100 characters. An empty name saves `"Default"`.

</ParamField>

<ParamField body="scope" type="string">

`full` calls every route an API key can use. `paid_reads` calls paid X read routes only. Other
routes answer it with `403 insufficient_scope`. The key's next request uses the new scope.

</ParamField>

<ParamField body="scopes" type="string[]">

The scopes the key holds, from `full`, `read`, `write`, `monitors`, `exports` & `billing`.
Every key holds `read`. `scopes` wins over `scope`. Missing keeps the key's scopes.
The key's next request uses the new list.

</ParamField>

<ParamField body="paused" type="boolean">

`true` pauses the key, and `false` resumes it. A paused key gets `403 api_key_paused` on every
request. Its next request after you resume goes through. Sending the current state again changes
nothing. While paused, the key has `pausedAt`, the time you paused it. A revoked key answers
`409 api_key_revoked`. An expired key answers `409 api_key_expired`.

</ParamField>

<ParamField body="allowedIps" type="string[]">

Up to 20 IPv4 or IPv6 addresses or CIDR ranges that may use the key. The list replaces the saved
one. Send `[]` to allow any IP again. Calls from other IPs get `403 ip_not_allowed`. The key's next
request uses the new list.

</ParamField>

## Response

### 200 OK

Returns the saved key with the same fields as [List API keys](/api-reference/api-keys/list).

```json
{
  "id": "42",
  "name": "Analytics notebook",
  "prefix": "xq_a1b2",
  "scope": "paid_reads",
  "scopes": ["read"],
  "allowedIps": [],
  "isActive": true,
  "createdAt": "2026-02-24T10:30:00.000Z",
  "lastUsedAt": "2026-02-24T18:45:12.000Z"
}
```

### 400 Invalid input

```json
{
  "error": "invalid_input",
  "message": "Send name, scopes, paused or allowedIps to change."
}
```

The body had no field to change, `scope` was not `full` or `paid_reads`, a `scopes` entry was not a
scope, or `name` was longer than 100 characters. An `allowedIps` entry that isn't an IP or CIDR range fails too. So does a list over 20
entries. Xquik changes nothing.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing, expired, or invalid dashboard session cookie.

### 404 Not found

```json
{ "error": "not_found" }
```

No active API key with this ID exists on your account. A revoked key cannot change.

### 429 Rate limited

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```

Too many requests. Wait for the `Retry-After` header before retrying.

<Note>

API key changes require a same-origin dashboard session. API keys and OAuth bearer tokens cannot
change account keys.
