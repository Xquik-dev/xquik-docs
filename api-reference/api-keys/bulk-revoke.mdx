`POST https://xquik.com/api/v1/api-keys/bulk-revoke`

Clean up old or leaked keys in 1 request. Xquik revokes each listed key that belongs to your
account. It answers with the IDs it revoked. It skips IDs of unknown keys and of other accounts'
keys. So a retry is safe.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<CodeGroup>

```bash cURL
curl -X POST https://dashboard.xquik.com/api/v1/api-keys/bulk-revoke \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{"ids": ["42", "43"]}' | jq
```

```python Python
import requests

response = requests.post(
    "https://dashboard.xquik.com/api/v1/api-keys/bulk-revoke",
    cookies={"__Host-xquik_session": "YOUR_SESSION_COOKIE"},
    headers={"Origin": "https://dashboard.xquik.com", "Sec-Fetch-Site": "same-origin"},
    json={"ids": ["42", "43"]},
)
print(response.json()["revoked"])
```

```go Go
package main

import (
	"bytes"
	"fmt"
	"io"
	"log"
	"net/http"
)

func main() {
	body := bytes.NewBufferString(`{"ids": ["42", "43"]}`)
	req, err := http.NewRequest("POST", "https://dashboard.xquik.com/api/v1/api-keys/bulk-revoke", body)
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Origin", "https://dashboard.xquik.com")
	req.Header.Set("Sec-Fetch-Site", "same-origin")
	req.AddCookie(&http.Cookie{Name: "__Host-xquik_session", Value: "YOUR_SESSION_COOKIE"})

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	answer, err := io.ReadAll(resp.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(answer))
}
```

## Headers

| Header         | Type     | Required | Description                                                                                                            |
| -------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `Cookie`       | `string` | Yes      | Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get `403 session_required`. |
| `Origin`       | `string` | Yes      | Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The dashboard sends both.      |
| `Content-Type` | `string` | Yes      | Must be `application/json`.                                                                                            |

</section>

<section>

## Body

| Body parameter | Type       | Required | Description                                                                                               |
| -------------- | ---------- | -------- | --------------------------------------------------------------------------------------------------------- |
| `ids`          | `string[]` | Yes      | IDs of the keys to revoke, from 1 to 10,000. Get them from [List API keys](/api-reference/api-keys/list). |

</section>

<section>

## Response

### 200 OK

| Field     | Type       | Description                                                                                                                                                                  |
| --------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `revoked` | `string[]` | IDs of your keys that are now revoked, newest first. A key you had already revoked still appears. Unknown IDs and other accounts' keys never do. A repeated ID appears once. |

```json
{ "revoked": ["42", "43"] }
```

### 400 Invalid input

`{ "error": "invalid_input", "message": "Send ids as a list of 1 to 10000 API key IDs." }`

`ids` was missing, empty, or longer than 100. Or it held a value that is not a numeric ID.
Xquik revokes nothing.

### 401 Unauthenticated

Missing, expired, or invalid dashboard session cookie.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.

<Warning>

Revocation is **immediate and permanent**. Every request with a revoked key returns
`401 Unauthenticated`. Create a new key if you need one. To stop keys for a while, pause them on
the [API keys page](https://dashboard.xquik.com/en/api-keys) instead.

</Warning>

<Note>

API key revocation requires a same-origin dashboard session. API keys and OAuth bearer tokens cannot
revoke account keys.

**Related.** [Revoke API Key](/api-reference/api-keys/revoke) &middot; [List API Keys](/api-reference/api-keys/list) &middot; [Create API Key](/api-reference/api-keys/create)

</Note>
