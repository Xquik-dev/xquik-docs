## When to create a key

Use this route only when creating a new credential. `fullKey` appears at creation, so store it immediately in a secret manager. List operations return inventory data and never replace this storage step.

Give each workload only the `scopes` it needs. A key that only reads X data needs `["read"]`. Set `expiresInDays` so a forgotten key stops working on its own.

Set `allowedIps` so only your servers can use the key. Calls from other IPs get `403 ip_not_allowed`.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

Store `fullKey` immediately and log only `id` and `prefix`.

<CodeGroup>

```bash cURL
response=$(curl -sS -X POST https://dashboard.xquik.com/api/v1/api-keys \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{"name": "Production"}')
full_key=$(jq -r '.fullKey' <<<"$response")
key_id=$(jq -r '.id' <<<"$response")
key_prefix=$(jq -r '.prefix' <<<"$response")
# Store $full_key in your secret manager; do not print it in logs.
printf 'Created API key %s (%s)\n' "$key_id" "$key_prefix"
```

import requests

response = requests.post(

```go Go
package main

import (
  "bytes"
  "encoding/json"
  "fmt"
  "log"
  "net/http"
)

func main() {
  body, err := json.Marshal(map[string]string{"name": "Production"})
  if err != nil {
    log.Fatal(err)
  }

  req, err := http.NewRequest("POST", "https://dashboard.xquik.com/api/v1/api-keys", bytes.NewReader(body))
  if err != nil {
    log.Fatal(err)
  }
  req.Header.Set("Content-Type", "application/json")
  req.Header.Set("Origin", "https://dashboard.xquik.com")
  req.Header.Set("Sec-Fetch-Site", "same-origin")
  req.AddCookie(&http.Cookie{Name: "__Host-xquik_session", Value: "YOUR_SESSION_COOKIE"})

  resp, err := http.DefaultClient.Do(req)
  if err != nil {
    log.Fatal(err)
  }
  defer resp.Body.Close()

  var key map[string]string
  if err := json.NewDecoder(resp.Body).Decode(&key); err != nil {
    log.Fatal(err)
  }

  apiKey := key["fullKey"]
  // Store apiKey in your secret manager; do not print it in logs.
  _ = apiKey
  fmt.Printf("Created API key %s (%s)\n", key["id"], key["prefix"])
}
```

| API key receipt column | Response source             | Storage rule                                 |
| ---------------------- | --------------------------- | -------------------------------------------- |
| Key ID                 | `id`                        | Use this ID for later revocation.            |
| Full API key           | `fullKey`                   | Store it once in an approved secret manager. |
| Safe prefix            | `prefix`                    | Use this value in logs and key inventories.  |
| Key label              | `name`                      | Identify the workload or environment.        |
| Access scope           | `scope`                     | Confirm the key can call only what it needs. |
| Scopes held            | `scopes`                    | Confirm the list matches the workload.       |
| IP allowlist           | `allowedIps`                | Confirm only your servers' IPs are listed.   |
| Creation time          | `createdAt`                 | Record when credential access began.         |
| Expiry time            | `expiresAt`                 | Plan the replacement before this time.       |
| Active-key limit       | `403 api_key_limit_reached` | Revoke an unused key before retrying.        |

## Headers

<ParamField header="Cookie" type="string" required>
  Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get
  `403 session_required`.
</ParamField>

<ParamField header="Origin" type="string" required>
  Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The
  dashboard sends both.
</ParamField>

<ParamField header="Content-Type" type="string" required>

Must be `application/json`.

</ParamField>

## Body

<ParamField body="name" type="string">

Display name for the key. Defaults to `"Default"` if omitted.

</ParamField>

<ParamField body="scope" type="string" default="full">

What the key can call. `full` calls every route an API key can use. `paid_reads` calls paid X read
routes only, such as tweet search, profiles and tweets. Other routes answer it with
`403 insufficient_scope`. Missing or `null` saves `full`. Change it later with
[Update API key](/api-reference/api-keys/update).

</ParamField>

<ParamField body="scopes" type="string[]">

The scopes the key holds. Pick from `full`, `read`, `write`, `monitors`, `exports` & `billing`.
Every key holds `read`. A list with `full` saves Full access. `scopes` wins over `scope`.
Calls outside the list get `403 insufficient_scope`.
[Authentication](/api-reference/authentication#limit-what-a-key-can-call) lists what each scope covers.

</ParamField>

<ParamField body="expiresInDays" type="integer">

Days until the key stops working, from 1 to 365. Missing or `null` keeps it working until you revoke
it. You cannot change the expiry later. Create a new key instead.

</ParamField>

<ParamField body="allowedIps" type="string[]">

Up to 20 IPv4 or IPv6 addresses or CIDR ranges that may use the key. Use entries like
`203.0.113.4`, `198.51.100.0/24` or `2001:db8::/32`. Calls from other IPs get `403 ip_not_allowed`.
Missing or `[]` allows any IP. Change the list later with
[Update API key](/api-reference/api-keys/update).

</ParamField>

## Response

### 201 Created

<ResponseField name="id" type="string">

Unique identifier for the API key.

</ResponseField>
<ResponseField name="fullKey" type="string">

The complete API key including the `xq_` prefix.

</ResponseField>
<ResponseField name="prefix" type="string">

First 8 characters of the key including the `xq_` prefix (for example `"xq_a1b2"`).

</ResponseField>
<ResponseField name="name" type="string">

Display name of the key.

</ResponseField>
<ResponseField name="scope" type="string">

`full` or `paid_reads`.

</ResponseField>
<ResponseField name="scopes" type="string[]">

The scopes the key holds. A Full access key holds `full`.

</ResponseField>
<ResponseField name="allowedIps" type="string[]">

IPs & CIDR ranges that may use the key. An empty list allows any IP.

</ResponseField>
<ResponseField name="isActive" type="boolean">

Always `true` for a new key.

</ResponseField>
<ResponseField name="createdAt" type="string">

ISO 8601 creation timestamp.

</ResponseField>
<ResponseField name="expiresAt" type="string">

ISO 8601 time the key stops working. Omitted when the key never expires.

</ResponseField>

<Warning>

Xquik returns `fullKey` once. Store it in a secret manager. You cannot retrieve it again.

</Warning>

### 400 Invalid input

```json
{
  "error": "invalid_input",
  "message": "Set expiresInDays to a whole number from 1 to 365."
}
```

`scope` is not `full` or `paid_reads`, a `scopes` entry is not a scope, `expiresInDays` is outside 1 to 365, or `name` is longer than
100 characters. An `allowedIps` entry that isn't an IP or CIDR range fails too. So does a list over
20 entries. The message names the field to fix. Xquik creates no key.

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```

Missing, expired, or invalid dashboard session cookie.

### 403 Key limit reached

```json
{
  "error": "api_key_limit_reached",
  "limit": 100,
  "message": "API key limit reached. Delete an existing key first."
}
```

You have reached the maximum number of active API keys (100). Revoke an active key before creating a new one. Revoked keys do not count toward the active limit.

### 429 Rate limited

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```

Too many requests. Wait for the `Retry-After` header before retrying.

<Note>

API key creation requires a same-origin dashboard session. API keys and OAuth
bearer tokens cannot create more keys.
