## When to create a key

Use this route only when creating a new credential. `fullKey` appears at creation, so store it immediately in a secret manager. List operations return inventory data and never replace this storage step.

{"\n"}

Give each workload only the `scopes` it needs. A key that only reads X data needs `["read"]`. Set `expiresInDays` so a forgotten key stops working on its own.

{"\n"}

Set `allowedIps` so only your servers can use the key. Calls from other IPs get `403 ip_not_allowed`.

{"\n"}

Set `monthlyBudgetCredits` to cap what the key spends each UTC calendar month.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

Store `fullKey` immediately and log only `id` and `prefix`.

<CodeGroup>

```bash cURL
response=$(curl -sS -X POST https://dashboard.xquik.com/api/v1/api-keys \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{"name": "Production"}')
full_key=$(jq -r '.fullKey' <<<"$response")
key_id=$(jq -r '.id' <<<"$response")
key_prefix=$(jq -r '.prefix' <<<"$response")
# Store $full_key in your secret manager; do not print it in logs.
printf 'Created API key %s (%s)\n' "$key_id" "$key_prefix"
```

```go Go
package main

import (
  "bytes"
  "encoding/json"
  "fmt"
  "log"
  "net/http"
)

func main() {
  body, err := json.Marshal(map[string]string{"name": "Production"})
  if err != nil {
    log.Fatal(err)
  }

  req, err := http.NewRequest("POST", "https://dashboard.xquik.com/api/v1/api-keys", bytes.NewReader(body))
  if err != nil {
    log.Fatal(err)
  }
  req.Header.Set("Content-Type", "application/json")
  req.Header.Set("Origin", "https://dashboard.xquik.com")
  req.Header.Set("Sec-Fetch-Site", "same-origin")
  req.AddCookie(&http.Cookie{Name: "__Host-xquik_session", Value: "YOUR_SESSION_COOKIE"})

  resp, err := http.DefaultClient.Do(req)
  if err != nil {
    log.Fatal(err)
  }
  defer resp.Body.Close()

  var key map[string]string
  if err := json.NewDecoder(resp.Body).Decode(&key); err != nil {
    log.Fatal(err)
  }

  apiKey := key["fullKey"]
  // Store apiKey in your secret manager; do not print it in logs.
  _ = apiKey
  fmt.Printf("Created API key %s (%s)\n", key["id"], key["prefix"])
}
```

| Expiry time            | `expiresAt`                 | Plan the replacement before this time.       |
| Active-key limit       | `403 api_key_limit_reached` | Revoke an unused key before retrying.        |

## Headers

| Header         | Type     | Required | Description                                                                                                            |
| -------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `Cookie`       | `string` | Yes      | Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get `403 session_required`. |
| `Origin`       | `string` | Yes      | Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The dashboard sends both.      |
| `Content-Type` | `string` | Yes      | Must be `application/json`.                                                                                            |

## Body

| Body parameter         | Type       | Required | Description                                                                                                                                                                                                                                                                                                                                            |
| ---------------------- | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `name`                 | `string`   | No       | Display name for the key. Defaults to `"Default"` if omitted.                                                                                                                                                                                                                                                                                          |
| `scope`                | `string`   | No       | What the key can call. `full` calls every route an API key can use. `paid_reads` calls paid X read routes only, such as tweet search, profiles and tweets. Other routes answer it with `403 insufficient_scope`. Missing or `null` saves `full`. Change it later with [Update API key](/api-reference/api-keys/update).                                |
| `scopes`               | `string[]` | No       | The scopes the key holds. Pick from `full`, `read`, `write`, `monitors`, `exports` & `billing`. Every key holds `read`. A list with `full` saves Full access. `scopes` wins over `scope`. Calls outside the list get `403 insufficient_scope`. [Authentication](/api-reference/authentication#limit-what-a-key-can-call) lists what each scope covers. |
| `connectsXAccounts`    | `boolean`  | No       | Lets this key connect, reconnect & disconnect X accounts. It starts off. Only a dashboard session can set it.                                                                                                                                                                                                                                          |
| `expiresInDays`        | `integer`  | No       | Days until the key stops working, from 1 to 365. Missing or `null` keeps it working until you revoke it. You cannot change the expiry later. Create a new key instead.                                                                                                                                                                                 |
| `allowedIps`           | `string[]` | No       | Up to 20 IPv4 or IPv6 addresses or CIDR ranges may use the key. Use entries like `203.0.113.4`, `198.51.100.0/24` or `2001:db8::/32`. Calls from other IPs get `403 ip_not_allowed`. Missing or `[]` allows any IP. Change the list later with [Update API key](/api-reference/api-keys/update).                                                       |
| `monthlyBudgetCredits` | `integer`  | No       | Credits the key can spend each UTC calendar month, from 1 to 1,000,000,000,000. Missing or `null` sets no budget. New calls that don't fit the budget get `403 api_key_budget_reached`. Change or remove it later with [Update API key](/api-reference/api-keys/update).                                                                               |

</section>

## Response

### 201 Created

| Field                  | Type       | Description                                                                               |
| ---------------------- | ---------- | ----------------------------------------------------------------------------------------- |
| `id`                   | `string`   | Unique identifier for the API key.                                                        |
| `fullKey`              | `string`   | The complete API key including the `xq_` prefix.                                          |
| `prefix`               | `string`   | First 8 characters of the key including the `xq_` prefix (for example `"xq_a1b2"`).       |
| `name`                 | `string`   | Display name of the key.                                                                  |
| `scope`                | `string`   | `full` or `paid_reads`.                                                                   |
| `scopes`               | `string[]` | The scopes the key holds. A Full access key holds `full`.                                 |
| `connectsXAccounts`    | `boolean`  | Whether this key can connect, reconnect & disconnect X accounts.                          |
| `allowedIps`           | `string[]` | IPs & CIDR ranges that may use the key. An empty list allows any IP.                      |
| `isActive`             | `boolean`  | Always `true` for a new key.                                                              |
| `createdAt`            | `string`   | ISO 8601 creation timestamp.                                                              |
| `expiresAt`            | `string`   | ISO 8601 time the key stops working. Omitted when the key never expires.                  |
| `monthlyBudgetCredits` | `integer`  | Credits the key can spend each UTC calendar month. Omitted when the key has no budget.    |
| `monthlySpentCredits`  | `integer`  | Credits charged for calls with the key this UTC calendar month. Always `0` for a new key. |

<Warning>

Xquik returns `fullKey` once. Store it in a secret manager. You cannot retrieve it again.

</Warning>

### 400 Invalid input

`{ "error": "invalid_input", "message": "Set expiresInDays to a whole number from 1 to 365." }`

{"\n"}

`scope` is not `full` or `paid_reads`, or a `scopes` entry is not a scope.
An `expiresInDays` outside 1 to 365 fails too. So does a `name` longer than 100 characters.
An `allowedIps` entry that isn't an IP or CIDR range fails too. So does a list over 20 entries.
So does a `monthlyBudgetCredits` that isn't a whole number from 1 to 1,000,000,000,000.
The message names the field to fix. Xquik creates no key.

### 401 Unauthenticated

Missing, expired, or invalid dashboard session cookie.

### 403 Key limit reached

`{ "error": "api_key_limit_reached", "limit": 10000, "message": "API key limit reached. Delete an existing key first." }`

{"\n"}

You have reached the maximum number of active API keys (10,000). Revoke an active key before creating a new one. Revoked keys do not count toward the active limit.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.

<Note>

API key creation requires a same-origin dashboard session. API keys and OAuth
bearer tokens cannot create more keys.
