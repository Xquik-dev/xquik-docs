`DELETE https://xquik.com/api/v1/x/account-connection-links/{id}`

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

Revoke a link sent to the wrong person, or one nobody needs anymore.
To remove an account a link connected, call [Disconnect X account](/api-reference/x-accounts/disconnect).

<CodeGroup>

```bash cURL
curl -X DELETE https://xquik.com/api/v1/x/account-connection-links/xlink_AAAAAAAAAAAAAAAA \
  -H "x-api-key: $XQUIK_API_KEY" | jq
```

</CodeGroup>

<section>

## Headers

| Header      | Type     | Required       | Description                                                      |
| ----------- | -------- | -------------- | ---------------------------------------------------------------- |
| `x-api-key` | `string` | Or `Cookie`    | A Full access API key.                                           |
| `Cookie`    | `string` | Or `x-api-key` | Your signed-in dashboard session cookie, `__Host-xquik_session`. |

</section>

<section>

## Path

| Path parameter | Type     | Required | Description                            |
| -------------- | -------- | -------- | -------------------------------------- |
| `id`           | `string` | Yes      | The `id` the create response gave you. |

</section>

<section>

## Response

### 200 OK

`{ "success": true }`

{"\n"}

### 400 Invalid input

`id` isn't a connect link ID. Use the `id` the create response gave you.

### 401 Unauthenticated

`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`

### 403 Forbidden

The key isn't Full access. OAuth tokens and MCP tools get `403 session_required`, since a link works like a password.

### 404 Not found

The link doesn't exist, belongs to another account, already connected, or was already revoked.

### 429 Rate limited

`{ "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 1 }`
