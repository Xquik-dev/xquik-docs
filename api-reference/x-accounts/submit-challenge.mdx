`POST https://xquik.com/api/v1/x/account-connection-challenges/{id}/submit`

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<Warning>

This takes a dashboard session, or a key with the **Connect X accounts** permission. Turn it on at [dashboard.xquik.com/api-keys](https://dashboard.xquik.com/api-keys). Full access doesn't include it. A key without it gets `403 x_account_connect_permission_required`. OAuth tokens and MCP tools get `403 session_required`.

</Warning>

Use this endpoint after [Connect X Account](/api-reference/x-accounts/connect) returns `202 Email Code Required`. Submit the one-time code from the account email inbox before `expiresAt`.

<Warning>

This endpoint cannot reopen an expired, failed, completed, or replaced challenge. After `409`, `410`, or `422`, start [Connect X Account](/api-reference/x-accounts/connect) again for a new account. For an existing account, use [Re-authenticate X Account](/api-reference/x-accounts/reauth). Call it with the current password and any required TOTP secret key.

</Warning>

## Continue the pending login

<CardGroup cols={1}>

  <Card title="Use the returned challenge ID" icon="ticket-check">

    Keep the `id` from the `202` response. Submit the inbox code to that challenge. The challenge belongs to the same pending login attempt.

  </Card>
  <Card title="Enter the account email code" icon="mail-check">

    Use the one-time code X sent to the account email inbox. Xquik strips spaces before submission. `123 456` and `123456` work the same way.

  </Card>
  <Card title="Handle another code prompt" icon="refresh-cw">

    If X asks for a new email code, this endpoint returns `202` again. Keep the same flow open and submit the next inbox code before `expiresAt`.

  </Card>
  <Card title="Start over when stale" icon="timer-reset">

    `410` means the code expired. `409` means the challenge already completed, failed, or expired. `409` can also mean a newer challenge replaced it. Start [Connect X Account](/api-reference/x-accounts/connect) again for a new account. Or use [Re-authenticate X Account](/api-reference/x-accounts/reauth) for an existing account.

  </Card>
</CardGroup>

The dashboard follows the same flow. It keeps the pending row open and asks for the email code. It accepts a new `202` prompt if X asks again. After the `201` response, it refreshes the account list.

<CodeGroup>

```bash cURL
curl -X POST https://dashboard.xquik.com/api/v1/x/account-connection-challenges/xch_8vGd8Y9JvH6dV0xA/submit \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{"email_code": "123456"}' | jq
```

## Headers

| Header         | Type     | Required       | Description                                                                                                       |
| -------------- | -------- | -------------- | ----------------------------------------------------------------------------------------------------------------- |
| `x-api-key`    | `string` | Or `Cookie`    | An API key holding the Connect X accounts permission.                                                             |
| `Cookie`       | `string` | Or `x-api-key` | Your signed-in dashboard session cookie, `__Host-xquik_session`.                                                  |
| `Origin`       | `string` | With `Cookie`  | Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The dashboard sends both. |
| `Content-Type` | `string` | Yes            | Must be `application/json`.                                                                                       |

## Body

| Body parameter | Type     | Required | Description                                                                                                                               |
| -------------- | -------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `email_code`   | `string` | Yes      | Email verification code for the pending connection. The API accepts codes from 4 to 64 characters. Xquik strips spaces before submission. |

## Response

### 201 Created

| Field       | Type     | Description                                                                                                                                                                                                |
| ----------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`        | `string` | Unique account ID.                                                                                                                                                                                         |
| `xUsername` | `string` | Connected X username.                                                                                                                                                                                      |
| `xUserId`   | `string` | X user ID.                                                                                                                                                                                                 |
| `status`    | `string` | Account connection status (for example `"active"`).                                                                                                                                                        |
| `health`    | `string` | Derived login and cookie health. One of `healthy`, `locked`, `needsReauth`, `recovering`, `suspended`, `temporaryIssue`. See [Account health](/api-reference/x-accounts/list#account-health) for meanings. |
| `createdAt` | `string` | ISO 8601 time when Xquik connected the account.                                                                                                                                                            |

```json
{
  "id": "3",
  "xUsername": "elonmusk",
  "xUserId": "44196397",
  "status": "active",
  "health": "healthy",
  "createdAt": "2026-02-20T08:15:00.000Z"
}
```

### 202 Email code required

| Field       | Type     | Description                                                   |
| ----------- | -------- | ------------------------------------------------------------- |
| `object`    | `string` | Always `x_account_connection_challenge`.                      |
| `id`        | `string` | Challenge ID to submit with the next email verification code. |
| `status`    | `string` | Always `requires_email_code`.                                 |
| `expiresAt` | `string` | ISO 8601 expiration time for the challenge.                   |
| `message`   | `string` | Human-readable next step.                                     |
| `username`  | `string` | X username being connected.                                   |

```json
{
  "object": "x_account_connection_challenge",
  "id": "xch_8vGd8Y9JvH6dV0xA",
  "status": "requires_email_code",
  "expiresAt": "2026-05-08T12:10:00Z",
  "message": "Enter the email verification code to continue.",
  "username": "elonmusk"
}
```

The connection still needs a valid email code. Submit the new code to the same endpoint.

### 400 Invalid input

Missing `email_code`, invalid JSON, or a code outside the accepted length.

### 401 Unauthenticated

`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`

{"\n"}

Missing or invalid API key.

### 404 Not found

`{ "error": "connection_challenge_not_found", "message": "Connection challenge not found." }`

{"\n"}

The challenge ID does not exist or does not belong to the authenticated user.

### 409 Conflict

The challenge already completed, failed, or expired, or a newer challenge replaced it.

### 410 Expired

Start a new account connection to receive a fresh challenge.

### 422 Login failed

X rejected the code or account login state. Start a new connection if the account requires fresh credentials.

### 429 Rate limit exceeded

`{ "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 60 }`

{"\n"}

Wait for the `Retry-After` header before retrying.

### 503 Service unavailable

Retry after a short delay.

<Note>

**Related.** [Connect X Account](/api-reference/x-accounts/connect) starts the challenge. [List X Accounts](/api-reference/x-accounts/list) verifies the account after connection.

</Note>
