## Response

### 200 OK

| Field         | Type             | Description                                                      |
| ------------- | ---------------- | ---------------------------------------------------------------- |
| `object`      | `string`         | Always `x_account_connection_link`.                              |
| `id`          | `string`         | The link's ID.                                                   |
| `purpose`     | `string`         | `connect` or `reconnect`.                                        |
| `status`      | `string`         | See the table below.                                             |
| `reference`   | `string \| null` | Your own ID for this person.                                     |
| `returnUrl`   | `string \| null` | The URL you gave.                                                |
| `accountId`   | `string \| null` | The connected account. Pass it as `account` on later calls.      |
| `xUserId`     | `string \| null` | The X user ID.                                                   |
| `xUsername`   | `string \| null` | The X username.                                                  |
| `health`      | `string \| null` | The account's health.                                            |
| `failure`     | `string \| null` | Why the last login didn't finish.                                |
| `createdAt`   | `string`         | ISO <span className="nw">8601 time</span>.                       |
| `expiresAt`   | `string`         | ISO <span className="nw">8601 time</span>.                       |
| `completedAt` | `string \| null` | ISO <span className="nw">8601 time</span> the account connected. |

The token never appears here, because Xquik stores only its hash.

| `status`              | What it means                                                      |
| --------------------- | ------------------------------------------------------------------ |
| `pending`             | Nobody finished signing in yet.                                    |
| `connecting`          | A <span className="nw">sign-in</span> is running.                  |
| `requires_email_code` | The person is entering a code X emailed them.                      |
| `connected`           | The account connected. The link can't be used again.               |
| `failed`              | X refused <span className="nw">5 logins</span>. Create a new link. |
| `expired`             | The link ran out of time. Create a new link.                       |
| `revoked`             | You revoked it.                                                    |

```json
{
  "object": "x_account_connection_link",
  "id": "xlink_AAAAAAAAAAAAAAAA",
  "purpose": "connect",
  "status": "connected",
  "reference": "crm-user-7",
  "returnUrl": "https://app.example.com/connected",
  "accountId": "42",
  "xUserId": "9876543210",
  "xUsername": "your_x_username",
  "health": "healthy",
  "failure": null,
  "createdAt": "2026-11-08T12:00:00.000Z",
  "expiresAt": "2026-11-08T12:30:00.000Z",
  "completedAt": "2026-11-08T12:04:10.000Z"
}
```

### 400 Invalid input

`id` isn't a connect link ID. Use the `id` the create response gave you.

### 401 Unauthenticated

<span className="cn">`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`</span>

### 403 Forbidden

The key isn't Full access. OAuth tokens and MCP tools get `403 session_required`, since a link works like a password.

### 404 Not found

The link doesn't exist, or belongs to another Xquik account.

### 429 Rate limited

<span className="cn">`{ "error": "rate_`<wbr />`limit_`<wbr />`exceeded", "message": "Too many requests. Try again later.", "retryAfter": 1 }`</span>
