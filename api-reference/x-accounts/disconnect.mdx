<Warning>

Disconnect X accounts at [dashboard.xquik.com/account](https://dashboard.xquik.com/account). This route serves only a signed-in dashboard session, since only a new sign-in restores the account. API keys and OAuth tokens get `403 session_required`.

</Warning>

Use this endpoint when a connected account should no longer be available for write actions, DMs, media upload, or profile updates. It deletes only the stored Xquik connection for that account ID. It does not change the X account itself. After success, the old Xquik account ID returns `404`. Reconnect the account to get a new ID.

## What disconnect does

<CardGroup cols={1}>

  <Card title="Removes this connection" icon="trash-2">

    Xquik removes the stored connection row from your account. Future `GET /x/accounts/{id}` calls for the same ID return `404`.

  </Card>
  <Card title="Stops writes immediately" icon="send">

    The dashboard Disconnect button uses the same endpoint. It warns that write actions stop immediately. After success, new write, DM, media upload, and profile actions must choose another connected account or reconnect this X account.

  </Card>
  <Card title="Keeps monitors separate" icon="radio">

    Account and keyword monitors are independent. Disconnecting credentials for `@username` does not remove monitors that track that username. Delete those monitors separately when tracking should stop.

  </Card>
  <Card title="Reconnect with a new ID" icon="refresh-cw">

    To use the same X account again, call [Connect X Account](/api-reference/x-accounts/connect). Store the new account `id` from the connect response. Do not reuse the deleted ID.

  </Card>
</CardGroup>

<CodeGroup>

```bash cURL
curl -X DELETE https://dashboard.xquik.com/api/v1/x/accounts/3 \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" | jq
```

```javascript Node.js
const response = await fetch("https://dashboard.xquik.com/api/v1/x/accounts/3", {
  method: "DELETE",
  headers: {
    Cookie: "__Host-xquik_session=YOUR_SESSION_COOKIE",
    Origin: "https://dashboard.xquik.com",
    "Sec-Fetch-Site": "same-origin",
  },
});
const data = await response.json();
```

</CodeGroup>

## Path parameters

<ParamField path="id" type="string" required>

The unique account ID.

</ParamField>

## Headers

<ParamField header="Cookie" type="string" required>
  Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get
  `403 session_required`.
</ParamField>

<ParamField header="Origin" type="string" required>
  Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The
  dashboard sends both.
</ParamField>

## Response

### 200 OK

<ResponseField name="success" type="boolean">
  Always `true` on successful disconnection.
</ResponseField>

```json
{ "success": true }
```

### 400 Invalid ID

```json
{ "error": "invalid_id", "message": "Invalid account ID format" }
```

The provided account ID is not a valid format.

### 401 Unauthenticated

```json
{ "error": "unauthenticated", "message": "Missing or invalid API key" }
```

Missing or invalid API key.

### 404 Not found

```json
{ "error": "not_found", "message": "Resource not found." }
```

No account exists with this ID, or it belongs to a different Xquik account.

### 429 Rate limited

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```

Wait for the `Retry-After` value before disconnecting another account.

<Info>

Xquik disconnects the account and permanently deletes stored credentials. This does not affect your X account itself.

</Info>
