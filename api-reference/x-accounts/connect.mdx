`POST https://xquik.com/api/v1/x/accounts`

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<Warning>

Connect X accounts at [dashboard.xquik.com/account](https://dashboard.xquik.com/account). This route serves only a signed-in dashboard session. That way, X passwords never pass through an API key. API keys and OAuth tokens get `403 session_required`.

</Warning>

<Warning>

Xquik encrypts credentials at rest. It uses them only to maintain the
connection. Xquik never stores plaintext passwords.

</Warning>

A durable Xquik connection requires Authenticator App 2FA and `totp_secret`.
Missing the key? Restart Authentication App 2FA in X to reveal a new secret.
Copy it, add it to your authenticator app, and finish X's 6-digit confirmation.
Then send the saved long key as `totp_secret`.

Xquik does not support custom, dedicated, or user-supplied proxies. Xquik connects
from its own infrastructure.

A connection can finish immediately or continue as a tracked attempt. It can
also ask for an email code. If it continues, follow the returned `Location`. Do
not send the credentials again while the attempt is `pending`.

<CodeGroup>

```bash cURL
curl -X POST https://dashboard.xquik.com/api/v1/x/accounts \
  -H "Cookie: __Host-xquik_session=YOUR_SESSION_COOKIE" \
  -H "Origin: https://dashboard.xquik.com" \
  -H "Sec-Fetch-Site: same-origin" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "your_x_username",
    "email": "account@example.invalid",
    "password": "<ACCOUNT_PASSWORD>",
    "totp_secret": "<TOTP_SECRET>"
  }' | jq
```

```javascript Node.js
const response = await fetch("https://dashboard.xquik.com/api/v1/x/accounts", {
  method: "POST",
  headers: {
    Cookie: "__Host-xquik_session=YOUR_SESSION_COOKIE",

  },
  body: JSON.stringify({
    username: "your_x_username",
    email: "account@example.invalid",
    password: "<ACCOUNT_PASSWORD>",

  }),
});
const data = await response.json();
```

</CodeGroup>

| X account connection result | Response source                     | Next step                                              |
| --------------------------- | ----------------------------------- | ------------------------------------------------------ |
| Connected account ID        | `id` from `201`                     | Use this ID for write actions and recovery.            |
| X username                  | `xUsername`                         | Confirm the intended profile connected.                |
| X user ID                   | `xUserId`                           | Store it. It stays the same when the username changes. |
| Connection state            | `status`                            | Continue only after the account becomes active.        |
| Login health                | `health`                            | Require `healthy` before durable actions.              |
| Pending attempt             | `id` from `202 pending`             | Poll the returned `Location` after `Retry-After`.      |
| Email challenge             | `id` from `202 requires_email_code` | Submit the matching email code before expiry.          |
| Challenge expiry            | `expiresAt`                         | Stop using an expired challenge.                       |

<section>

## Headers

| Header         | Type     | Required | Description                                                                                                            |
| -------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `Cookie`       | `string` | Yes      | Your signed-in dashboard session cookie, `__Host-xquik_session`. API keys and OAuth tokens get `403 session_required`. |
| `Origin`       | `string` | Yes      | Must be `https://dashboard.xquik.com`, sent with `Sec-Fetch-Site` set to `same-origin`. The dashboard sends both.      |
| `Content-Type` | `string` | Yes      | Must be `application/json`.                                                                                            |

</section>

<section>

## Body

| Body parameter | Type     | Required | Description                                                                                                               |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| `username`     | `string` | Yes      | X username to connect. Xquik strips the `@` prefix if included.                                                           |
| `email`        | `string` | Yes      | Email address associated with the X account.                                                                              |
| `password`     | `string` | Yes      | Password for the X account. Xquik encrypts it at rest on receipt.                                                         |
| `totp_secret`  | `string` | Yes      | Authenticator App TOTP secret required for a durable connection. This is the base32-encoded secret, not the 6-digit code. |

</section>

<section>

## 2FA secret key setup

Xquik needs the authenticator app secret key, not a live 6-digit code. That key belongs to **Authentication App** 2FA. The key is the long base32 string X shows while you set up 2FA. An example is `JBSWY3DPEHPK3PXP`.

<CardGroup cols={2}>

  <Card title="Use the secret key" icon="key-round">

    Paste the long base32 key into `totp_secret`. Xquik uses it to generate fresh 2FA codes during login challenges.

  </Card>
  <Card title="Do not use backup codes" icon="ban">

    Do not paste the 6-digit authenticator code. Do not paste the 12-character backup code, a passkey, or a security key prompt.

  </Card>
</CardGroup>

If you already saved the secret key, send it as `totp_secret`. If you did not save it, create a fresh authenticator app secret on X.

<CardGroup cols={1}>

  <Card title="You saved the key" icon="clipboard-check">

    Paste that saved base32 secret into `totp_secret`. Do not paste the current 6-digit authenticator code.

  </Card>
  <Card title="2FA is on, key is missing" icon="rotate-ccw">

    X shows the text secret only during Authentication App setup. Turn Authentication App off, then on again. Copy the new key, then finish setup on X.

  </Card>
  <Card title="2FA is not enabled" icon="shield-check">

    Start Authentication App setup on X and reveal the text secret. Copy it and add it to your authenticator app. Confirm the 6-digit code on X, then connect.

  </Card>
</CardGroup>

1. Open X **Settings and Privacy > Security and Account Access > Security**.
2. Open **Two-Step Verification > Authentication App**.
3. Turn Authentication App off.
4. Turn Authentication App on again.
5. X shows a QR code. Then choose **Can't scan the QR code?** to reveal the text secret.
6. Copy the long secret key. Then store it in a password manager before leaving the setup screen.
7. Add that key to your authenticator app if you are setting it up fresh.
8. Finish enabling 2FA on X by entering the current 6-digit code. The code comes from your authenticator app.
9. Send the saved long key in `totp_secret` when you call Xquik.

<Warning>

Do not stop after copying the secret key. Complete the X-side 2FA confirmation before starting the Xquik connection. Otherwise the key will not work.

</Warning>

<Note>

Xquik can't complete passkey or security key prompts. If X asks this account for a passkey, delete the passkey on X. In that case, keep Authenticator App 2FA.

</Note>

## Response

### 201 Created

| Field       | Type     | Description                                                                                                                                                                                                |
| ----------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`        | `string` | Unique account ID.                                                                                                                                                                                         |
| `xUsername` | `string` | Connected X username.                                                                                                                                                                                      |
| `xUserId`   | `string` | X user ID.                                                                                                                                                                                                 |
| `status`    | `string` | Account connection status (for example `"active"`).                                                                                                                                                        |
| `health`    | `string` | Derived login and cookie health. One of `healthy`, `locked`, `needsReauth`, `recovering`, `suspended`, `temporaryIssue`. See [Account health](/api-reference/x-accounts/list#account-health) for meanings. |
| `createdAt` | `string` | ISO 8601 time when Xquik connected the account.                                                                                                                                                            |

```json
{
  "id": "3",
  "xUsername": "your_x_username",
  "xUserId": "9876543210",
  "status": "active",
  "health": "healthy",
  "createdAt": "2026-02-20T08:15:00.000Z"
}
```

### 202 Connecting

| Field         | Type      | Description                                          |
| ------------- | --------- | ---------------------------------------------------- |
| `object`      | `string`  | Always `x_account_connection_attempt`.               |
| `id`          | `string`  | Connection attempt ID.                               |
| `status`      | `string`  | Always `pending`.                                    |
| `pollAfterMs` | `integer` | Milliseconds to wait before checking the status URL. |

```json
{
  "object": "x_account_connection_attempt",
  "id": "xatt_0123456789abcdef0123456789abcdef",
  "status": "pending",
  "pollAfterMs": 3000
}
```

The response includes these headers.

- `Location: /api/v1/x/account-connection-attempts/{id}`
- `Retry-After: 3`
- `Cache-Control: no-store`

Wait for `Retry-After`, then call [Get X Account Connection Status](/api-reference/x-accounts/connection-attempt). Keep checking while `status` is `pending`. Do not create another attempt.

### 202 Email code required

| Field       | Type     | Description                                              |
| ----------- | -------- | -------------------------------------------------------- |
| `object`    | `string` | Always `x_account_connection_challenge`.                 |
| `id`        | `string` | Challenge ID to submit with the email verification code. |
| `status`    | `string` | Always `requires_email_code`.                            |
| `expiresAt` | `string` | ISO 8601 expiration time for the challenge.              |
| `message`   | `string` | Human-readable next step.                                |
| `username`  | `string` | X username being connected.                              |

```json
{
  "object": "x_account_connection_challenge",
  "id": "xch_8vGd8Y9JvH6dV0xA",
  "status": "requires_email_code",
  "expiresAt": "2026-05-08T12:10:00Z",
  "message": "Enter the email verification code to continue.",
  "username": "elonmusk"
}
```

Submit the code to [Submit X Account Email Code](/api-reference/x-accounts/submit-challenge).

### 400 Invalid input

Missing `username`, `email`, `password`, or `totp_secret`, or invalid field format.

### 401 Unauthenticated

`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`

{"\n"}

Missing or invalid API key.

### 409 Duplicate

The specified X account is already connected to your Xquik account.

### 429 Rate limit exceeded

`{ "error": "rate_limit_exceeded", "message": "Connection safety limit reached. Try again later.", "retryAfter": 900 }`

{"\n"}

You reached the connection safety limit. The `Retry-After: 900` header gives the seconds to wait before retrying. See the [rate limits guide](/guides/rate-limits) for details.

### 429 Login cooldown

`{ "error": "login_cooldown", "message": "Login is temporarily paused", "reason": "automated", "retryAfterMs": 3600000 }`

{"\n"}

A prior login attempt triggered a cooldown (for example, X flagged the session). Wait for `retryAfterMs` before retrying. The response includes a `Retry-After` header in seconds.

### 422 Login failed

`{ "error": "login_failed", "message": "Login failed. Check credentials and try again.", "retryAfterMs": 300000 }`

{"\n"}

X rejected the submitted username, email, password, or TOTP secret. Retry with the current password and the saved Authenticator App secret key. Use the key, not a 6-digit code. When `retryAfterMs` is present, wait for that duration. The response also includes `Retry-After` in seconds.

{"\n"}

`{ "error": "passkey_required", "message": "X asked this account to sign in with a passkey. Delete the passkey in X's security settings, keep Authentication app 2FA, then try again.", "retryAfterMs": 3600000 }`

{"\n"}

X showed this account a passkey sign-in, which Xquik can't complete. Open X **Settings and Privacy > Security and Account Access > Security > Passkey**. Delete the passkey but keep Authenticator App 2FA on, then connect again after `retryAfterMs`. The response also includes `Retry-After` in seconds.

{"\n"}

`{ "error": "login_failed", "reason": "login_unconfirmed", "message": "X didn't confirm the sign-in after your password. Wait 5 minutes, then try again. Retrying sooner can make X lock the account.", "retryAfterMs": 300000 }`

{"\n"}

X showed no known page after the password. Xquik sends the password only once per attempt. Wait for `Retry-After`, then try again. Retrying sooner can make X lock the account.

### 502 X user lookup failed

`{ "error": "x_user_lookup_failed", "message": "X user not found. Check the username." }`

{"\n"}

Xquik could not resolve the X username. Verify the handle is correct and that the account exists.

### 503 Service unavailable

`{ "error": "service_unavailable", "message": "Service temporarily unavailable. Try again." }`

{"\n"}

The X connection service is temporarily unavailable. Retry after a short delay.
