GET https://xquik.com/api/v1/x/account-connection-attempts/{id}

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<Warning>

This takes a dashboard session, or a key with the **Connect X accounts** permission. Turn it on at [dashboard.xquik.com/api-keys](https://dashboard.xquik.com/api-keys). Full access doesn't include it. A key without it gets <span className="cn"><span className="nw">`403 x_`</span><wbr />`account_`<wbr />`connect_`<wbr />`permission_`<wbr />`required`</span>. OAuth tokens and MCP tools get `403 session_required`. An ID this account never started reads as `pending`, like one still registering.

</Warning>

<Info>

Check this endpoint after the connect response's `Retry-After` delay. You can
call other Xquik routes while the connection continues. Do not send the credentials again
while `status` is `pending`.

</Info>

<section>

## Response

Every `200` response includes <span className="cn"><span className="nw">`Cache-Control: `</span><wbr /><span className="nw">`no-store`</span></span>.

### 200 Pending

| Field         | Type      | Description                                 |
| ------------- | --------- | ------------------------------------------- |
| `object`      | `string`  | Always `x_account_connection_attempt`.      |
| `id`          | `string`  | Connection attempt ID.                      |
| `status`      | `string`  | Always `pending`.                           |
| `pollAfterMs` | `integer` | Milliseconds to wait before checking again. |

```json
{
  "object": "x_account_connection_attempt",
  "id": "xatt_0123456789abcdef0123456789abcdef",
  "status": "pending",
  "pollAfterMs": 3000
}
```

The response includes `Retry-After: 3`. Wait, then check the same attempt.

### 200 Success

| Field       | Type     | Description                            |
| ----------- | -------- | -------------------------------------- |
| `object`    | `string` | Always `x_account_connection_attempt`. |
| `id`        | `string` | Connection attempt ID.                 |
| `status`    | `string` | Always `success`.                      |
| `accountId` | `string` | The connected account's ID.            |

```json
{
  "object": "x_account_connection_attempt",
  "id": "xatt_0123456789abcdef0123456789abcdef",
  "status": "success",
  "accountId": "42"
}
```

The account is ready. Pass `accountId` as `account` on later calls.

### 200 Email code required

| Field       | Type     | Description                                                     |
| ----------- | -------- | --------------------------------------------------------------- |
| `object`    | `string` | Always `x_account_connection_challenge`.                        |
| `id`        | `string` | Challenge ID, not the attempt ID.                               |
| `status`    | `string` | Always `requires_email_code`.                                   |
| `expiresAt` | `string` | ISO <span className="nw">8601 challenge</span> expiration time. |
| `message`   | `string` | <span className="nw">Human-readable</span> next step.           |
| `username`  | `string` | X (Twitter) username being connected.                           |

```json
{
  "object": "x_account_connection_challenge",
  "id": "xch_8vGd8Y9JvH6dV0xA",
  "status": "requires_email_code",
  "expiresAt": "2026-05-08T12:10:00Z",
  "message": "Enter the email verification code to continue.",
  "username": "your_x_username"
}
```

Submit the newest code to [Submit X Account Email Code](/api-reference/x-accounts/submit-challenge).

### 200 Failed

| Field       | Type      | Description                                      |
| ----------- | --------- | ------------------------------------------------ |
| `object`    | `string`  | Always `x_account_connection_attempt`.           |
| `id`        | `string`  | Connection attempt ID.                           |
| `status`    | `string`  | Always `failed`.                                 |
| `error`     | `string`  | Stable public error code.                        |
| `reason`    | `string`  | More specific reason when available.             |
| `retryable` | `boolean` | Whether you can attempt another connect request. |

```json
{
  "object": "x_account_connection_attempt",
  "id": "xatt_0123456789abcdef0123456789abcdef",
  "status": "failed",
  "error": "service_unavailable",
  "retryable": true
}
```

Stop checking this attempt. Start a new connection only when `retryable` is `true`.

### 400 Invalid input

<span className="cn">`{ "error": "invalid_input", "message": "Invalid connection attempt ID. Check the path parameter." }`</span>

{"\n"}

The attempt ID is malformed, unavailable, or belongs to another account.
Xquik does not keep attempts forever. Save the final result.

### 401 Unauthenticated

<span className="cn">`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`</span>

{"\n"}

The API key is missing or invalid.

### 429 Rate limited

<span className="cn">`{ "error": "rate_`<wbr />`limit_`<wbr />`exceeded", "message": "Too many requests. Try again later.", "retryAfter": `<wbr /><span className="nw">`1 }`</span></span>

{"\n"}

Wait for `Retry-After` before checking again.

<Note>

**Related.** [Connect X Account](/api-reference/x-accounts/connect) starts the
attempt. [Submit X Account Email Code](/api-reference/x-accounts/submit-challenge)
completes an email challenge.

</Note>

</section>
