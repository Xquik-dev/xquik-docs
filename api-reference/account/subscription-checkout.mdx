## Create an X API subscription checkout

Call `POST /subscribe` after an authenticated user confirms a billing action.
The request creates a hosted URL. It never completes payment automatically.

Use this route for 3 account states.

| Account state                       | Response status      | Returned destination                       |
| ----------------------------------- | -------------------- | ------------------------------------------ |
| No active subscription              | `checkout_created`   | Hosted subscription checkout               |
| Active or trialing subscription     | `already_subscribed` | Dashboard billing page, after sign-in      |
| Past-due or incomplete subscription | `payment_issue`      | Dashboard billing page, to fix the payment |

Always route by `status`. Do not infer the destination from the URL hostname.
Use only the URL returned by the current response.

This endpoint does not quote current Twitter API pricing or X API pricing.
Review the [live Xquik pricing](https://xquik.com) before checkout.
The home page lists the current tiers and credits.

</section>

<section>

## Choose a subscription tier

Send `tier` only when the user selected a specific Xquik plan.

| Tier value | Checkout behavior                           |
| ---------- | ------------------------------------------- |
| `starter`  | Pre-select Starter.                         |
| `pro`      | Pre-select Pro.                             |
| `business` | Pre-select Business.                        |
| Omitted    | Let the user choose on the hosted checkout. |

The field pre-selects a tier. It does not activate that tier by itself.
Send only the documented enum values.

</section>

<section>

## Pay in the user's currency

Send `currency` to charge in the user's currency. The default is `USD`.

Xquik accepts `USD`, `EUR`, `GBP`, `TRY`, `JPY`, `CNY`, `KRW`, `CAD`, `AUD`, and `MXN`.
Lowercase codes work too. An unknown code returns `400`.

Xquik converts the USD plan price at the latest daily ECB rate.
Each renewal charges the same amount before tax.
An account that already pays in USD gets a USD checkout.
With rates over 3 ECB working days old, the checkout charges USD.
Read `chargedCurrency` to see the currency the checkout charges.

</section>

<section>

## Complete a safe billing handoff

1. Show the current plan and credit terms before confirmation.
2. Call this endpoint once for the confirmed action.
3. Check the HTTP status before reading `url`.
4. Send the user to the returned hosted URL.
5. Keep the billing URL out of logs and analytics.
6. Recheck [`GET /account`](/api-reference/account/get) after the user returns.

Read `plan` to confirm subscription state. Read `creditInfo.balance` before
tweet search, follower exports, writes, or monitor work.

Subscriptions are not the only funding path. A funded pay-as-you-go account can
continue eligible work while `plan` is `inactive`.

</section>

<section>

## Handle checkout retries

The service can reuse a matching open checkout. Use the latest returned
URL. A different tier or currency can replace an older open checkout.

Do not call this endpoint from a timer or an automatic retry loop.
For `429`, wait for `Retry-After`. For `401`, replace the credential first.

</section>

## Body

| Body parameter | Type     | Required | Description                                                                                                   |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------- |
| `tier`         | `string` | No       | Pre-select `starter`, `pro`, or `business`. Omit the body when the user should choose on the hosted checkout. |
| `currency`     | `string` | No       | Currency to pay in, such as `EUR`. Lowercase codes work too. Default `USD`.                                   |

## Response

### 200 OK

| Field             | Type     | Description                                                                                                          |
| ----------------- | -------- | -------------------------------------------------------------------------------------------------------------------- |
| `url`             | `string` | Checkout URL for new subscribers, or the dashboard billing page for existing subscribers. Send the user to this URL. |
| `message`         | `string` | Human-readable message describing the action taken.                                                                  |
| `status`          | `string` | The status is `already_subscribed`, `checkout_created`, or `payment_issue`.                                          |
| `chargedCurrency` | `string` | Currency the checkout charges. Only a `checkout_created` answer has it.                                              |

```json
{
  "chargedCurrency": "EUR",
  "url": "https://xquik.com/billing/checkout/session",
  "message": "Complete checkout at the URL below to start your subscription.",
  "status": "checkout_created"
}
```

### 400 Invalid input

`{ "error": "invalid_input", "message": "currency must be 1 of USD, EUR, GBP, TRY, JPY, CNY, KRW, CAD, AUD, MXN" }`

Send a listed currency code, or omit `currency` to pay in USD.

### 401 Unauthenticated

`{ "error": "unauthenticated", "message": "Missing or invalid API key" }`

Missing or invalid API key.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.
