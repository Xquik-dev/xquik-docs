## Run an API account preflight

Call `GET /account` before a long tweet search, follower export, scheduled write,
or monitor rollout. The response separates subscription access, available
credits, and active monitor cost. It also separates automatic top-up settings and
the linked X username.

| Preflight question                          | Response field                       | Integration decision                                                              |
| ------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------- |
| Is the subscription active?                 | `plan`                               | Report subscription state. Check `creditInfo.balance` before metered work.        |
| How many credits remain?                    | `creditInfo.balance`                 | Compare the Bigint string with the estimated tweet, follower, or extraction cost. |
| How many monitors are active?               | `monitorsUsed`                       | Reconcile account and keyword monitors before enabling another one.               |
| What is the current hourly monitor charge?  | `monitorBilling.activeHourlyBurn`    | Include active monitors in the hourly credit budget.                              |
| What is the estimated daily monitor charge? | `monitorBilling.activeDailyEstimate` | Add the estimate to your daily credit forecast.                                   |
| Is automatic top-up enabled?                | `creditInfo.autoTopupEnabled`        | Confirm the account can buy credits without a manual checkout.                    |
| Which X identity is linked?                 | `xUsername`                          | Compare the username with the intended tweet, reply, or follower workflow.        |

Use `plan` to report subscription state. Do not use it to decide whether credits remain.
Funded pay-as-you-go requests can continue while `plan` is `inactive`.
Treat missing `creditInfo` as no recorded balance, not numeric zero.

Do not use `monitorsAllowed` as a capacity limit. The field is deprecated and
always reports the maximum safe integer. Use `monitorsUsed` and the monitor
billing fields for cost checks.

## Store an account billing snapshot

Store a timestamped account snapshot before a worker starts billable work.
Never convert credit strings to an unsafe JavaScript number.

| Stored value           | Source                               | Use                                                                            |
| ---------------------- | ------------------------------------ | ------------------------------------------------------------------------------ |
| Subscription state     | `plan`                               | Explain why a job started or stopped.                                          |
| Credit balance         | `creditInfo.balance`                 | Reconcile credits before and after tweet, follower, write, or extraction work. |
| Purchased credits      | `creditInfo.lifetimePurchased`       | Compare account funding with cumulative usage.                                 |
| Used credits           | `creditInfo.lifetimeUsed`            | Track total credits the account has used.                                      |
| Active monitors        | `monitorsUsed`                       | Match the snapshot against your account and keyword monitor lists.             |
| Hourly monitor charge  | `monitorBilling.activeHourlyBurn`    | Detect an unexpected monitor-cost increase.                                    |
| Daily monitor estimate | `monitorBilling.activeDailyEstimate` | Forecast the next 24 hours of active monitor usage.                            |
| Automatic top-up state | `creditInfo.autoTopupEnabled`        | Send low-balance alerts to a person or let automatic top-up handle them.       |
| Linked X username      | `xUsername`                          | Confirm which X account write actions will use.                                |

## Response

### 200 OK

| Field                                        | Type      | Description                                                                                                                                                                                                             |
| -------------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plan`                                       | `string`  | Subscription status. `"active"` or `"inactive"`.                                                                                                                                                                        |
| `subscription`                               | `object`  | Subscription state, without billing provider IDs.                                                                                                                                                                       |
| `subscription.status`                        | `string`  | `none`, `active`, `past_due`, `canceling` or `incomplete`.                                                                                                                                                              |
| `subscription.tier`                          | `string`  | `starter`, `pro` or `business`. Omitted without a subscription.                                                                                                                                                         |
| `subscription.currentPeriodStart`            | `string`  | Start of the current billing period, ISO 8601.                                                                                                                                                                          |
| `subscription.currentPeriodEnd`              | `string`  | Renewal date, or the end date when canceling. ISO 8601.                                                                                                                                                                 |
| `monitorsAllowed`                            | `number`  | Deprecated. Monitor slots are unlimited, so this is always `9007199254740991`.                                                                                                                                          |
| `monitorsUsed`                               | `number`  | Number of active account monitors and keyword monitors.                                                                                                                                                                 |
| `monitorBilling`                             | `object`  | Active monitor billing details.                                                                                                                                                                                         |
| `monitorBilling.activeDailyEstimate`         | `string`  | Estimated daily credits for active monitors.                                                                                                                                                                            |
| `monitorBilling.activeHourlyBurn`            | `string`  | Credits charged each hour for active monitors.                                                                                                                                                                          |
| `monitorBilling.creditsPerActiveMonitorDay`  | `string`  | Daily credit estimate for 1 active monitor.                                                                                                                                                                             |
| `monitorBilling.creditsPerActiveMonitorHour` | `string`  | Hourly credits charged for 1 active monitor.                                                                                                                                                                            |
| `monitorBilling.eventsIncluded`              | `boolean` | Whether monitor billing includes webhook and event deliveries.                                                                                                                                                          |
| `monitorBilling.instantCheckIntervalSeconds` | `number`  | Active monitor check interval in seconds.                                                                                                                                                                               |
| `monitorBilling.unlimitedSlots`              | `boolean` | Whether monitor slot count is unlimited.                                                                                                                                                                                |
| `creditInfo`                                 | `object`  | Credit balance details. Omitted if no credit balance row exists yet.                                                                                                                                                    |
| `creditInfo.balance`                         | `string`  | Current credit balance (Bigint string to preserve precision above Number.MAX_SAFE_INTEGER).                                                                                                                             |
| `creditInfo.lifetimePurchased`               | `string`  | Total credits purchased across all time (Bigint string).                                                                                                                                                                |
| `creditInfo.lifetimeUsed`                    | `string`  | Total credits consumed across all time (Bigint string).                                                                                                                                                                 |
| `creditInfo.autoTopupEnabled`                | `boolean` | Whether automatic credit top-up is enabled.                                                                                                                                                                             |
| `creditInfo.autoTopupStopped`                | `boolean` | Whether declined charges stopped automatic top-up while it is enabled. It stops after 3 declines in a row on one card. A paid top-up or a paid plan renewal clears it. So does the next automatic top-up on a new card. |
| `creditInfo.autoTopupAmountDollars`          | `number`  | Dollar amount charged when automatic top-up runs.                                                                                                                                                                       |
| `creditInfo.autoTopupThreshold`              | `string`  | Credit balance threshold that triggers automatic top-up when enabled (Bigint string).                                                                                                                                   |
| `xUsername`                                  | `string`  | Linked X username. Omitted when no X account is connected.                                                                                                                                                              |

### 401 Unauthenticated

Missing or invalid API key. Check the `x-api-key` header value.

### 429 Rate limited

`{"error":"rate_limit_exceeded","message":"Too many requests. Try again later.","retryAfter":1}`

Too many requests. Wait for the `Retry-After` header before retrying.

## Credit balance

Every subscriber gets a monthly credit allowance. Metered reads bill per result
or call. Writes bill per action. Active monitors bill 30 credits per hour.
`monitorsUsed`, `monitorBilling.activeHourlyBurn`, and `monitorBilling.activeDailyEstimate` include active account monitors and active keyword monitors. The daily estimate is 24 hours of the hourly burn. At 0 credits, metered calls return `402`.
