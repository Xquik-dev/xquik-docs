## When to read one ticket

Use this route when one ticket ID needs full message history. Use list for summaries across tickets. Use reply or update only when the conversation or status must change.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

| Support ticket history column | Response source                   | Review rule                                                        |
| ----------------------------- | --------------------------------- | ------------------------------------------------------------------ |
| Ticket ID                     | `publicId`                        | Match the requested ticket before processing.                      |
| Ticket subject                | `subject`                         | Keep the reported workflow visible.                                |
| Current state                 | `status`                          | Handle open, in-progress, resolved, and closed tickets separately. |
| Message author                | `messages[].sender`               | Separate user and support replies.                                 |
| Message text                  | `messages[].body`                 | Keep messages in time order.                                       |
| Attachment state              | `messages[].attachments[].status` | Download only ready attachments.                                   |
| Updated at                    | `updatedAt`                       | Stop polling after the expected state arrives.                     |

## Response

### 200 OK

| Field                                  | Type       | Description                                                           |
| -------------------------------------- | ---------- | --------------------------------------------------------------------- |
| `publicId`                             | `string`   | Unique ticket public ID.                                              |
| `subject`                              | `string`   | Ticket subject.                                                       |
| `status`                               | `string`   | The current status is `open`, `in_progress`, `resolved`, or `closed`. |
| `createdAt`                            | `string`   | ISO 8601 creation timestamp.                                          |
| `updatedAt`                            | `string`   | ISO 8601 last update timestamp.                                       |
| `messages`                             | `object[]` | Array of message objects in time order.                               |
| `messages[].body`                      | `string`   | Message content.                                                      |
| `messages[].sender`                    | `string`   | The sender is `user` or `support`.                                    |
| `messages[].createdAt`                 | `string`   | ISO 8601 timestamp of when the sender posted the message.             |
| `messages[].attachments`               | `object[]` | Private image and video attachments.                                  |
| `messages[].attachments[].publicId`    | `string`   | Attachment public ID.                                                 |
| `messages[].attachments[].filename`    | `string`   | Original filename.                                                    |
| `messages[].attachments[].contentType` | `string`   | Validated media type.                                                 |
| `messages[].attachments[].kind`        | `string`   | `image` or `video`.                                                   |
| `messages[].attachments[].sizeBytes`   | `integer`  | File size in bytes.                                                   |
| `messages[].attachments[].status`      | `string`   | `ready`, `pending`, or `failed`.                                      |
| `messages[].attachments[].url`         | `string`   | Authenticated download path.                                          |

### 401 Unauthenticated

Missing or invalid API key.

### 404 Not found

No ticket exists with this ID, or it belongs to a different account.

### 429 Rate limited

`{"error":"rate_limit_exceeded","message":"Too many requests. Try again later.","retryAfter":1}`

Wait for the `Retry-After` value before fetching the ticket again.
