import (

    req.Header.Set("x-api-key", "xq_YOUR_KEY_HERE")

    if err != nil {
        panic(err)

    defer resp.Body.Close()

    var data map[string]interface{}

## Send a support reply once

Read the ticket before composing a response. Confirm its public ID, status,
latest sender, and most recent message. Another operator may
have answered already.

{"\n"}

Choose the request format by content. Send JSON for text only.
Use multipart form fields when screenshots or videos are required.

{"\n"}

Write a specific message body. Reference the observed problem, completed
check, or requested next step. Avoid pasting secrets, API keys, or private
browser session details.

{"\n"}

Review every attachment before upload. Use only the documented image and video
formats. Keep each file and the combined request within the documented size
limits.

{"\n"}

Generate one idempotency key after the text and attachments are final. Reuse
it only when the identical request loses its response. Changed text or files
require a new key.

{"\n"}

Read each reply status.

- `201` means Xquik created the new message.
- `200` with `Idempotency-Replayed` returns the earlier message.
- `409` means the key already represents different content.
- `404` means the ticket is missing or belongs to another account.
- `429` requires waiting for `Retry-After`.

Store the ticket ID, idempotency key, reply time, and attachment receipts. Do
not store attachment bytes in shared logs.

{"\n"}

Fetch the ticket again after creation. Confirm the message appears once and the
sender is correct. Inspect each attachment status before telling the user a
screenshot or video is available.

</section>

## Path parameters

| Path parameter | Type     | Required | Description                                                                                                                                                                           |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string` | Yes      | The ticket public ID (for example `tkt_a1b2c3d4e5f6a1b2c3d4e5f6`). Returned when you [create a ticket](/api-reference/support/create) or [list tickets](/api-reference/support/list). |

</section>

<section>

## Headers

| Header            | Type     | Required | Description                                                                                                                                                                    |
| ----------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `x-api-key`       | `string` | Yes      | Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://dashboard.xquik.com/en/account?tab=api-keys).                       |
| `Content-Type`    | `string` | Yes      | Use `application/json` for text only. Use `multipart/form-data` for media.                                                                                                     |
| `Idempotency-Key` | `string` | No       | Generate one random value for this reply. Reuse it only when retrying identical text and attachments. A replay returns the original message with `Idempotency-Replayed: true`. |

</section>

<section>

## Body

| Body parameter | Type     | Required | Description                                                                                               |
| -------------- | -------- | -------- | --------------------------------------------------------------------------------------------------------- |
| `body`         | `string` | Yes      | Message content. 1-10,000 characters.                                                                     |
| `attachments`  | `file[]` | No       | Up to 4 JPEG, PNG, GIF, WebP, MP4, MOV, or WebM files. The same per-file and 30 MB combined limits apply. |

For a media-only reply, omit `body` and include at least 1 attachment.

```bash cURL With Media
curl -X POST https://xquik.com/api/v1/support/tickets/tkt_a1b2c3d4e5f6a1b2c3d4e5f6/messages \
  -H "x-api-key: xq_YOUR_KEY_HERE" \
  -H "Idempotency-Key: replace-with-one-random-value" \
  -F "body=This recording shows the current behavior." \
  -F "attachments=@recording.mp4" | jq
```

</section>

## Response

### 201 Created

| Field                    | Type       | Description                                        |
| ------------------------ | ---------- | -------------------------------------------------- |
| `publicId`               | `string`   | Public ID of the ticket that received the message. |
| `attachments`            | `object[]` | Created media receipts.                            |
| `attachments[].publicId` | `string`   | Private attachment public ID.                      |
| `attachments[].status`   | `string`   | The upload status is `ready` or `failed`.          |

```json
{
  "publicId": "tkt_a1b2c3d4e5f6a1b2c3d4e5f6",
  "attachments": []
}
```

### 200 Replayed

Returns the original response after a safe retry. The `Idempotency-Replayed` response header is `true`.

### 400 Invalid input

Missing or invalid `body` field.

### 401 Unauthenticated

Missing or invalid API key.

### 404 Not found

No ticket exists with this ID, or it belongs to a different account.

### 409 Conflict

The `Idempotency-Key` already belongs to different text or attachments. Generate a new key for the changed reply.

### 429 Rate limited

Wait for the `Retry-After` value before adding another reply.
