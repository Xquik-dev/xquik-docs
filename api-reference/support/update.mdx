package main

    var data map[string]interface{}

<section>

## Path parameters

| Path parameter | Type     | Required | Description                                                                                                                                                                           |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string` | Yes      | The ticket public ID (for example `tkt_a1b2c3d4e5f6a1b2c3d4e5f6`). Returned when you [create a ticket](/api-reference/support/create) or [list tickets](/api-reference/support/list). |

</section>

<section>

## Headers

| Header         | Type     | Required | Description                                                                                                                                              |
| -------------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x-api-key`    | `string` | Yes      | Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://dashboard.xquik.com/en/account?tab=api-keys). |
| `Content-Type` | `string` | Yes      | Must be `application/json`.                                                                                                                              |

</section>

<section>

## Body

| Body parameter | Type     | Required | Description                                                                                                                     |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `status`       | `string` | Yes      | New status. Use `open`, `resolved`, or `closed`. Support staff set the `in_progress` status. You cannot set it through the API. |

</section>

<section>

## Response

### 200 OK

| Field      | Type     | Description              |
| ---------- | -------- | ------------------------ |
| `publicId` | `string` | Unique ticket public ID. |
| `status`   | `string` | Updated ticket status.   |

```json
{
  "publicId": "tkt_a1b2c3d4e5f6a1b2c3d4e5f6",
  "status": "resolved"
}
```

### 400 Invalid input

Missing or invalid `status` value.

### 401 Unauthenticated

Missing or invalid API key.

### 404 Not found

`{"error":"not_found","message":"Ticket not found."}`

No support ticket matches the supplied public ID.

### 429 Rate limited

Wait for the `Retry-After` value before updating ticket status again.
