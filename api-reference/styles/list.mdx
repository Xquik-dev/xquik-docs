<section>

## List cached Twitter writing styles

Call this endpoint to list the writing-style profiles in one Xquik
account. Each item summarizes one cached X (Twitter) username or custom label. The list does not include
tweet text, tone analysis, vocabulary, or engagement metrics.

{"\n"}

An empty response is valid.

```json
{
  "styles": []
}
```

An empty `styles` array means this Xquik account has no cached profiles. Use
[Analyze & Cache Style](/api-reference/styles/analyze) to create one.

</section>

<section>

## Read each writing style summary

| Field          | Meaning                                                                        | Integration use                                      |
| -------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------- |
| `xUsername`    | Normalized X (Twitter) username for the cached profile                         | Build Get, Delete, Compare, or Performance requests. |
| `tweetCount`   | Number of tweet samples stored in this profile                                 | Show the sample size.                                |
| `isOwnAccount` | Whether the profile represents the authenticated user's X account              | Label owned and external profile samples.            |
| `fetchedAt`    | ISO <span className="nw">8601 time</span> when Xquik fetched the tweet samples | Decide whether to refresh the cache.                 |

Do not interpret `tweetCount` as the X profile's lifetime tweet total. It only
counts the tweet samples stored for this writing-style profile.

{"\n"}

`fetchedAt` records the cache fetch time. It is not a tweet publication time,
profile update time, or writing-style creation timestamp.

</section>

## Choose the next style request

Use the summary fields to choose the next endpoint.

| Goal                                                 | Next request                                             | Input from this response                             |
| ---------------------------------------------------- | -------------------------------------------------------- | ---------------------------------------------------- |
| Inspect sampled tweet text                           | [Get Style](/api-reference/styles/get)                   | Pass `xUsername` in `{id}`.                          |
| Refresh stale samples                                | [Analyze & Cache Style](/api-reference/styles/analyze)   | Send `xUsername` as `username`.                      |
| Compare <span className="nw">2 account</span> voices | [Compare Styles](/api-reference/styles/compare)          | Send <span className="nw">2 cached</span> usernames. |
| Refresh likes, replies, reposts, and views           | [Analyze Performance](/api-reference/styles/performance) | Pass `xUsername` in `{id}`.                          |
| Remove a cached profile                              | [Delete Style](/api-reference/styles/delete)             | Pass `xUsername` in `{id}`.                          |

The response pages by cursor. When `hasMore` is `true`, pass `nextCursor` as
`cursor` for the next page. Do not invent `page` or `total` fields.

</section>

<section>

## Handle list style errors

| Status | Meaning                             | Recovery                                   |
| ------ | ----------------------------------- | ------------------------------------------ |
| `200`  | The style summary list is available | Read `styles`, including an empty array.   |
| `401`  | Authentication failed               | Replace the missing or invalid credential. |
| `429`  | The request exceeded the rate limit | Wait for `Retry-After`, then retry once.   |

### Does list styles return the analyzed tweets?

No. This endpoint returns summaries only. Use [Get Style](/api-reference/styles/get)
to retrieve the stored tweet samples for one username.

### Why is the Twitter writing style list empty?

The authenticated Xquik account has no cached profiles. Analyze an X (Twitter) username
first. Then call this endpoint again with the same Xquik credentials.

</section>

## Headers

| Header      | Type     | Required | Description                                                                                                                                              |
| ----------- | -------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x-api-key` | `string` | Yes      | Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://dashboard.xquik.com/en/account?tab=api-keys). |

</section>

<section>

## Query parameters

| Query parameter | Type      | Required | Description                                                                                            |
| --------------- | --------- | -------- | ------------------------------------------------------------------------------------------------------ |
| `limit`         | `integer` | No       | Maximum items per page, from <span className="nw">1 to</span> 10,000. Default 200.                     |
| `cursor`        | `string`  | No       | `nextCursor` from the previous page. The `after` alias also works. Offset pagination is not supported. |

</section>

<section>

## Response

### 200 OK

| Field                   | Type       | Description                                                                   |
| ----------------------- | ---------- | ----------------------------------------------------------------------------- |
| `styles`                | `object[]` | Array of cached style summaries.                                              |
| `styles[].xUsername`    | `string`   | Normalized X (Twitter) username.                                              |
| `styles[].tweetCount`   | `number`   | Number of cached tweets.                                                      |
| `styles[].fetchedAt`    | `string`   | ISO <span className="nw">8601 timestamp</span> when Xquik fetched the tweets. |
| `styles[].isOwnAccount` | `boolean`  | Whether this is the authenticated user's own X account.                       |
| `hasMore`               | `boolean`  | Whether more rows follow this page.                                           |
| `nextCursor`            | `string`   | Pass it as `cursor` for the next page. Present when `hasMore` is `true`.      |

```json
{
  "styles": [
    {
      "xUsername": "elonmusk",
      "tweetCount": 20,
      "fetchedAt": "2026-02-24T10:30:00.000Z",
      "isOwnAccount": false
    },
    {
      "xUsername": "sama",
      "tweetCount": 18,
      "fetchedAt": "2026-02-25T14:00:00.000Z",
      "isOwnAccount": false
    }
  ],
  "hasMore": false
}
```
