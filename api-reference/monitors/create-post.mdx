Create a post monitor when 1 X post needs live tracking. It reports new
replies, new quotes, edits & deletion. It also tracks views, likes, retweets,
replies, quotes & bookmarks.

<Callout icon="coins" color="#5c3327">

**Requires 30 available credits.** Active post monitors bill 30 credits per hour.

</Callout>

<Note>

The hourly price covers stored events & webhook deliveries. Xquik charges an
hour only after a read that finds the post.

</Note>

## How do I track a tweet's engagement with an API?

Send the post link or ID as `post`. Xquik reads the post once & returns its
current metrics. Each metric starts with a gain of `0`.

Xquik then reads the post every 2 to 4 seconds. A metric event fires when a count
holds a new value. Each metric fires at most once a minute. The event covers
the whole change since the last one.

New replies & quotes come as their own events. Each one carries the reply or
quote as `data`, like `tweet.new`. Xquik sends them oldest first.

## What happens when the author edits or deletes the post?

X moves engagement to the newest version of an edited post. The monitor
follows that version, so metrics keep counting after an edit.

`post.edited` carries `previousText`, `text` & `versionId`. `post.deleted`
fires once 3 reads in a row confirm the deletion. It carries the last text
the monitor saw.

After 3 missed reads, Xquik pauses the monitor. `pausedReason` says why.
A paused monitor costs nothing.

## Headers

<ParamField header="x-api-key" type="string" required>

Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://dashboard.xquik.com/en/account?tab=api-keys).

</ParamField>

<ParamField header="Content-Type" type="string" required>

Must be `application/json`.

</ParamField>

## Body

<ParamField body="post" type="string" required>

Post link or ID, up to 2,048 characters. x.com, twitter.com, mobile &
`/i/web/status/` links work with any query string.

</ParamField>

<ParamField body="name" type="string | null">

Your own label for the monitor, 1 to 80 characters. Every event the monitor
produces carries it as `monitorName`. Xquik normalizes whitespace.

</ParamField>

<ParamField body="eventTypes" type="string[]">

Post event types to send, 1 to 10. Without it, the monitor sends
`post.reply.new`, `post.quote.new`, `post.likes.changed`,
`post.retweets.changed`, `post.edited` & `post.deleted`.

</ParamField>

## Valid event types

| Event type               | Fires when                             | `data`                                     |
| ------------------------ | -------------------------------------- | ------------------------------------------ |
| `post.reply.new`         | A new direct reply appears.            | The reply.                                 |
| `post.quote.new`         | A new quote of the post appears.       | The quote.                                 |
| `post.likes.changed`     | The like count holds a new value.      | `metric`, `previous`, `current`, `change`. |
| `post.retweets.changed`  | The retweet count holds a new value.   | `metric`, `previous`, `current`, `change`. |
| `post.replies.changed`   | The reply count holds a new value.     | `metric`, `previous`, `current`, `change`. |
| `post.quotes.changed`    | The quote count holds a new value.     | `metric`, `previous`, `current`, `change`. |
| `post.bookmarks.changed` | The bookmark count holds a new value.  | `metric`, `previous`, `current`, `change`. |
| `post.views.changed`     | The view count holds a new value.      | `metric`, `previous`, `current`, `change`. |
| `post.edited`            | The author edits the post.             | `previousText`, `text`, `versionId`.       |
| `post.deleted`           | 3 reads in a row confirm the deletion. | `text`, the last text the monitor saw.     |

The reply count can include replies X does not list. `post.reply.new`
reports the replies X lists.

### 400 Invalid input

`post` is missing or is not a post link or ID. The message says what to fix.

### 401 Unauthenticated

Missing or invalid API key.

### 402 Payment required

You need at least 30 available credits to create a post monitor.

### 404 Tweet not found

X shows no such post, so Xquik creates nothing. `reason` is `deleted`,
`author_suspended` or `protected` when X names it.

### 409 Duplicate

An active monitor already tracks this post. Use
[Update Post Monitor](/api-reference/monitors/update-post) to change it.

### 422 Post unavailable

The author limits who can see the post. Choose a public post.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.

### 502 X unavailable

X failed the read. Retry after a short wait.

### 503 Busy

Xquik is busy right now. Wait for `Retry-After`, then retry.
