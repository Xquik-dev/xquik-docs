## Cancel one extraction job

Send `DELETE /extractions/{id}` to stop a `pending` or `running` job. The job
ends as `canceled`. It saves no rows & uses no credits. A repeat request on a
canceled job answers `200`, so a retry is safe.

{"\n"}

Use the job ID from [Create Extraction](/api-reference/extractions/create) or
[List Extractions](/api-reference/extractions/twitter-scraping-job-history). An
API key needs the exports scope for this route.

<CodeGroup>

```bash cURL
curl --request DELETE \
  https://xquik.com/api/v1/extractions/aB3dE6gH9jK2 \
  --header "x-api-key: xq_YOUR_KEY_HERE"
```

```javascript Node.js
const jobId = "aB3dE6gH9jK2";
const response = await fetch(`https://xquik.com/api/v1/extractions/${jobId}`, {
  method: "DELETE",
  headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
});
const body = await response.json();

if (!response.ok) {
  throw new Error(`${response.status} ${body.error}: ${body.message}`);
}

console.log(`${body.id} is ${body.status}`);
```

```python Python
import requests

job_id = "aB3dE6gH9jK2"
response = requests.delete(
    f"https://xquik.com/api/v1/extractions/{job_id}",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
)
body = response.json()

if not response.ok:
    raise RuntimeError(f'{response.status_code} {body["error"]}: {body["message"]}')

print(f'{body["id"]} is {body["status"]}')
```

## Know when a job can stop

Only a `pending` or `running` job can stop. A finished job answers `409` with
its `status`. Its rows stay as they were.

{"\n"}

To keep the rows a job already found, let it finish. Then read them through
[Extraction results](/api-reference/extractions/twitter-extraction-results).

## Headers

| Header          | Type     | Required | Description                                                                                                 |
| --------------- | -------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| `x-api-key`     | `string` | No       | Your Xquik API key. Generate one from the [dashboard](https://dashboard.xquik.com/en/account?tab=api-keys). |
| `Authorization` | `string` | No       | An OAuth bearer token formatted as `Bearer YOUR_TOKEN`. Send this header or `x-api-key`, not both.          |

</section>

## Path parameters

| Path parameter | Type     | Required | Description                                                                                                                                                            |
| -------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string` | Yes      | Extraction job ID returned from [Create Extraction](/api-reference/extractions/create) or [List Extractions](/api-reference/extractions/twitter-scraping-job-history). |

## Response

<Tabs>

  <Tab title="200 Canceled">

    ```json
    { "id": "aB3dE6gH9jK2", "status": "canceled" }
    ```
    Xquik stopped the job. It saved no rows.

  </Tab>
  <Tab title="401 Unauthenticated">

    ```json
    { "error": "unauthenticated", "message": "Authentication required. Provide a valid API key or bearer token." }
    ```
    The API key or bearer token is missing or invalid.

  </Tab>
  <Tab title="403 Forbidden">

    ```json
    { "error": "insufficient_scope", "message": "This API key lacks the exports scope. Add it at dashboard.xquik.com/api-keys.", "requiredScope": "exports" }
    ```
    The API key lacks the exports scope, or it is paused.

  </Tab>
  <Tab title="404 Not found">

    ```json
    { "error": "not_found", "message": "Resource not found." }
    ```
    No job has this ID, or it belongs to another account.

  </Tab>
  <Tab title="409 Already ended">

    ```json
    { "error": "extraction_terminal", "message": "Extraction already finished. Check its status.", "status": "completed" }
    ```
    The job already finished. `status` names how it ended.

  </Tab>
  <Tab title="429 Rate limited">

    ```json
    { "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 60 }
    ```
    Wait for the `Retry-After` header, then retry once.

  </Tab>
</Tabs>
