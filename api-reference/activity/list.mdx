The rows match the dashboard's Activity log. Copy as cURL on that page gives this call with
its filters. A cut list ends with a `notice` row that says where it stopped.

<CodeGroup>

```bash cURL
curl "https://xquik.com/api/v1/activity?category=monitors&status=failed&limit=50" \
  -H "x-api-key: xq_YOUR_KEY_HERE" | jq
```

```javascript Node.js
const response = await fetch(
  "https://xquik.com/api/v1/activity?category=monitors&status=failed&limit=50",
  { headers: { "x-api-key": "xq_YOUR_KEY_HERE" } },
);
const rows = await response.json();
process.stdout.write(`${JSON.stringify(rows, null, 2)}\n`);
```

```python Python
import requests

response = requests.get(
    "https://xquik.com/api/v1/activity",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
    params={"category": "monitors", "status": "failed", "limit": 50},
)
rows = response.json()
print(rows)
```

```go Go
package main

import (
	"fmt"
	"io"
	"log"
	"net/http"
)

func main() {
	req, err := http.NewRequest("GET", "https://xquik.com/api/v1/activity?category=monitors&status=failed&limit=50", nil)
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("x-api-key", "xq_YOUR_KEY_HERE")
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()
	body, err := io.ReadAll(resp.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(body))
}
```

## Download the log as a file

Add `format` to get a file. The file comes in the same formats as every other Xquik export.

| `format`      | File                    |
| ------------- | ----------------------- |
| `json`        | JSON array, the default |
| `csv`         | CSV                     |
| `xlsx`        | Excel workbook          |
| `md`          | Markdown table          |
| `md-document` | Markdown document       |
| `pdf`         | PDF, up to 10,000 rows  |
| `txt`         | Plain text              |

</section>

## Headers

| Header      | Type     | Required | Description                                                                              |
| ----------- | -------- | -------- | ---------------------------------------------------------------------------------------- |
| `x-api-key` | `string` | Yes      | Your API key with full access. Generate one from the [API Keys page](https://xquik.com). |

</section>

<section>

## Query parameters

| Query parameter | Type     | Required | Description                                                                      |
| --------------- | -------- | -------- | -------------------------------------------------------------------------------- |
| `format`        | `string` | No       | Answer format. `json`, `csv`, `xlsx`, `md`, `md-document`, `pdf` or `txt`.       |
| `limit`         | `number` | No       | Most rows to return, from 1 to 100,000. PDF stops at 10,000 rows. Default `100`. |
| `category`      | `string` | No       | `all`, `actions`, `extractions`, `monitors`, `webhooks` or `billing`.            |
| `status`        | `string` | No       | Comma-separated statuses, such as `failed,running`.                              |
| `q`             | `string` | No       | Search text, up to 200 characters.                                               |
| `since`         | `string` | No       | Oldest time, ISO 8601.                                                           |
| `until`         | `string` | No       | Newest time, ISO 8601.                                                           |

</section>

<section>

## Response

### 200 OK

An array of rows, newest first. Each row has these fields.

| Field      | Type               | Description                                                                              |
| ---------- | ------------------ | ---------------------------------------------------------------------------------------- |
| `time`     | `string`           | ISO 8601 time in UTC to the millisecond. Empty on the notice row.                        |
| `category` | `string`           | Kind of activity, such as `write_action`, `monitor_event` or `webhook_delivery`.         |
| `type`     | `string`           | Type within the category, such as `like` or `pause`.                                     |
| `activity` | `string`           | The row's title, as the Activity log shows it.                                           |
| `status`   | `string`           | `completed`, `running`, `failed` or `canceled`.                                          |
| `source`   | `string`           | The account, monitor or key the activity came from.                                      |
| `target`   | `string`           | The post or account it acted on.                                                         |
| `results`  | `number \| string` | Results, for extractions and giveaways.                                                  |
| `credits`  | `number \| string` | Credits charged, or added for billing rows.                                              |
| `details`  | `string`           | Extra detail, such as a result ID or an HTTP status.                                     |
| `id`       | `string`           | Activity ID. Pass it to [Get activity](/api-reference/activity/get) for the full record. |
| `link`     | `string`           | Link to the post or profile on X.                                                        |

### 400 Invalid input

A query parameter has the wrong format. Check the values above.

### 401 Unauthenticated

Missing or invalid API key. Check the `x-api-key` header value.

### 403 Forbidden

A read-only or scoped key cannot read activity. Use a key with full access.

### 429 Rate limited

`{"error":"rate_limit_exceeded","message":"Too many requests. Try again later.","retryAfter":1}`

Too many requests. Wait for the `Retry-After` header before retrying.
