`GET https://xquik.com/api/v1/activity/{id}`

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

Every activity keeps a full record you can fetch. Take the ID from the activity page URL in the
dashboard. Or take it from a row of [List activity](/api-reference/activity/list). Copy as cURL
on that page gives the same call. An API key's own record answers only a signed-in dashboard
session.

<CodeGroup>

```bash cURL
curl https://xquik.com/api/v1/activity/naF3xqHLWDTs \
  -H "x-api-key: xq_YOUR_KEY_HERE" | jq
```

```javascript Node.js
const response = await fetch("https://xquik.com/api/v1/activity/naF3xqHLWDTs", {
  headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
});
const activity = await response.json();
process.stdout.write(`${JSON.stringify(activity, null, 2)}\n`);
```

```python Python
import requests

response = requests.get(
    "https://xquik.com/api/v1/activity/naF3xqHLWDTs",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
)
activity = response.json()
print(activity)
```

```go Go
package main

import (
	"fmt"
	"io"
	"log"
	"net/http"
)

func main() {
	req, err := http.NewRequest("GET", "https://xquik.com/api/v1/activity/naF3xqHLWDTs", nil)
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("x-api-key", "xq_YOUR_KEY_HERE")
	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()
	body, err := io.ReadAll(resp.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(body))
}
```

## Debug an activity

| Question                           | Field                                 |
| ---------------------------------- | ------------------------------------- |
| Which call made this change?       | `request.method`, `request.path`      |
| Did the call succeed?              | `request.httpStatus`                  |
| How long did the call take?        | `request.durationMs`                  |
| Which key or app made it?          | `caller.apiKey`, `caller.oauthClient` |
| How many credits did it use?       | `charge.credits`                      |
| What happened to the same subject? | `related`                             |

Send the record to your support ticket or AI assistant as is. It never holds an API key
value. An OAuth app gets it without your IP address and user agent.

</section>

## Response

### 200 OK

| Field        | Type             | Description                                                                                                                                                                                                                                                                                     |
| ------------ | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `object`     | `string`         | Always `activity`.                                                                                                                                                                                                                                                                              |
| `id`         | `string`         | Activity ID.                                                                                                                                                                                                                                                                                    |
| `kind`       | `string`         | `write_action`, `extraction`, `monitor_change`, `api_key`, `billing`, `giveaway_draw`, `monitor_event`, `media_download`, `media_share`, `support_ticket`, `webhook_delivery`, `webhook_endpoint` or `x_account_connection`.                                                                    |
| `type`       | `string`         | Type within the kind, the same as its Activity log row, such as `pause`.                                                                                                                                                                                                                        |
| `status`     | `string`         | `completed`, `running`, `failed` or `canceled`.                                                                                                                                                                                                                                                 |
| `url`        | `string`         | Dashboard page of this activity.                                                                                                                                                                                                                                                                |
| `requestId`  | `string \| null` | ID of the API request behind this activity.                                                                                                                                                                                                                                                     |
| `timestamps` | `object`         | Every time of this activity, ISO 8601 in UTC to the millisecond. `createdAt` is always present. Other times appear when the activity has them. Examples are `updatedAt`, `completedAt`, `confirmedAt`, `expiresAt`, `occurredAt`, `discoveredAt`, `deliveredAt`, `nextRetryAt` or `lastUsedAt`. |
| `request`    | `object \| null` | The API request behind this activity. It holds `method`, `path`, `httpStatus`, `durationMs`, `ipAddress`, `userAgent` and `at`. Null for activity from before Oct 30, 2026. Also null for activity no API request made. Examples are a monitor event or a webhook delivery.                     |
| `caller`     | `object`         | Who made the change. `authMethod` is `api_key`, `oauth` or `session`. `apiKey` holds the key's `name` and `prefix`. `oauthClient` holds the app's `id` and `name`.                                                                                                                              |
| `charge`     | `object \| null` | Credits charged, with `credits`, `balanceAfter` and `at`. Null when the activity charged nothing.                                                                                                                                                                                               |
| `details`    | `object`         | Fields of this kind of activity. They can hold the target, the search query or the monitor. They can also hold the event data or the webhook payload.                                                                                                                                           |
| `related`    | `object[]`       | Up to 5 other activities on the same subject within 7 days, newest first. Each has `id`, `type`, `status`, `createdAt` and `url`.                                                                                                                                                               |

### 400 Invalid input

The activity ID has the wrong format. Copy it from the activity page URL.

### 401 Unauthenticated

Missing or invalid API key. Check the `x-api-key` header value.

### 403 Forbidden

A read-only or scoped key cannot read activity. Use a key with full access.

### 404 Not found

No activity exists with this ID, or it belongs to a different account.

### 429 Rate limited

`{ "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 1 }`

Too many requests. Wait for the `Retry-After` header before retrying.
