```text
POST https://xquik.com/api/v1/draws
```

Use this Twitter giveaway picker API to select primary and backup winners. Filter replies by reposts, follows, keywords, hashtags, mentions, or language. Add account-age, follower-count, or unique-author rules.

<Callout icon="coins" color="#5c3327">

**Metered draw execution** · source lookup, replies, optional retweeters, and optional follow checks consume credits

</Callout>

<Note>

Xquik reads every direct reply and retweeter X shows. It stops at what your remaining credits cover. `totalEntries` and `validEntries` count the inspected direct replies. X hides some replies, so the post can report more. A draw on a busy post takes about 1 minute. To allow for that, keep the request open for 100 seconds. Xquik runs & charges follow checks only for authors who pass your other filters.

</Note>

```go Go
package main

import (
	"bytes"
	"crypto/rand"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
)

func main() {
	payload := map[string]interface{}{
		"tweetUrl":           "https://x.com/NASA/status/2102882545427714266",
		"winnerCount":        3,
		"backupCount":        2,
		"mustRetweet":        true,
		"filterMinFollowers": 10,
		"requiredKeywords":   []string{"giveaway"},
	}
	body, err := json.Marshal(payload)
	if err != nil {
		log.Fatal(err)
	}

	req, err := http.NewRequest("POST", "https://xquik.com/api/v1/draws", bytes.NewReader(body))
	if err != nil {
		log.Fatal(err)
	}
	req.Header.Set("x-api-key", "xq_YOUR_KEY_HERE")
	req.Header.Set("Idempotency-Key", rand.Text())
	req.Header.Set("Content-Type", "application/json")

	resp, err := http.DefaultClient.Do(req)
	if err != nil {
		log.Fatal(err)
	}
	defer resp.Body.Close()

	respBody, err := io.ReadAll(resp.Body)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println(string(respBody))
}
```

| Giveaway draw column | Request or response source | Audit rule                                |
| -------------------- | -------------------------- | ----------------------------------------- |
| Draw ID              | Response `id`              | Use this public ID for review and export. |
| Source tweet         | Response `tweetId`         | Keep the giveaway tweet identifier.       |
| Inspected entries    | Response `totalEntries`    | Record how many replies Xquik inspected.  |
| Eligible entries     | Response `validEntries`    | Compare this count with every filter.     |
| Winner order         | `winners[].position`       | Keep the original selection order.        |
| Winner username      | `winners[].authorUsername` | Store the selected X account.             |
| Winning reply        | `winners[].tweetId`        | Retain the qualifying reply identifier.   |
| Backup state         | `winners[].isBackup`       | Separate primary and backup winners.      |

<section>

## Headers

| Header            | Type     | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `x-api-key`       | `string` | Yes      | Your API key. Session cookie authentication is also supported.                                                                                                                                                                                                                                                                                                                                                     |
| `Content-Type`    | `string` | Yes      | Must be `application/json`.                                                                                                                                                                                                                                                                                                                                                                                        |
| `Idempotency-Key` | `string` | No       | Use <span className="nw">1-255</span> visible ASCII characters. Generate one unique value for each draw. Reuse it only for an exact retry. A retry returns the original draw and charges nothing. A retry while the first request runs returns `409 idempotency_in_progress`. A draw that fails frees its key for a retry. If the first request stops, the key frees after <span className="nw">10 minutes</span>. |

</section>

<section>

## Body

| Body parameter         | Type       | Required | Description                                                                                                                                                                                                            |
| ---------------------- | ---------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tweetUrl`             | `string`   | Yes      | Full tweet URL to run the draw on. Accepts `x.com` and `twitter.com` formats (for example `https://x.com/user/status/1893456789012345678`).                                                                            |
| `winnerCount`          | `number`   | No       | Number of winners to draw. Defaults to <span className="nw">`1` if</span> omitted.                                                                                                                                     |
| `backupCount`          | `number`   | No       | Number of backup winners to draw. Xquik selects backup winners in case you disqualify primary winners.                                                                                                                 |
| `uniqueAuthorsOnly`    | `boolean`  | No       | When `true`, each author can win once, however many replies they posted.                                                                                                                                               |
| `mustRetweet`          | `boolean`  | No       | When `true`, only entries from users who retweeted the original tweet are eligible.                                                                                                                                    |
| `mustFollowUsername`   | `string`   | No       | X (Twitter) username that entrants must follow to be eligible. That account's numeric user ID also works. Xquik strips the `@` prefix if included. A number is a user ID, up to <span className="nw">19 digits</span>. |
| `filterMinFollowers`   | `number`   | No       | Minimum follower count required for eligible entries.                                                                                                                                                                  |
| `filterAccountAgeDays` | `number`   | No       | Minimum account age in days. The draw excludes accounts younger than this.                                                                                                                                             |
| `filterLanguage`       | `string`   | No       | Filter entries by tweet language code (for example `en`, `tr`, `es`).                                                                                                                                                  |
| `requiredKeywords`     | `string[]` | No       | Array of keywords that must appear in the reply text. The draw excludes entries missing any keyword.                                                                                                                   |
| `requiredHashtags`     | `string[]` | No       | Array of hashtags that must appear in the reply text. Include the `#` prefix.                                                                                                                                          |
| `requiredMentions`     | `string[]` | No       | Array of usernames that the reply text must mention. Include the `@` prefix.                                                                                                                                           |

</section>

## Response

### 201 Created

An exact retry returns the original draw with `Idempotency-Replayed: `<span className="cn"><wbr />`true`</span>.

| Field                      | Type      | Description                                                                                   |
| -------------------------- | --------- | --------------------------------------------------------------------------------------------- |
| `id`                       | `string`  | Draw public ID returned by Xquik.                                                             |
| `tweetId`                  | `string`  | X tweet ID extracted from the URL.                                                            |
| `totalEntries`             | `number`  | Entries inspected after the credit cap, which can be fewer than the post's replies.           |
| `validEntries`             | `number`  | Inspected entries that passed every filter. A credit cap can leave valid replies uninspected. |
| `winners`                  | `array`   | Selected winners and backup winners.                                                          |
| `winners[].position`       | `number`  | Winner position (<span className="nw">1-indexed</span>).                                      |
| `winners[].authorUsername` | `string`  | X (Twitter) username of the winner.                                                           |
| `winners[].tweetId`        | `string`  | Tweet ID of the winning reply.                                                                |
| `winners[].isBackup`       | `boolean` | `true` if this is a backup winner.                                                            |

### 400 Invalid input

`{ `<span className="cn"><wbr />`"error": "invalid_input", "message": "Missing or malformed request body" }`</span>

{"\n"}

Missing or malformed request body. Send `tweetUrl` as a string.

### 400 Invalid tweet URL

`{ `<span className="cn"><wbr />`"error": "invalid_tweet_url", "message": "Invalid tweet URL format" }`</span>

{"\n"}

Xquik could not parse the `tweetUrl`. Must be a valid `x.com` or `twitter.com` status URL.

### 400 Invalid idempotency key

`{ "error": "invalid_`<span className="cn"><wbr />`idempotency_`<wbr />`key", "message": `<wbr /><span className="nw">`"Idempotency-Key `</span><wbr />`invalid. Use `<wbr /><span className="nw">`1-255 `</span><wbr />`visible ASCII characters." }`</span>

{"\n"}

The `Idempotency-Key` header is empty, longer than 255 characters, or not visible ASCII.

### 401 Unauthenticated

`{ `<span className="cn"><wbr />`"error": "unauthenticated", "message": "Missing or invalid API key" }`</span>

{"\n"}

Missing or invalid API key / session cookie.

### 402 Insufficient credits

`{ "error": "insufficient_`<span className="cn"><wbr />`credits", "message": "Insufficient credits. Top up or subscribe to continue." }`</span>

{"\n"}

The available balance cannot cover the minimum draw cost. A later final deduction failure also returns `insufficient_credits`. Xquik stores no draw result and charges nothing after that failure. Check your [credit balance](/api-reference/account/get).

### 404 Not found

`{ `<span className="cn"><wbr />`"error": "tweet_not_found", "message": "Tweet not found" }`</span>

{"\n"}

The target tweet does not exist, was deleted, or the ID is invalid.

### 409 Idempotency conflict

Reuse a key only for the same request. Exact retries return the original draw. Xquik reads nothing and charges nothing for this request.

### 409 Idempotency in progress

`{ "error": "idempotency_in_`<span className="cn"><wbr />`progress", "message": `<wbr /><span className="nw">`"Idempotency-Key `</span><wbr />`belongs to a running request. Retry later." }`</span>

{"\n"}

The first request with this key is still running. Retry with the same key after it finishes. Xquik charges nothing for this request.

### 424 Short read

`{ "error": "draw_too_large", "message": "The post has more replies than `<span className="cn"><wbr /><span className="nw">`1 draw `</span><wbr />`reads. Contact support." }`</span>

{"\n"}

X failed or stopped early. Retry after `replies_incomplete` or `retweeters_`<span className="cn"><wbr />`incomplete`</span>. `draw_too_large` means the post has more entries than 1 draw reads. Contact support. Xquik saves & charges nothing.

### 424 X API dependency failed

`{ `<span className="cn"><wbr />`"error": { "type": "dependency_error", "code": "x_api_unavailable", "message": "X data source temporarily unavailable" } }`</span>

{"\n"}

Send `xquik-api-contract: `<span className="cn"><wbr /><span className="nw">`2026-04-29`</span></span> to receive this status for dependency failures that return `502` by default.

### 429 Rate limited

`{ "error": "rate_`<span className="cn"><wbr />`limit_`<wbr />`exceeded", "message": "Too many requests. Try again later.", "retryAfter": `<wbr /><span className="nw">`1 }`</span></span>

{"\n"}

Too many requests. Wait for the `Retry-After` header before retrying.

### 502 X API unavailable

`{ `<span className="cn"><wbr />`"error": "x_api_unavailable", "message": "X data source temporarily unavailable" }`</span>

{"\n"}

The read service returned an error. Retry after a short delay.
