Each line below is something you get from Xquik.
Each line applies to 1 or more of the REST API, MCP, Apify Actors & monitors.
You pay only for delivered, unique, matching rows.

## Complete results

- Searches return posts that X's own search tab leaves out.
- Large date ranges come back whole & fast.
- Searches return every match, whatever operators you combine.
- Account searches include all of the account's posts & reposts.
- Account history comes back complete, old posts included.
- Threads include every post & the author's own replies.
- Profile exports keep every post of the author's own threads.
- Profile reads include the pinned post, flagged as pinned.
- List timelines include posts that X's List page leaves out.
- Follower & following exports return full lists.
- Verified follower exports return full lists too.
- Reply exports include replies that X's post page leaves out.
- Reply exports work from any post ID or link.
- Complete mode adds replies the author hid & explains empty threads.
- Similar-account lists come back fuller.
- Top tweet lists come back reliably.
- Filtered pages come back full until the results run out.
- Every page size returns the same complete results.
- Timelines page all the way to the last post.
- Batch post lookups miss fewer posts.
- Account location labels fill in on more rows, at no extra charge.
- Each answer holds the fullest data X has for it.

## Accurate rows

- Search results hold every post that matches your query & nothing else.
- Word & phrase matching works in every language & script.
- Language filters work for every language X tags.
- Language, date & engagement filters hold on every row you get.
- A post is called missing only when it's gone.
- "X can't run this search" appears only when it's true.
- Protected accounts & private Lists get a clear answer, not an empty page.
- Reposts carry the full original text.
- Every ID in a row stays exact.
- Mentions, links, hashtags & highlights line up with the text.
- Counts X didn't send are listed in `unknownCounts`, never shown as 0.
- Verified badges match what x.com shows.
- Rows hold public data only.
- Quote searches return every real quote & nothing else.
- Reply exports hold only direct replies, in a proven order.
- Newest-first results come back in date order.
- Messy queries still run instead of failing.
- Place searches work with names in 6 languages.
- Searches X can't run fail at once, with the fix.
- A date means one thing in any common form.
- Searches accept `since_id` & `max_id` bounds.
- Ads & promoted entries never reach your rows.
- Monitors report only real deletions & unfollows.
- Profile change alerts don't flap.

## Fresh data

- Account monitors see changes within about a second.
- Keyword monitors catch every matching post.
- Monitors don't miss posts between checks.
- A monitor that falls behind catches up on what it missed.
- Live videos & Spaces raise an event when they start.
- Post monitors report changes to likes, views & other counts.
- Trends can be read for any past moment since the archive began.
- Reads keep working when X ships changes.

## Speed

- A slow X answer doesn't hold up your request.
- Repeated lookups answer at once.
- Searches stay fast on busy topics.
- Each next page arrives fast.
- Actors read many handles, posts & queries at once.
- Reads finish the moment their rows arrive.
- Stalled Actor calls recover on their own.
- Webhooks arrive without connection setup delay.

## Fair billing

- You pay only for the rows you get, after filters & duplicate removal.
- Every answer states its charge in `X-Xquik-Credits-Charged`.
- A retried page is free.
- A low balance trims results instead of failing.
- Bad input costs nothing, since it's refused before any read.
- AI analysis bills only the posts it analyzed.
- Monitors have 1 flat hourly price, events & webhooks included.
- Monitor Actors bill only the hours a monitor watched.
- Writes cost nothing until they land.
- Saving the same media again is free.
- Removed media isn't billed, & `media_unavailable` gives the reason.
- Empty trend history steps are free.
- You can price a bulk job before you run it.
- A post ID listed twice in a batch is billed once.
- Actors charge only for delivered, unique, matching rows.
- A profile shared by several targets is billed once.
- A restarted run never charges twice.
- A spend cap becomes a row cap, & diagnostics still get written.
- Each run shows what it cost in its run report.
- Small runs end with a tip that cuts cost.
- AI Actors don't bill failed or skipped analyses.
- Each refund points at the exact charge it reverses.

## Reliability

- A one-off X failure doesn't fail your request.
- Paging stays consistent from one page to the next.
- Paging never loops forever.
- A deadline returns the rows already found, with diagnostics.
- Overload is announced with 503, `Retry-After` & a reason.
- `X-Xquik-Cause` tells X's outages apart from Xquik's.
- Actors ride out short Xquik outages.
- Actor runs survive restarts without repeats.
- One bad row doesn't sink a batch.
- Stopped runs keep their rows & their report.
- A run that can't start still explains itself.
- `stopCauses`, `failedSubtargets` & `unavailableTargets` spell out partial failures.
- Webhooks are signed & replay-safe.
- Webhook deliveries retry until they land, for up to 7 days.
- New events don't queue behind old retries.
- Webhooks never go to private or local hosts.
- Missed events can be replayed from `Last-Event-ID`.
- Chat alerts arrive in order without hitting rate limits.
- A write reports success only once it's live on X.
- Writes don't post twice.
- Posting paces itself to protect your linked X accounts.
- Replies land on the right post.
- Retrying a write is safe with an idempotency key.
- Problems on X's side are fixed before they reach your reads.
- Asking again for a page in progress answers 409 with `Retry-After`.
- Support can see exactly what a request or run returned.

## Built for agents

- Agents reach the whole API through a few MCP tools.
- Paid results are saved under a `result_id`, so failed scripts never pay twice.
- Large answers fit the agent's context, capped at 24,000 characters.
- Clients can run reads without prompts & confirm writes.
- 1 stable shape with snake_case, Unix seconds, `has_more` & `next_cursor`.
- Sign-in works in modern MCP clients with OAuth 2.1 & PKCE.
- `whoami` returns an account ID that never changes.
- Agents can pay per call without an account.
- Tool input errors say what to change.
- MCP shows why a post or search failed.
- Pick only the fields you need with `fields` & `omit`.
- Actors accept input written for other Actors.
- Output is ready for spreadsheets, with flat columns & engagement totals.
- Datasets describe each field with a title, a description & an example.
- Every run says why it ended & whether to retry.
- Agents can find Xquik on their own through llms.txt & an agent card.
- Give each agent a key that calls only the routes you pick.
- Rate limits & deprecations come as machine-readable headers.
- Common names for cursor, limit, sort & type just work.
- Cursors fit in a URL & last 90 days.

## Rich data

- Post rows carry note text, edits, Community Notes, reach labels & reply controls.
- Rows carry source apps, media counts & professional account data.
- Cashtag searches add X's ticker card in `searchContext`.
- Media comes with variants, alt text, sizes & availability reasons.
- Video subtitles come with timed cues.
- You see when each account reposted a post.
- You see whether each account replied to, reposted or quoted a post, follows its author or belongs to a Community.
- Posts & bios can be translated into your language.
- Short links resolve, & list rows can carry full profiles.
- Profiles yield emails, phones & links tagged by network.
- Account location comes with country code, accuracy note & username history.
- Account checks say if each account is active, protected, suspended or missing.
- Trends by place name, country or region ID, promoted trends marked.
- Football games, plays, box scores, rosters, player props & game posts.
- Community Notes contributors & notes, Space replays & job listings as Markdown.
- AI answers carry probabilities, confidence & a question version.
- Changes across analysis runs don't flip on noise.
- `viralAlgorithmScore` turns a post's public counts into 1 comparable number.
- Each snapshot row holds every count's change since an earlier run.
- Giveaway draws pick winners with cryptographic randomness.

## Quality checks

- Every field X shows is served, left out on purpose or proven absent.
- Every read is checked live each hour.
- Actor READMEs, schemas & real output name the same fields.
- Docs match the API spec, & every Actor input has a proof run.
