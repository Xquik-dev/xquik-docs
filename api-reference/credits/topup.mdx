## When to use hosted checkout

Use this route when the buyer needs a hosted checkout. Use quick top-up for a saved payment method. Use top-up status only to poll an existing checkout session. Store the `session_id` from the returned URL before redirecting the user. The status route needs it.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

Ask the user to confirm the dollar amount before calling this endpoint. The response returns a hosted checkout URL. The call does not complete payment or add credits.

<CodeGroup>

```bash cURL
curl -X POST https://xquik.com/api/v1/credits/topup \
  -H "x-api-key: xq_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"dollars": 10}' | jq
```

## Headers

| Header         | Type     | Required | Description                                                    |
| -------------- | -------- | -------- | -------------------------------------------------------------- |
| `x-api-key`    | `string` | Yes      | Your API key. Session cookie authentication is also supported. |
| `Content-Type` | `string` | Yes      | Must be `application/json`.                                    |

## Body

| Body parameter | Type     | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------- | -------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `dollars`      | `number` | Yes      | Amount in US dollars to top up. Minimum $10.                                                                                                                                                                                                                                                                                                                                                                                                           |
| `currency`     | `string` | No       | Currency to pay in. Xquik converts the dollar amount at the latest daily ECB rate. The credits always match the dollar amount. Use <span className="nw">1 of</span> `USD`, `EUR`, `GBP`, `TRY`, `JPY`, `CNY`, `KRW`, `CAD`, `AUD` or `MXN`. Lowercase codes work too.<br />With rates over <span className="nw">3 ECB</span> working days old, Checkout charges USD instead. It shows the USD charge before payment, and `chargedCurrency` says `USD`. |
| `locale`       | `string` | No       | Optional checkout locale. Defaults to `en`.                                                                                                                                                                                                                                                                                                                                                                                                            |
| `returnPath`   | `string` | No       | Optional Xquik tool page to return to after Checkout, such as `/en/x-article-reader`. Without it, Checkout returns to the billing page.                                                                                                                                                                                                                                                                                                                |

</section>

## Response

### 200 OK

| Field               | Type      | Description                                                                                                                                                                                                               |
| ------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `url`               | `string`  | Stable Xquik redirect URL for the active hosted checkout session. Open it in a browser.<br />`GET /credits/topup/redirect` redirects with `303`. The target is the payment page, or the account page after checkout ends. |
| `redirect_url`      | `string`  | Same stable redirect URL in snake_case.                                                                                                                                                                                   |
| `chargedCurrency`   | `string`  | Currency the checkout charges, such as `EUR`.                                                                                                                                                                             |
| `chargedMinorUnits` | `integer` | Amount the checkout charges before tax, in the currency's smallest unit. JPY and KRW have no decimals, so <span className="nw">1580 JPY</span> is ¥1,580.                                                                 |

```json
{
  "url": "https://xquik.com/api/v1/credits/topup/redirect?session_id=checkout_session_id",
  "redirect_url": "https://xquik.com/api/v1/credits/topup/redirect?session_id=checkout_session_id",
  "chargedCurrency": "EUR",
  "chargedMinorUnits": 892
}
```

### 400 Invalid input

<span className="cn">`{ "error": "invalid_input", "message": "Minimum `<wbr /><span className="nw">`top-up `</span><wbr />`is $10" }`</span>

{"\n"}

Xquik opens no checkout. The `message` names the field to fix.

- `dollars` is missing, below USD <span className="nw">10 or</span> not a whole number.
- `currency` is not <span className="nw">1 of</span> the <span className="nw">10 codes</span>.
- `returnPath` is not an Xquik tool page.

### 401 Unauthenticated

Missing or invalid API key.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.
