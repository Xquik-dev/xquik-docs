## Add API credits with a saved payment method

Use quick top-up after the dashboard confirms an amount from USD 10 through 500. This route requires a same-origin Xquik session. External integrations
must use the [hosted top-up endpoint](/api-reference/credits/topup).

{"\n"}

Read `outcome` before handling any other response field. `charged` means the
credits and new balance are ready. `requires_action` means the client must
complete payment authentication. `declined` means the saved method failed.
`no_payment_method` means the account has no reusable payment method.

{"\n"}

Never print or store `clientSecret`. Pass it directly to the payment
confirmation flow. Log only the outcome, added credits, and resulting balance
after a successful charge.

{"\n"}

Quick top-up differs from standard checkout status. The status route polls a
hosted checkout session by `session_id`. This route returns its own immediate
payment outcome for the saved payment method.

<Callout icon="circle-check" color="#16a34a">

**Free.** This endpoint does not consume credits.

</Callout>

<CodeGroup>

```javascript Dashboard browser
const response = await fetch("/api/v1/credits/quick-topup", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ dollars: 25 }),
});
const result = await response.json();

if (result.outcome === "charged") {
  window.location.reload();
} else if (result.outcome === "requires_action") {
  await confirmSavedPayment(result.clientSecret);
} else {
  window.location.assign("/account/subscription");
}
```

</CodeGroup>

## Body

| Body parameter      | Type      | Required | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------- | --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dollars`           | `number`  | Yes      | <span className="nw">Top-up</span> amount in US dollars, which sets the credits. Minimum USD 10, maximum USD 500.                                                                                                                                                                                                                                                                                                                                                                              |
| `currency`          | `string`  | No       | Currency the saved card pays in. Xquik converts the dollar amount at the latest daily ECB rate. The credits always match the dollar amount. Use <span className="nw">1 of</span> `USD`, `EUR`, `GBP`, `TRY`, `JPY`, `CNY`, `KRW`, `CAD`, `AUD` or `MXN`. Lowercase codes work too.<br />With rates over <span className="nw">3 ECB</span> working days old, Xquik charges nothing in other currencies. It answers <span className="nw">409 `price_changed`</span> with the USD charge instead. |
| `chargedMinorUnits` | `integer` | No       | The charge you showed the payer, in the currency's smallest unit. Send <span className="nw">`2231` for</span> EUR <span className="nw">22.31 or</span> <span className="nw">`1580` for</span> JPY 1,580. If the charge differs, Xquik charges nothing. It answers <span className="nw">409 `price_changed`</span> with the new charge. Leave it out to pay the current charge.                                                                                                                 |

At USD 0.00015 per credit, a USD 25 quick top-up adds 166,666 credits. Xquik rounds down to whole credits.

{"\n"}

Only `charged` grants credits. Complete `requires_action` with `clientSecret`.
Use hosted checkout for `declined` or `no_payment_method`.

## Response

### 200 Charged

The payment succeeded. Xquik added the credits to your balance.

| Field               | Type      | Description                                                                      |
| ------------------- | --------- | -------------------------------------------------------------------------------- |
| `outcome`           | `string`  | Always `"charged"`.                                                              |
| `balance`           | `string`  | Updated credit balance after <span className="nw">top-up</span> (Bigint string). |
| `credits`           | `string`  | Number of credits added (Bigint string).                                         |
| `chargedCurrency`   | `string`  | Currency the saved card paid in, such as `EUR`.                                  |
| `chargedMinorUnits` | `integer` | Amount charged in the currency's smallest unit. JPY and KRW have no decimals.    |

```json
{
  "outcome": "charged",
  "balance": "466666",
  "credits": "166666",
  "chargedCurrency": "EUR",
  "chargedMinorUnits": 2231
}
```

### 200 Requires action

Payment requires more authentication, such as 3D Secure. Use the returned client secret with the billing confirmation flow to complete the payment.

| Field          | Type     | Description                                       |
| -------------- | -------- | ------------------------------------------------- |
| `outcome`      | `string` | Always `"requires_action"`.                       |
| `clientSecret` | `string` | Payment client secret for completing the payment. |

```json
{
  "outcome": "requires_action",
  "clientSecret": "pi_3abc...secret_xyz"
}
```

### 200 No payment method

The account has no saved payment method. Redirect the user to add one in the billing portal. Or use the standard [top-up endpoint](/api-reference/credits/topup) instead.

| Field     | Type     | Description                   |
| --------- | -------- | ----------------------------- |
| `outcome` | `string` | Always `"no_payment_method"`. |

```json
{
  "outcome": "no_payment_method"
}
```

### 200 Declined

The saved method failed. Open hosted checkout so the user can choose another.

| Field     | Type     | Description          |
| --------- | -------- | -------------------- |
| `outcome` | `string` | Always `"declined"`. |

```json
{
  "outcome": "declined"
}
```

### 400 Invalid input

<span className="cn">`{ "error": "invalid_input", "message": "Maximum quick `<wbr /><span className="nw">`top-up `</span><wbr />`is $500" }`</span>

{"\n"}

Xquik charges nothing. The `message` names the field to fix.

- `dollars` is missing, below USD 10, above USD <span className="nw">500 or</span> has over <span className="nw">2 decimals</span>.
- `currency` is not <span className="nw">1 of</span> the <span className="nw">10 codes</span>.
- `chargedMinorUnits` is not a positive whole number.

### 401 Unauthenticated

Missing or expired dashboard session. This route does not accept API keys.

### 409 Conflict

Xquik charged nothing for this request.

{"\n"}

<span className="cn">`{ "error": "price_changed", "message": "The price changed. Resend with this chargedCurrency & chargedMinorUnits to pay.", "chargedCurrency": "USD", "chargedMinorUnits": 2500 }`</span>

{"\n"}

`price_changed` means the charge differs from the one you sent. Show the payer the new charge. To pay it, resend with `currency` set to `chargedCurrency` and the new `chargedMinorUnits`.

| Field               | Type      | Description                                                     |
| ------------------- | --------- | --------------------------------------------------------------- |
| `chargedCurrency`   | `string`  | Currency Xquik would charge now, such as `USD`.                 |
| `chargedMinorUnits` | `integer` | Amount Xquik would charge now, in the currency's smallest unit. |

`idempotency_conflict` means an `Idempotency-Key` came back with another amount or currency. Send a new key to buy again.

{"\n"}

`topup_in_progress` means another top-up for this account is still running. Check your balance before you try again.

### 429 Rate limited

Too many requests. Wait for the `Retry-After` header before retrying.
