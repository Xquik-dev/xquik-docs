## Why you can't create a community on Twitter

X stopped accepting new Communities in April 2026. `POST /x/communities` answers
`422 x_community_creation_closed`. Xquik charges nothing.

Existing Communities still work. Use
[Join Community](/api-reference/x-write/join-community) to enter one and
[Community Info](/api-reference/x/community-info) to read one.

This route does not add rules, members,
moderators, invitations, posts, analytics, or membership settings.

## Community creation questions

### Do X communities still exist?

Yes. Existing Communities still work, and people post in them every day. X
stopped accepting new ones in April 2026.

### Do you need X Premium to create a community?

Premium doesn't help. X refuses new Communities, so an account upgrade doesn't
fix `x_community_creation_closed`.

### Can the API add rules, members, or moderators?

No. The request accepts `account`, `name`, and `description`. Never send
undocumented fields.

### How should software handle community creation?

Treat `422 x_community_creation_closed` as final, and don't retry it. Send people
to an existing Community, an XChat group link or an X List.

</section>

<section>

## Handle creation failures

`422 x_community_creation_closed` means X isn't accepting new Communities. Don't
retry it or add credits for it. Xquik charges nothing.

A `409` means the key already identifies another request. Compare both request
bodies. Reuse the key only when every input matches.

After `503`, check the write lifecycle before you retry. A disconnected client
doesn't prove failure.

</section>
