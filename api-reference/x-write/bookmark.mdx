Each request bookmarks 1 tweet by ID.

Create a unique `Idempotency-Key` for the intended bookmark.

## Bookmark one tweet by ID

Put the exact Tweet ID in the request path.
Put the connected account username or ID in the body.
That account saves the bookmark.

Copy Tweet IDs as strings.
JavaScript numbers cannot represent every X identifier exactly.
This endpoint accepts 1 Tweet ID per request.

## Keep bookmarks private to the acting account

X shows a bookmark only to the account that saved it.
The post's author sees a bookmark count, never who saved it.
Bookmarking never notifies the author or adds a like.

Read the saved posts with [Bookmarks](/api-reference/x/bookmarks).

## Save a bookmark receipt

Save the action first. Then update your reading list.

| Bookmark action column | Source                 | Rule                                            |
| ---------------------- | ---------------------- | ----------------------------------------------- |
| `acting_account`       | Request `account`      | Keep the connected X account with the bookmark. |
| `tweet_id`             | Path `id`              | Keep the exact Tweet ID the user picked.        |
| `idempotency_key`      | Request header         | Generate 1 key for this account and Tweet ID.   |
| `write_action_id`      | Response `id`          | Store the action before polling.                |
| `terminal`             | Response `terminal`    | Mark the bookmark saved only when `true`.       |
| `safe_to_retry`        | Response `safeToRetry` | Retry only when this value is `true`.           |

## Choose bookmark, like, or read bookmarks

| Intent                   | API route                        | Result                                    |
| ------------------------ | -------------------------------- | ----------------------------------------- |
| Save one tweet privately | `POST /x/tweets/{id}/bookmark`   | Adds the post to the account's bookmarks. |
| Remove one saved tweet   | `DELETE /x/tweets/{id}/bookmark` | Removes the post from the bookmarks.      |
| Read saved tweets        | `GET /x/bookmarks`               | Returns the account's bookmarked posts.   |
| Like one tweet in public | `POST /x/tweets/{id}/like`       | Adds a public like instead.               |

Use [Remove bookmark](/api-reference/x-write/unbookmark) to reverse a bookmark.

## Twitter bookmark API questions

### Can an API bookmark a tweet by ID?

Yes. Send the Tweet ID in the path and the connected account in the body.

### Can other people see the bookmark?

No. X shows bookmarks only to the account that saved them.
The author sees the total bookmark count on the post.

## Handle errors

Never infer failure from a client timeout.
Poll a returned action before sending another request.

- For `400`, correct the Tweet ID or account value.
- For `401`, replace invalid Xquik authentication.
- For `402`, add credits before another request.
- For `403`, reconnect the selected X account.
- For `409`, keep the original action and payload.
- For `422`, review the X rejection before retrying.
- For `429`, wait for `Retry-After`.
- For `500` or `503`, follow `safeToRetry` and `terminal`.

## Headers

<ParamField header="x-api-key" type="string">

Unique key for this intended write. Reuse it only for an exact network replay.

<ParamField header="Content-Type" type="string" required>

Must be `application/json`.

</ParamField>

X username or account ID identifying which connected X account will bookmark the tweet. Xquik strips the `@` prefix if included.
