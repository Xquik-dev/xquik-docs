## What this means

Xquik builds and operates its own APIs, SDKs, MCP tools, webhooks, dashboard,
and documentation. X Corp. does not sponsor, authorize, endorse, or operate
Xquik. Nothing here implies a partnership, agency, or official integration.

{"\n"}

References to X and Twitter identify the services and workflows that Xquik
supports. The same applies to tweets, reposts, replies, followers, following,
and profiles. It also applies to timelines, communities, lists, direct
messages, and other platform features. Those references do not transfer
ownership of X Corp. trademarks or products to Xquik.

## Separate services

Xquik controls its subscriptions, credits, API keys, endpoints, SDKs, monitor
events, and webhook deliveries. X Corp. controls the X platform, accounts,
official X (Twitter) APIs, and developer access. It also controls platform rules
and feature availability. Changes made by either service may affect an integration.

{"\n"}

Use official X Corp. websites for X account support or official X API access.
Use them too for X developer terms, trademark policies, or platform status. Use
Xquik support when you need help with Xquik API keys, credits, or requests. Use
it too for responses, exports, monitors, SDKs, MCP tools, or webhook signatures.
