## <span className="nw">Source-backed</span> SocialCrawl scope

SocialCrawl's official docs describe it as a unified social media data API. They say it is for developers and AI agents.

{"\n"}

Current SocialCrawl pages give different coverage counts. The docs introduction says 21 platforms and 108 endpoints. The pricing page says 27 platforms and 133 APIs.

{"\n"}

The docs introduction says responses use a consistent format across platforms. It says responses also include computed fields such as `engagement_rate`, `language`, `content_category`, and `estimated_reach`.

{"\n"}

Authentication docs say requests use the `x-api-key` header. Missing or malformed credentials return `401 MISSING_API_KEY` or `401 INVALID_API_KEY`. Accounts can keep up to 5 active keys.

{"\n"}

The credits page describes credit-based pay-as-you-go billing. Each credential has a 50 concurrent request ceiling. Standard requests cost 1 credit across 84 endpoints. Advanced requests cost 5 credits across 18 endpoints. Premium requests cost 10 credits across 6 endpoints.

{"\n"}

The response schema includes `success`, `platform`, `endpoint`, `data`, `credits_used`, `credits_remaining`, `request_id`, and `cached`. List endpoints return `items`, optional `next_cursor`, and optional `total`.

{"\n"}

SocialCrawl docs say cache hits cost 0 credits and every response includes `credits_remaining`. `GET `<span className="cn"><wbr />`/v1/credits/balance`</span> costs 0 credits. The docs add that idempotent replays deduct 0 new credits within a 24-hour TTL.

{"\n"}

The pricing page lists Free with 400 one-time credits. Starter has 2,500 credits for GBP 15. Growth has 20,000 credits for GBP 49. Pro has 150,000 credits for GBP 299. Enterprise has custom credits.

{"\n"}

The AI agent docs publish `/llms.txt`, `/llms-full.txt`, OpenAPI JSON and YAML. They also publish per-platform llms files. The Twitter/X llms file lists profile, user tweets, and tweet detail endpoints. It also lists community detail, community tweets, video transcript, and AI-powered X search endpoints.

{"\n"}

The Skills & MCP docs list a `socialcrawl-mcp` package on npm and MCP Registry. It has 4 tools, `socialcrawl_`<span className="cn"><wbr />`list_`<wbr />`platforms`</span>, `socialcrawl_`<span className="cn"><wbr />`list_`<wbr />`endpoints`</span>, `socialcrawl_request`, and `socialcrawl_get_docs`.

## Migration path

Run the same query in both products. Then compare record completeness, deduplication, error states, and export shape. Move the task only after the systems reading the data accept the Xquik output.

{"\n"}

Keep the test small. Use 1 task, 1 output, 1 cost model, and 1 owner for the output. Switch only when the Xquik output matches the required records. It must also reduce integration work or cost.

{"\n"}

Compare SocialCrawl and Xquik by platform coverage and X endpoint count. Also compare export formats and agent tools.

{"\n"}

Price the real workload. On Xquik, Starter is USD 20/month with 140,000 credits. Top-ups are USD 0.00015/credit. Webhook and stored-event management cost no credits. Active monitors bill only while enabled.
