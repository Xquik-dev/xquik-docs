X (Twitter) has several MCP servers. Xquik hosts one at `https://xquik.com/mcp`. X publishes xmcp, a local server for its own API. Community servers on GitHub wrap the X API with your own keys.

This page compares where each runs, the keys it needs & its read price.

<Info>

Facts about other servers come from each project's official page, read on 2026-11-20. Check each page before you choose.

</Info>

## X (Twitter) MCP servers side by side

| Server                                                                       | Where it runs                     | Keys you need                                   | Search & post | Price of 1 post read         |
| ---------------------------------------------------------------------------- | --------------------------------- | ----------------------------------------------- | ------------- | ---------------------------- |
| Xquik                                                                        | Hosted at `https://xquik.com/mcp` | An Xquik sign-in or API key                     | Both          | USD 0.00015                  |
| [xmcp](https://github.com/xdevplatform/xmcp) by X                            | Your machine, port 8000           | X developer app key, secret & bearer token      | Both          | USD 0.005, X API pay-per-use |
| [x-twitter-mcp-server](https://github.com/rafaljanicki/x-twitter-mcp-server) | Your machine, STDIO or HTTP       | X API key, secret, access tokens & bearer token | Both          | USD 0.005, X API pay-per-use |
| [x-mcp-server](https://github.com/DataWhisker/x-mcp-server)                  | Your machine, Node.js             | X OAuth 1.0a keys & access tokens               | Both          | USD 0.005, X API pay-per-use |
| [twitter-mcp](https://github.com/EnesCinr/twitter-mcp)                       | Your machine, through `npx`       | X API keys & access tokens                      | Both          | USD 0.005, X API pay-per-use |

{"\n"}

X's [pricing page](https://docs.x.com/x-api/getting-started/pricing) lists USD 0.005 per post read & USD 0.015 per created post. Every server above except Xquik calls the X API with your own app's keys. So X bills your developer account for each read.

{"\n"}

Posting through Xquik needs a connected X account. So do private reads such as DMs & bookmarks. Public reads need none.

## Why Xquik is the Twitter MCP server to pick

**It's hosted.** Claude & ChatGPT connect to a public HTTPS URL. A local server needs a running process on your machine. The xmcp README says remote clients need a tunnel such as ngrok.

{"\n"}

**It needs no X developer app.** You sign in to Xquik when your app asks. Reads run on Xquik's infrastructure.

{"\n"}

**It's the cheapest per read.** 1,000 public tweets cost USD 0.15 through Xquik. The same 1,000 post reads cost USD 5 on X's pay-per-use API.

{"\n"}

**It bills only what you get.** Xquik bills only delivered, unique, filter-matching results. Empty or failed reads cost nothing.

{"\n"}

**Its speed & price are public.** Dated speed & price runs against named rivals are on the [benchmark page](https://xquik.com/benchmarks).

## Questions about X MCP servers

### Is there an MCP server for X (Twitter)?

Yes. Xquik hosts a remote X MCP server at `https://xquik.com/mcp`. X publishes xmcp for its own API. GitHub lists more community servers.

### What is the best Twitter MCP server for Claude?

Xquik fits Claude best of the servers on this page. Add `https://xquik.com/mcp?app=claude` as a custom connector & sign in. Claude can then search tweets, read replies, profiles & followers, & post. The other servers need X developer keys & a process on your machine.

### Which X MCP server can search tweets and post?

Xquik, xmcp, x-twitter-mcp-server, x-mcp-server & twitter-mcp all search & post. Of these, only Xquik runs hosted with no X developer keys.

### Do I need an X developer account for an X MCP server?

You need one for xmcp & every community server on this page. They call the X API with your app's keys. Xquik needs none. You connect an X account only to post or to read private data.

### How much does an X (Twitter) MCP server cost?

Most server code is free to run. The X API reads behind it aren't. X lists USD 0.005 per post read. Xquik charges USD 0.00015 per public result, so 1,000 tweets cost USD 0.15.

### Does X have an official MCP server?

Yes. X's developer platform publishes [xmcp](https://github.com/xdevplatform/xmcp) on GitHub. It runs on your machine & turns about 119 X API operations into tools. It needs your X developer app's keys.
