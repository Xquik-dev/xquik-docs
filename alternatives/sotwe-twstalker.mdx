Sotwe and TwStalker are third-party Twitter web viewers. They show public profiles, tweets and trends with no account. This page shows how each one answers today. It then maps each job to Xquik.

<section>

## Sotwe and TwStalker today

The Wayback Machine saved Sotwe's home page on November 11, 2026. It calls Sotwe a "Twitter Web Viewer & Trend Analyzer & Downloader".

{"\n"}

TwStalker's newest saved home page is from April 30, 2026. It calls TwStalker "a free Twitter web viewer" that needs no account.

{"\n"}

On 2026-11-20, both sites answered scripts with a Cloudflare page and HTTP 403. A feed reader or a script gets that page, not the posts.

</section>

<section>

## View Twitter without an account

The [X (Twitter) Viewer](https://xquik.com/en/twitter-viewer?ref=docs-sotwe) opens public profiles, posts, threads and replies. It also opens hashtags, keyword searches, lists and communities. You need no X account, and you sign in to Xquik to run it.

{"\n"}

Paste the username from a Sotwe or TwStalker link, such as `NASA`. Each post row holds its text, media, date, likes, reposts, replies, quotes and views. Export the rows as CSV, Excel, JSON or Markdown.

{"\n"}

Each result costs 1 credit, or USD 0.00015 with pay-as-you-go credits. Private accounts stay private, since the viewer reads public accounts only.

</section>

<section>

## Twitter trends and video downloads

[X (Twitter) Trends](https://xquik.com/en/twitter-trends?ref=docs-sotwe) shows a place's trends, now or on a past date. Each trend comes in rank order with a search link.

{"\n"}

The [X (Twitter) Video Downloader](https://xquik.com/en/twitter-video-downloader?ref=docs-sotwe) saves a post's video as MP4, MP3 or GIF. Paste the post link and pick a quality up to 1080p.

</section>

<section>

## Tweet alerts for accounts you follow

An Xquik account monitor checks 1 account every second. It sends each new post to Telegram, Discord, Slack or a signed webhook. A keyword monitor does the same for a search, a hashtag or a mention.

{"\n"}

Each active monitor costs 30 credits per hour, or 720 credits per day. The USD 20 plan includes 140,000 credits a month. That keeps 6 monitors on all month.

</section>

## Twitter API calls for Sotwe and TwStalker jobs

Scripts that read either site can call the same data from the Xquik API.

| Job                  | Xquik call                                                                             |
| -------------------- | -------------------------------------------------------------------------------------- |
| A profile's posts    | [User tweets](/api-reference/x/user-tweets)                                            |
| A search             | [Search tweets](/api-reference/x/search-tweets)                                        |
| Trends for a place   | [Trends](/api-reference/x/trends)                                                      |
| Photos and videos    | [Download media](/api-reference/x/download-media)                                      |
| New posts as they go | [Account monitor](/api-reference/monitors/create) with a [webhook](/webhooks/overview) |

{"\n"}

This call reads the same posts as a Sotwe or TwStalker `NASA` profile.

```bash
curl https://xquik.com/api/v1/x/users/NASA/tweets \
  -H "x-api-key: xq_YOUR_KEY_HERE" | jq
```

Each returned tweet costs 1 credit. Continue with `next_cursor` to read the next page. A trends call costs 1 credit.
