Nitter is an open-source X (Twitter) front end. It showed profiles, posts and RSS feeds with no X account. This page shows its state today. It then maps each Nitter job to Xquik.

<Info>

Check [nitter.net](https://nitter.net) for its current state before you plan around it.

</Info>

<section>

## What happened to Nitter

On 2026-11-20, nitter.net showed only an update from its developer, dated October 10. Profile and post links showed that same update. Its developer archived the [Nitter repository](https://github.com/zedeus/nitter) on October 9, 2026. It is now read-only.

{"\n"}

XCancel, a public Nitter instance, showed a notice that its service is suspended. Nitter's README calls its RSS feeds "instance-specific, often disabled due to abuse".

</section>

<section>

## Read X (Twitter) without an X account

The [X (Twitter) Viewer](https://xquik.com/en/twitter-viewer) opens public profiles, posts, threads and replies. It also opens hashtags, keyword searches, lists and communities. You need no X account, and you sign in to Xquik to run it.

{"\n"}

Paste a username or a Nitter link, such as `nitter.net/NASA`. The viewer also opens XCancel, FxTwitter and VxTwitter links. Each post row holds its text, media, date, likes, reposts, replies, quotes and views. Export the rows as CSV, Excel, JSON or Markdown.

{"\n"}

Each result costs 1 credit, or USD 0.00015 with pay-as-you-go credits. Private accounts stay private, since the viewer reads public accounts only.

</section>

<section>

## Follow accounts without a Nitter RSS feed

Nitter readers often followed accounts through its RSS feeds. An Xquik account monitor does that job with alerts. It checks the account every second and sends each new post where you pick.

- A Telegram chat, through @XquikBot.
- A Discord channel webhook or a Slack incoming webhook.
- Your own HTTPS endpoint, as a signed webhook.

{"\n"}

A keyword monitor does the same for a search, a hashtag or a mention. Each active monitor costs 30 credits per hour, or 720 credits per day. The USD 20 plan includes 140,000 credits a month. That keeps 6 monitors on all month.

{"\n"}

Xquik sends alerts and API pages, not RSS files. An RSS reader can't subscribe to a monitor today.

</section>

## Nitter pages and their Xquik calls

Scripts that scraped Nitter pages can call the same data from the Xquik API.

| Nitter page                | Xquik call                                                       |
| -------------------------- | ---------------------------------------------------------------- |
| `/<username>`              | [User tweets](/api-reference/x/user-tweets)                      |
| `/<username>/with_replies` | [User replies](/api-reference/x/user-replies)                    |
| `/<username>/media`        | [User media](/api-reference/x/user-media)                        |
| `/<username>/status/<id>`  | [Tweet thread](/api-reference/x/tweet-thread)                    |
| `/search?q=<query>`        | [Search tweets](/api-reference/x/search-tweets)                  |
| `/i/lists/<id>`            | [List tweets](/api-reference/x/list-tweets)                      |
| `/<username>/rss`          | [Account monitor](/api-reference/monitors/create) with a webhook |

{"\n"}

This call reads the same posts as `nitter.net/NASA`.

```bash
curl https://xquik.com/api/v1/x/users/NASA/tweets \
  -H "x-api-key: xq_YOUR_KEY_HERE" | jq
```

Each returned tweet costs 1 credit. Continue with `next_cursor` to read the next page.
