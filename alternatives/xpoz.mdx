## Where Xpoz fits

Xpoz calls itself the social data API for AI agents. It covers Twitter/X, Instagram, TikTok & Reddit. It bills credits per search, not per result.

This guide compares Xpoz and Xquik on specific X tasks. It covers tweet search, tracking, writes, webhooks, exports & agent connections.

<Info>

Facts on this page come from Xpoz's official pages, read on 2026-10-15. Verify current pricing and terms on the official site before buying.

</Info>

## Source-backed Xpoz scope

- A Twitter/X search costs 2 credits. It returns up to 300 results at no extra charge.
- Each tool call bills, including later pages of a paged result.
- Free gives 500 one-time credits. Pro costs USD 20 a month for 7,500 credits.
- Max costs USD 200 a month for 120,000 credits.
- Extra credits cost USD 0.003 each on Pro and USD 0.002 on Max. A search then costs USD 0.006 or USD 0.004.
- Tracked keywords & users make later searches more complete and fresher. Free has 1 slot, Pro 3 & Max 10.
- The hosted MCP server has 48 tools, 13 of them for Twitter/X. Every tool is read-only, except tracking tools.
- SDKs cover TypeScript & Python, plus a CLI. CSV exports reach 500K rows, metered against a row allowance.
- Authentication uses an access key, Google sign-in or a bearer token.

## Comparison

| Area           | Xpoz                                                          | Xquik                                                                                                  |
| -------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Billing unit   | 2 credits per Twitter/X search, up to 300 results.            | 1 credit per returned row, USD 0.00015 with pay-as-you-go credits. Plans cost up to 20% less.          |
| Large searches | About USD 0.00002 per result on a full 300-result search.     | USD 0.00015 per row with pay-as-you-go credits.                                                        |
| Empty search   | 2 credits, however many results return.                       | Billed only for returned rows, so 0 rows cost nothing.                                                 |
| Write actions  | MCP tools are read-only.                                      | 18 write actions from connected accounts. Posting a tweet costs 30 credits.                            |
| Monitoring     | Tracked keywords & users refresh data for later searches.     | Account & keyword monitors check every second and send signed webhooks. Each costs 30 credits an hour. |
| Agent tooling  | Hosted MCP server with 48 tools, using OAuth or a bearer key. | Remote MCP server with OAuth or API key.                                                               |
| SDKs           | TypeScript & Python, plus a CLI.                              | TypeScript, Python, Go, Java, Kotlin, PHP, Ruby & C#, plus a CLI & a Terraform provider.               |
| Exports        | CSV up to 500K rows, metered by a row allowance.              | CSV, XLSX, JSON & Markdown exports.                                                                    |

## What to test in Xquik

Count the results each search returns. Xpoz bills per search, so large result sets cost less there. Xquik bills per row, so small and empty searches cost less here. At the Pro extra-credit rate, a search costs USD 0.006. That equals 40 Xquik rows.

Xquik's X Tweet Scraper ran in public Apify benchmarks on 2026-09-27 & 2026-09-29. It cost USD 0.000175 per useful tweet, the lowest of 12 Apify Actors. It was also the fastest, at 39.2 useful tweets per second. The benchmark covers Apify Actors, not Xpoz. Read the [published benchmark](https://xquik.com/en/trust#benchmark-x-tweet-scraper).

## Migration path

Run the same X query in both products. Compare results per search, fields, freshness & cost. Move the task once the systems that read the data accept Xquik's output.
