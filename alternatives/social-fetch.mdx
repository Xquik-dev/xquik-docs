## Where Social Fetch fits

Social Fetch calls itself a versioned public REST API for social data. It covers 25 platforms, X included. Most completed lookups cost 1 credit.

This guide compares Social Fetch and Xquik on specific X tasks. It covers tweet search, lookups, monitors, webhooks, writes & agent connections.

<Info>

Facts on this page come from Social Fetch's official pages, read on 2026-10-15. Verify current pricing and terms on the official site before buying.

</Info>

## Source-backed Social Fetch scope

- Pay as you go costs USD 0.00236 per request. Plans cost USD 0.00161 to USD 0.00150 per request.
- Starter costs USD 29 a month for 18,000 credits. Scale costs USD 225 a month for 150,000.
- X search, tweet & profile routes cost 1 credit per successful request.
- A completed `not_found` lookup still bills. Validation errors & infrastructure failures do not.
- Pay-as-you-go pack credits never expire. Monthly plan credits reset each period.
- New accounts get 100 free credits with no card.
- Monitors poll on a schedule and send HMAC-signed webhooks. X sources have a 5-minute floor.
- Each monitor check bills like the lookup it runs, also when nothing is new.
- Pay as you go allows 5 active monitors. Starter allows 25, Growth 100 & Scale 250.
- Requests use an `x-api-key` header. A TypeScript SDK & a hosted MCP server are available.
- Each workspace can have 200 requests in flight. Paid metered routes have no RPS cap.

## Comparison

| ----------------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Billing unit            | 1 credit per lookup, USD 0.0015 to USD 0.00236.                              | 1 credit per returned row, USD 0.00015 with pay-as-you-go credits. Plans cost up to 20% less. |

| Monitor price           | Each check bills. A 5-minute X monitor runs 288 checks a day.                | 30 credits an hour, which is USD 0.108 a day.                                                 |
| Write actions           | Its 29 X routes are all GET reads.                                           | 18 write actions from connected accounts. Posting a tweet costs 30 credits.                   |
| Agent tooling           | Hosted MCP server with OAuth or API key. Every endpoint is a tool.           | Remote MCP server with OAuth or API key.                                                      |
| SDKs                    | TypeScript SDK.                                                              | TypeScript, Python, Go, Java, Kotlin, PHP, Ruby & C#, plus a CLI & a Terraform provider.      |
| Exports                 | JSON API responses.                                                          | CSV, XLSX, JSON & Markdown exports.                                                           |

## What to test in Xquik

Price the X part of the task. A Social Fetch lookup costs from USD 0.0015. An Xquik tweet or profile costs USD 0.00015. For monitors, compare check speed and daily cost. Xquik checks every second for USD 0.108 a day.

Xquik's X Tweet Scraper ran in public Apify benchmarks on 2026-09-27 & 2026-09-29. It cost USD 0.000175 per useful tweet, the lowest of 12 Apify Actors. It was also the fastest, at 39.2 useful tweets per second. The benchmark covers Apify Actors, not Social Fetch. Read the [published benchmark](https://xquik.com/en/trust#benchmark-x-tweet-scraper).
