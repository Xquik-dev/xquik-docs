## Where ScrapeCreators fits

ScrapeCreators returns profiles, posts & comments from 20+ platforms through 1 API. Its Twitter API page lists 7 endpoints. Xquik adds X writes, monitors & file exports.

This guide compares ScrapeCreators and Xquik on specific X tasks. It covers tweet search, lookups, writes, monitors & agent connections.

## Source-backed ScrapeCreators scope

- The Twitter API page lists 7 endpoints. They cover search, profiles, user tweets, tweet details, transcripts & communities.
- Search finds posts through Google-indexed results, not native X search.
- The docs say recent posts can be missing from search. Google ranks the results, not recency.
- Each successful search page costs 1 credit, including empty results.
- User tweets returns about 100 of a user's most popular tweets, not the latest.
- Most endpoints cost 1 credit per request. Cached results cost 0 credits.
- Freelance costs USD 47 for 25,000 credits, which is USD 0.00188 per request.
- Business costs USD 497 for 500,000 credits, which is USD 0.000994 per request. Credits never expire.
- No account-level rate or concurrency caps apply. The homepage suggests staying under 500 concurrent requests.
- Requests use an `x-api-key` header. The hosted MCP server takes OAuth or that header.

| Billing unit            | 1 credit per request on most endpoints, USD 0.000994 to USD 0.00188. | 1 credit per returned row, USD 0.00015 with pay-as-you-go credits. Plans cost up to 20% less. |

## What to test in Xquik

Price the X part of the task. A ScrapeCreators request costs from USD 0.000994. An Xquik tweet or profile costs USD 0.00015. Check search results for recent posts in both products. Add writes, monitors & exports if the workflow needs them.

Xquik's X Tweet Scraper ran in public Apify benchmarks on 2026-09-27 & 2026-09-29. It cost USD 0.000175 per useful tweet, the lowest of 12 Apify Actors. It was also the fastest, at 39.2 useful tweets per second. The benchmark covers Apify Actors, not ScrapeCreators. Read the [published benchmark](https://xquik.com/en/trust#benchmark-x-tweet-scraper).
