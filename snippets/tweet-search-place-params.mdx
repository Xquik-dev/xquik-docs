| Query parameter | Type     | Required | Description                                                                                          |
| --------------- | -------- | -------- | ---------------------------------------------------------------------------------------------------- |
| `keywords`      | `string` | No       | Words the Tweets must match, in X search syntax.                                                     |
| `place`         | `string` | No       | Search within this X place ID. [Search places](/api-reference/x/search-places) finds the ID by name. |
| `placeCountry`  | `string` | No       | Search within this country code.                                                                     |
| `pointRadius`   | `string` | No       | Geo point radius in X search syntax, such as `-73.99 40.73 25mi`.                                    |
| `boundingBox`   | `string` | No       | Geo bounding box in X search syntax, such as `-74.1 40.6 -73.9 40.8`.                                |
| `advancedQuery` | `string` | No       | Raw X search operators appended to the final search query.                                           |
