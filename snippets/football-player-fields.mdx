| Field        | Type     | Description                                                                                                                                                                                                                                  |
| ------------ | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`         | `string` | The player ID that plays & stats refer to.                                                                                                                                                                                                   |
| `teamId`     | `string` | The player's team, a key of `teams`.                                                                                                                                                                                                         |
| `name`       | `string` | The player's full name.                                                                                                                                                                                                                      |
| `shortName`  | `string` | The name play descriptions use, such as `B.Purdy`.                                                                                                                                                                                           |
| `jersey`     | `string` | The jersey number, as text.                                                                                                                                                                                                                  |
| `position`   | `string` | The position, such as `QB` or `DE`.                                                                                                                                                                                                          |
| `college`    | `string` | The college the player came from.                                                                                                                                                                                                            |
| `birthPlace` | `string` | Where the player was born. X sends it only for NFL players.                                                                                                                                                                                  |
| `birthDate`  | `string` | The birth date, as `YYYY-MM-DD`.                                                                                                                                                                                                             |
| `headshots`  | `object` | Photo links in `original`, `large`, `medium` & `small`. Any of them can be null.                                                                                                                                                             |
| `xUser`      | `object` | The player's X account, with `id`, `username` & `blueVerified`. Null when the player has none. Rosters also fill `protected`, `superFollowEligible` & the highlighted `labelType`, such as `BusinessLabel`. Other answers send them as null. |
