## Body

| Body parameter             | Type       | Required | Description                                                                                                                                                                                                                                                                          |
| -------------------------- | ---------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `tweetIds`                 | `string[]` | No       | Up to 100 post IDs or post URLs, such as `x.com/nasa/status/20`. A post named twice is analyzed once. Send `tweetIds`, `texts`, or a search, not more than 1.                                                                                                                        |
| `query`                    | `string`   | No       | X search to analyze, with the operators of [Search Tweets](/api-reference/x/search-tweets). X searches up to 512 characters, counted with the other search fields. Search Tweets counts `q` the same way.                                                                            |
| `username`                 | `string`   | No       | Analyze 1 account's posts. Send a handle, with or without `@`, or a profile URL.                                                                                                                                                                                                     |
| `listId`                   | `string`   | No       | Analyze a public List's posts. Send its ID or URL.                                                                                                                                                                                                                                   |
| `quotesOf`                 | `string`   | No       | Analyze the quotes of 1 post. Send its ID or URL.                                                                                                                                                                                                                                    |
| `repliesTo`                | `string`   | No       | Analyze the replies in 1 post's conversation. Send its ID or URL.                                                                                                                                                                                                                    |
| `sinceTime`                | `string`   | No       | Inclusive start of the search, such as `2026-09-25T00:00:00Z`. Unix seconds also work. A time without an offset is UTC.                                                                                                                                                              |
| `untilTime`                | `string`   | No       | Exclusive end of the search. Unix seconds also work. A time without an offset is UTC.                                                                                                                                                                                                |
| `queryType`                | `string`   | No       | Search order. Use `Latest` or `Top`. Defaults to `Latest`.                                                                                                                                                                                                                           |
| `limit`                    | `integer`  | No       | Maximum posts to analyze from the search. Accepts `1-100`. Defaults to `20`. Credits can return fewer.                                                                                                                                                                               |
| `cursor`                   | `string`   | No       | The `next_cursor` of the page before. Send the same search with it.                                                                                                                                                                                                                  |
| `texts`                    | `string[]` | No       | Up to 100 texts of your own, such as drafts. Each must contain words. Reads nothing from X.                                                                                                                                                                                          |
| `baseline`                 | `object[]` | No       | Rows of an earlier answer to compare with, such as its `results`. You can send up to 10,000 rows. Each needs the post's `id`, or `tweet.id`, and its `answers`. Each new result's `monitor` says whether the post is new, changed, or unchanged. The comparison costs nothing extra. |
| `analysis`                 | `object`   | No       | Optional settings. Leave it out to ask the route's own questions.                                                                                                                                                                                                                    |
| `analysis.targets`         | `object[]` | No       | Up to 100 brands, people, assets, or topics the questions are about. Each has a `name` and optional `aliases`, such as a ticker or product name.                                                                                                                                     |
| `analysis.context`         | `string`   | No       | Background the AI reads with every post, such as your product or market.                                                                                                                                                                                                             |
| `analysis.questions`       | `object[]` | No       | 1 to 8 questions of your own, which replace the route's questions. Each needs an `id` and a `type` of `choice`, `score`, or `probability`. Each also needs a `version` and `instructions`. A choice adds `categories`, a score adds `levels`, and a probability can add `criteria`.  |
| `analysis.preset`          | `string`   | No       | A ready set of questions, used when `questions` is left out. Use `brand`, `complaints`, `competitors`, `purchase_intent`, `product_feedback`, `news`, `sentiment`, or `market`. `complaints`, `competitors`, `purchase_intent`, and `product_feedback` need `targets`.               |
| `analysis.maxContextBytes` | `integer`  | No       | Bytes of post, quote, and settings the AI reads. Accepts `1-64000`. Defaults to `64000`. Xquik cuts a longer post to fit.                                                                                                                                                            |
| `analysis.concurrency`     | `integer`  | No       | Posts analyzed at the same time. Accepts `1-16`. Defaults to `16`.                                                                                                                                                                                                                   |
| `analysis.images`          | `boolean`  | No       | Reads up to 4 images per post with its text, at no extra cost. Defaults to `true`. Images of posts X marks sensitive stay unread. Send `false` to analyze the text alone. `contextAvailability.media` is `images` when the AI read them.                                             |
