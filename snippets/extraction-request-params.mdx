## Body

| Body parameter | Type     | Required | Description                                                       |
| -------------- | -------- | -------- | ----------------------------------------------------------------- |
| `toolType`     | `string` | Yes      | Extraction tool to run or estimate. See the endpoint's tool list. |

Each tool reads its own target, collection, and filter fields. See [extraction parameters](/api-reference/extractions/parameters) for every field.
