Each analyzed post costs 2 credits. Each text in `texts` costs the same. Posts
in `unanalyzed` cost nothing.

When credits cover fewer posts than you asked for, fewer come back. The posts
left over appear in `unanalyzed` with `insufficient_credits`. If credits cover
no post, the call returns `402 insufficient_credits`.

| `unanalyzed[].reason`  | Meaning                                  | What to do                       |
| ---------------------- | ---------------------------------------- | -------------------------------- |
| `post_unavailable`     | X returns no such post                   | Skip the post                    |
| `missing_text`         | The post has no text                     | Skip the post                    |
| `insufficient_credits` | Credits ran out                          | Add credits, then send it again  |
| `context_limit`        | The settings leave the post no room      | Shorten the context or questions |
| Any other reason       | The analysis failed (`status: "failed"`) | Send the post again              |
