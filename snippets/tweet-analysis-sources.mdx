Send exactly 1 of `tweetIds`, `query`, or `texts`. Sending none, or more than 1,
returns `400 invalid_input`.

| Source         | Send                                                   | Posts analyzed                     |
| -------------- | ------------------------------------------------------ | ---------------------------------- |
| Post IDs       | `tweetIds`, up to 100 post IDs or post URLs            | Each post once                     |
| X search       | `query`, with optional `queryType`, `limit` & `cursor` | Up to `limit` posts, 20 by default |
| Your own texts | `texts`, up to 100 strings                             | Each text. Reads nothing from X    |
