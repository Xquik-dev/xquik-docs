| Field          | Type       | Description                                                                                                                                                                                                                                                                                           |
| -------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | `string`   | The team ID that games & players refer to.                                                                                                                                                                                                                                                            |
| `name`         | `string`   | The team's full name, such as `San Francisco 49ers`.                                                                                                                                                                                                                                                  |
| `shortName`    | `string`   | The team's short name.                                                                                                                                                                                                                                                                                |
| `abbreviation` | `string`   | The team's abbreviation, such as `SF`.                                                                                                                                                                                                                                                                |
| `alternateId`  | `string`   | Another ID X keeps for the team. College plays & drives name a side by it.                                                                                                                                                                                                                            |
| `location`     | `string`   | The school or place the team plays for. College schedules & a game's audience send it.                                                                                                                                                                                                                |
| `colors`       | `object[]` | The team's colors. Each has `r`, `g` & `b`, from 0 to 255.                                                                                                                                                                                                                                            |
| `logos`        | `object`   | The team's logo links. `default` is the one X shows. `light` & `dark` suit light or dark backgrounds.                                                                                                                                                                                                 |
| `xUserId`      | `string`   | The user ID of the team's X account. Pass it to [Get user](/api-reference/x/twitter-profile-lookup).                                                                                                                                                                                                  |
| `record`       | `object`   | The team's `wins`, `losses` & `ties` this season. X sends it only in college football games.                                                                                                                                                                                                          |
| `recentGames`  | `object[]` | The team's recent games, newest first. Games without a kickoff time come last. Each has `id`, `startsAt`, `venue`, `status`, `clock`, `quarter`, `home` & `away`. `home` & `away` hold `teamId` & `points`. X sends them only with the teams of a college football game. The list is empty elsewhere. |
