| Query parameter | Type      | Required | Description                                                                                                                          |
| --------------- | --------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `cardName`      | `string`  | No       | Keep only Tweets with this card type, such as `poll2choice_text_only`.                                                               |
| `source`        | `string`  | No       | X search no longer supports `source`. A Tweet search with it answers 424 & charges nothing.                                          |
| `excludeSource` | `string`  | No       | X search no longer supports `excludeSource`. A Tweet search with it answers 424 & charges nothing.                                   |
| `geocode`       | `string`  | No       | X search no longer supports `geocode`. A Tweet search with it answers 424 & charges nothing.                                         |
| `near`          | `string`  | No       | A place name. A country, such as United States, works like `placeCountry` & keeps Tweets tagged there. A city keeps Tweets about it. |
| `within`        | `string`  | No       | X search no longer supports `within`. A Tweet search with it answers 424 & charges nothing. Use `near` alone.                        |
| `safe`          | `boolean` | No       | When `true`, enable X safe-search filtering.                                                                                         |
| `news`          | `boolean` | No       | X no longer searches `filter:news`, so leave this unset.                                                                             |
