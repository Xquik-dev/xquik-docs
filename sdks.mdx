Official Xquik SDKs wrap the REST API with generated request types and response models. They add retries, pagination helpers, and consistent authentication. Use this page to choose the right SDK, CLI, or MCP handoff. It covers tweet search exports, follower export jobs, media tweets, and DM attachments. It also covers monitor webhooks and agent workflows.

<Info>

For SDK extraction jobs, treat `202 Accepted` as a queued run receipt. Poll `GET `<span className="cn"><wbr />`/extractions/{id}`</span> before exporting rows. Xquik reserves credits after the job starts. The run can lower `resultsLimit` to the affordable count or fail with `insufficient_credits`.

</Info>

## Choose an SDK

- **TypeScript / Node.js.** Install from npm. Open the [TypeScript SDK guide](/sdks/typescript) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-typescript).
- **Python.** Install from PyPI. Open the [Python SDK guide](/sdks/python) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-python).
- **Go.** Install with Go modules. Open the [Go SDK guide](/sdks/go) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-go).
- **Java.** Install from Maven Central. Open the [Java SDK guide](/sdks/java) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-java).
- **Kotlin.** Install from Maven Central. Open the [Kotlin SDK guide](/sdks/kotlin) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-kotlin).
- **C# / .NET.** Install from NuGet. Open the [C# SDK guide](/sdks/csharp-x-api-sdk) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-csharp).
- **Ruby.** Install from RubyGems. Open the [Ruby SDK guide](/sdks/ruby) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-ruby).
- **PHP.** Install from Packagist with Composer. Open the [PHP SDK guide](/sdks/php) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-php).
- **CLI.** Install from npm or with Go. Open the [CLI guide](/sdks/cli) or the [source on GitHub](https://github.com/Xquik-dev/x-twitter-scraper-cli).
- **Terraform provider.** Install from the Terraform Registry. Open the [Terraform guide](/sdks/terraform) or the [source on GitHub](https://github.com/Xquik-dev/terraform-provider-x-twitter-scraper).

## Choose by job

- **Tweet search exports.** Start with [TypeScript](/sdks/typescript), [Python](/sdks/python), [Go SDK](/sdks/go), or [CLI](/sdks/cli) plus [Search Tweets](/api-reference/x/search-tweets). Hand off `PaginatedTweets`, `tweets`, `has_next_page`, `next_cursor`, and `xquik-tweet-search.`<span className="cn"><wbr />`jsonl`</span> for JSON Lines, CSV, or XLSX. The cost is <span className="nw">1 credit</span> per tweet returned.
- **Follower export files.** Start with [Follower Export CRM Workflow](/guides/follower-export-crm), [TypeScript](/sdks/typescript), [Python](/sdks/python), [Go SDK](/sdks/go), or [CLI](/sdks/cli). Run `follower_explorer` with `targetUsername` and optional `resultsLimit`. Then export CSV, JSON, or XLSX from [Export Extraction](/api-reference/extractions/export). Store the `202 Accepted` receipt `id` and `toolType`. Then poll `GET `<span className="cn"><wbr />`/extractions/{id}`</span> for `job.status`, `results`, `hasMore`, and `nextCursor`. The cost is <span className="nw">1 credit</span> per follower extracted or returned.
- **Post media tweets or replies.** Start with [TypeScript](/sdks/typescript), [Go SDK](/sdks/go), or [CLI](/sdks/cli) plus [Create Tweet](/api-reference/x-write/create-tweet). Pass public media URLs in `media`. Send up to <span className="nw">4 image</span> URLs. Or send exactly <span className="nw">1 MP4</span> video URL up to <span className="nw">100 MB</span>. Store `tweetId`, `reply_to_tweet_id`, `chargedCredits`, or `writeActionId`. A <span className="nw">text-only</span> write costs <span className="nw">30 credits</span>. Attached media adds <span className="nw">2 credits</span> per started MB across all files.
- **Upload DM attachments.** Call [Upload Media](/api-reference/x-write/upload-media), then [Send Direct Message](/api-reference/x-write/send-dm). Use the returned `mediaId` as the <span className="nw">one-item</span> `media_ids` value. Store `mediaUrl` and the returned `messageId`. The cost is <span className="nw">10 credits</span> per media upload plus <span className="nw">10 credits</span> per DM send.
- **Monitor tweets to webhooks.** Start with [Create Monitor](/api-reference/monitors/create), [Webhooks](/webhooks/overview), or [Terraform](/sdks/terraform). Store monitor IDs, webhook IDs, event types, and signed delivery metadata. Active monitors cost <span className="nw">30 credits</span> per <span className="nw">monitor-hour</span>.
- **Agent handoff.** Use the [MCP Server](/mcp/overview) for tool calls, or SDKs for direct code. Return JSON objects with the endpoint path, request parameters, and result fields. Add the pagination cursor and endpoint cost.

</section>

## Authentication

All SDKs accept the same API credentials as the REST API.

```bash
export X_TWITTER_SCRAPER_API_KEY="xq_YOUR_KEY_HERE"
```

SDKs accept OAuth 2.1 bearer tokens where the generated SDK exposes `X_TWITTER_`<span className="cn"><wbr />`SCRAPER_`<wbr />`BEARER_`<wbr />`TOKEN`</span>.

## Common workflows

- Search tweets or scrape tweets to JSON Lines, CSV, or XLSX through [Search Tweets](/api-reference/x/search-tweets). Keep `xquik-tweet-search.`<span className="cn"><wbr />`jsonl`</span> or the <span className="nw">language-specific</span> export file as the downstream handoff.
- Inspect threads through [Get Tweet](/api-reference/x/get-tweet) and [Tweet Thread](/api-reference/x/tweet-thread).
- Look up profiles and relationships through [Get User](/api-reference/x/twitter-profile-lookup), [Followers](/api-reference/x/followers), and [Check Follower](/api-reference/x/check-follower).
- Post media tweets or replies through [Create Tweet](/api-reference/x-write/create-tweet). Send up to <span className="nw">4 public</span> image URLs. Or send exactly <span className="nw">1 public</span> MP4 video URL up to <span className="nw">100 MB</span>. <span className="nw">Text-only</span> tweet or reply writes cost <span className="nw">30 credits</span>. Attached media adds <span className="nw">2 credits</span> per started MB across all files. [Send Direct Message](/api-reference/x-write/send-dm) takes one uploaded media ID in `media_ids`. Get it through [Upload Media](/api-reference/x-write/upload-media).
- Create account monitors with [Create Monitor](/api-reference/monitors/create), then receive events through [Webhooks](/webhooks/overview).
- Run exports and giveaway workflows with [Extractions](/api-reference/extractions/create) and [Draws](/api-reference/draws/create).
- Connect agents through the [MCP Server](/mcp/overview) when you need tool use. Use direct SDK calls otherwise.

</section>

## Error handling & pagination

Generated SDKs map HTTP errors into language-native exception or error types. The [error handling guide](/guides/error-handling) explains each status code. Each language page shows its idiomatic handling.

{"\n"}

Paginated endpoints return a page object with a next-page marker. It reads `has_next_page`, `hasNextPage`, or `HasNextPage`, by language casing. Use the SDK's generated pagination helpers when available. Otherwise pass the cursor fields documented on each endpoint.
