To use Twitter advanced search, open
[x.com/search-advanced](https://x.com/search-advanced) and fill in the filters.
You can also type search operators into the search box on X.

```text
nasa min_faves:1000
```

That search returns posts about NASA with at least 1,000 likes. Xquik keeps the
full, tested list of
[Twitter advanced search operators](https://github.com/Xquik-dev/x-twitter-advanced-search).

## Use advanced search on X

<Steps>

  <Step title="Open advanced search">

    Open [x.com/search-advanced](https://x.com/search-advanced), or use the search box on X.

  </Step>
  <Step title="Add your filters">

    Fill in your words, accounts and dates. In the search box, type operators instead.

  </Step>
  <Step title="Pick Latest or Top">

    Latest lists the newest tweets first. Top shows the tweets X ranks highest.

  </Step>
</Steps>

</section>

## Search operators to copy

| You want                                                     | Search                       |
| ------------------------------------------------------------ | ---------------------------- |
| Tweets from <span className="nw">1 account</span>            | `from:NASA`                  |
| Replies to an account                                        | `to:NASA`                    |
| Mentions of an account                                       | `@NASA`                      |
| An exact phrase                                              | `"climate change"`           |
| Either of <span className="nw">2 words</span>                | `tesla OR rivian`            |
| A word without another word                                  | `jaguar -car`                |
| A hashtag                                                    | `#photography`               |
| A stock or coin cashtag                                      | `$TSLA`                      |
| A language, by its <span className="nw">2-letter</span> code | `ramen lang:ja`              |
| Tweets with at least <span className="nw">1,000 likes</span> | `nasa min_faves:1000`        |
| Tweets with an image or video                                | `nasa filter:media`          |
| Tweets from verified accounts                                | `nasa filter:verified`       |
| Tweets without replies                                       | `nasa -filter:replies`       |
| Tweets from a date onward                                    | `from:NASA since:2026-10-01` |

The operator list ran each of these examples on X on 2026-10-13.

</section>

## Search the tweets of <span className="nw">1 user</span>

Type `from:` and the username to see only that account's tweets. Add a keyword
to narrow the list.

```text
from:NASA mars
```

To limit the dates too, read
[search tweets by date](/guides/search-tweets-by-date).

## Run and export the search in Xquik

X shows results on screen only. To keep them, run the same search through the
[X (Twitter) Advanced Search](https://xquik.com/en/twitter-advanced-search)
page.

- Filter by keyword, account, phrase, date and <span className="nw">65 languages</span>.
- Add minimum likes, media type, hashtags, cashtags and verified authors.
- Exclude accounts, then sort by Latest or Top.
- Export the tweets as CSV, Excel, JSON or Markdown.

You can build and copy a search with no account. Running it on that page needs
an Xquik account. Each returned tweet costs 1 credit, USD 0.00015 with

## Advanced search questions

### Can I use X advanced search without an account?

Yes. You can build and copy a search on the Xquik page with no account. Running
it there needs an Xquik account.

### How do I find tweets from <span className="nw">1 account</span>?

Type `from:nasa` to find tweets from @nasa. Or fill in the account under the
advanced filters.

### Which sort order should I pick?

Latest lists the newest tweets first and suits date-ordered exports. Top shows
the tweets X ranks highest.

### How far back does Twitter search go?

X search goes back to March 2006. Read
[Twitter archive search](/guides/twitter-archive-search) for old tweets.
