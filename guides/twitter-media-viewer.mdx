A Twitter media viewer lists the photos, videos and GIFs of a public account.
Enter a username in the
[X (Twitter) Media Viewer](https://xquik.com/en/twitter-media-viewer) to see
them.

You can also open a profile on X and tap Media. The viewer adds downloads and
exports.

## View an account's media

<Steps>

  <Step title="Open the media viewer">

    Open the [X (Twitter) Media Viewer](https://xquik.com/en/twitter-media-viewer) and sign in to Xquik.

  </Step>
  <Step title="Enter the account">

    Enter a username or profile link. A post link lists the media of its author.

  </Step>
  <Step title="Play or download the media">

    Play each video on the results page. Press Download under a file to save it.

  </Step>
</Steps>

</section>

<section>

## What you get

Each row is 1 post with media. It shows the text, the post date, the media type
and the file links. It adds the engagement counts.

- Download ZIP saves <span className="nw">200 posts</span> at a time.
- The list exports to CSV.

</section>

<section>

## Media viewer questions

### Can I view Twitter media without an X account?

Yes. You only sign in to Xquik. Public profiles need no connected X account.

### Does it work on private accounts?

No. The media viewer reads public accounts only.

### Which media types does it find?

Photos, videos and GIFs. Each row names its media type.

### Can I paste a post link?

Yes. The viewer lists the media of that post's author.

### How do I download Twitter media?

Run the viewer for the account. Then press Download ZIP on the results page, or
press Download under a file.
