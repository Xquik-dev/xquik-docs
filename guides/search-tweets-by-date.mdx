To search tweets by date, add `since:` and `until:` to an X (Twitter) search. Both take
a UTC day, written YYYY-MM-DD. `since:` keeps posts sent on or after that day.
`until:` keeps posts sent before it.

```text
from:NASA since:2026-09-01 until:2026-10-01
```

That search returns posts by NASA from September 2026. Xquik keeps the full,
tested list of
[Twitter advanced search operators](https://github.com/Xquik-dev/x-twitter-advanced-search).

## Date operators

| Operator                        | What it does                                                                   | Example                                   |
| ------------------------------- | ------------------------------------------------------------------------------ | ----------------------------------------- |
| `since:`                        | Posts sent on or after the UTC day.                                            | `from:NASA since:2026-10-01`              |
| `until:`                        | Posts sent before the UTC day.                                                 | `from:NASA until:2026-01-01`              |
| `until:YYYY-MM-DD_HH:MM:SS_UTC` | Posts sent before the exact UTC time.                                          | `from:NASA until:2026-01-01_00:00:00_UTC` |
| `since_time:`                   | Posts sent at or after a Unix time in seconds.                                 | `from:NASA since_time:1767225600`         |
| `until_time:`                   | Posts sent before a Unix time in seconds.                                      | `from:NASA until_time:1767225600`         |
| `within_time:`                  | Posts from the last period, such as 2d for <span className="nw">2 days</span>. | `nasa within_time:2d`                     |

The operator list ran each of these examples on X on 2026-10-13.

</section>

## Export tweets from a date range

X shows results on screen only. To keep them, run the same query through Xquik.

- In the [Tweet Searcher](https://xquik.com/en/twitter-advanced-search), paste
  the query and choose a result limit. Export CSV, XLSX, JSON or Markdown from
  there.
- Through the REST API, send the query in `q` to
  [Search tweets](/api-reference/x/search-tweets). The `sinceDate` and
  `untilDate` parameters also take UTC days. `untilDate` includes its own day.
- On Apify, Xquik's
  [X Tweet Scraper](https://apify.com/xquik/x-tweet-scraper) takes the same
  query.

```bash
curl -G "https://xquik.com/api/v1/x/tweets/search" \
  -H "x-api-key: xq_YOUR_KEY_HERE" \
  --data-urlencode "q=from:NASA since:2026-09-01 until:2026-10-01" \
  --data-urlencode "limit=100"
```

Each returned tweet costs 1 credit, USD 0.00015 with pay-as-you-go credits.
Xquik bills only the rows it returns, so an empty search costs nothing.

## Search by date questions

### How do I search tweets by date?

Add `since:` and `until:` with UTC days to a search on X (Twitter). For example, search
`from:NASA since:`<span className="cn"><wbr /><span className="nw">`2026-09-01 `</span><wbr />`until:`<wbr /><span className="nw">`2026-10-01`</span></span>.

### Does until include its own day?

No. On X, `until:` keeps posts sent before that day. The `untilDate` parameter
of Xquik's search API includes its own day.

### Can I search old tweets by date?

Yes. Set `since:` and `until:` to the days you want. Both take any UTC day.

### How do I export tweets from a date range?

Run the query in Xquik's Tweet Searcher or through the search API. The X
Tweet Scraper on Apify can also run it. Each returned tweet costs 1 credit.
