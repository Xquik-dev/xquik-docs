To unroll a Twitter thread, copy the URL of 1 public post from it. Paste it into
the [X (Twitter) Thread Reader](https://xquik.com/en/twitter-thread-reader).
Xquik returns the conversation as 1 list.

<section>

## Unroll a thread

<Steps>

  <Step title="Copy a post URL">

    Copy the URL of a public post from the thread on X.

  </Step>
  <Step title="Paste it into the thread reader">

    Open the [X (Twitter) Thread Reader](https://xquik.com/en/twitter-thread-reader) and paste the URL.

  </Step>
  <Step title="Read or save the thread">

    Read it top to bottom. Or export Markdown, PDF, CSV, Excel or JSON.

  </Step>
</Steps>

Each row is 1 post or reply from the thread. It shows the text, the author and
the date. It adds the likes, reposts and replies.

</section>

<section>

## Read a conversation on X

On X, search `conversation_id:` with the ID of the post that started the
conversation. The ID is the last part of that post's URL.

```text
conversation_id:2109320622882873464
```

Xquik's list of
[Twitter advanced search operators](https://github.com/Xquik-dev/x-twitter-advanced-search)
ran this example on X on 2026-10-13.

</section>

## Thread unroll questions

### Do I need an X account to read a thread?

No. Xquik reads public threads without your X account. You sign in to Xquik.

### Does it include replies?

Yes. It returns the thread and its replies, up to your result limit.

### Can I save a thread as a PDF?

Yes. Pick PDF when you export. Pick Markdown for notes you want to edit.

### Does it read threads from private accounts?

No. It reads threads that anyone can see on X.
