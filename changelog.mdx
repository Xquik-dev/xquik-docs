<Update label="November 2026" description="v1">

**Changed**

- Connect links let your users connect an X account on a page Xquik hosts. They need no Xquik signup. Your backend never receives their password. See [Connect your users' X accounts](/guides/connect-x-accounts-for-your-users)
- A new key permission, Connect X accounts, opens this API to your backend. It connects, reconnects, retries & disconnects X accounts. It starts off, and Full access doesn't include it. Only a dashboard session can turn it on. See [Connect your users' X accounts](/guides/connect-x-accounts-for-your-users). MCP tools still never take X passwords
- X account logins no longer stop at <span className="nw">10 per</span> <span className="nw">15 minutes</span>. Failed logins slow a caller down, & each account it connects lifts that limit. Reconnects follow the same limits & cooldowns
- <span className="cn">`POST /x/accounts/`<wbr />`{id}/`<wbr />`reauth`</span> can answer <span className="nw">`202` for</span> an email code, & <span className="cn"><span className="nw">`409 x_`</span><wbr />`account_`<wbr />`mismatch`</span> for another X account's <span className="nw">sign-in</span>
- <span className="cn">`POST /x/media/download`</span> takes any number of posts in `tweetIds`, where it took 50. Posts it had no time to read come back in `unprocessedTweetIds` at no charge. Send them again
- `GET /x/tweets` & `GET /x/users/batch` take as many IDs as fit in <span className="nw">1 URL</span>. They took 100
- <span className="cn">`GET /x/users/`<wbr />`batch/`<wbr />`tweets`</span> takes any number of users, where it took 20. `pageSize` goes up to <span className="nw">300 posts</span> a user. Users it had no time to read come back in `unprocessed_ids` at no charge
- <span className="cn">`GET /x/users/`<wbr />`{id}/`<wbr />`insights`</span> & <span className="cn">`GET /x/users/`<wbr />`{id}/`<wbr />`shadowban`</span> read past where X ends a profile timeline. So `limit=2000` returns <span className="nw">2,000 posts</span>. The rows below that place come from search, which can miss a few posts
- `sample.read` in user insights gives the posts read. `sample.posts` gives the posts the averages used
- Every Community route takes an ID or a <span className="nw">URL-encoded</span> `x.com/i/communities` link. So does the `communityId` search filter
- Changes to Xquik resources get <span className="nw">6,000 requests</span> per minute, `DELETE` included. X (Twitter) actions through a connected account keep <span className="nw">120 per</span> minute. A <span className="nw">`429` message</span> names the limit and the wait
- Extraction jobs take up to <span className="nw">10,000 items</span> per target list. That covers usernames, search queries, Community IDs, List IDs & profile relations
- `POST /x/communities` answers <span className="cn"><span className="nw">`422 x_`</span><wbr />`community_`<wbr />`creation_`<wbr />`closed`</span> and charges nothing. X stopped accepting new Communities in April 2026
- An MCP answer over <span className="nw">24,000 characters</span> now stays valid JSON. It keeps whole items from the start. Each cut says `--- TRUNCATED ---`. `truncated` holds the full size, `next`, `result_id` & a CSV `download_url`
- The `execute` tool states what <span className="nw">1,000 credits</span> cost in dollars
- The `execute` tool says its <span className="nw">55 seconds</span> include waits. It also says how long a post can take. A script past the limit with no request running gets a refusal. The refusal names its last successful request
- Hidden likers answer <span className="cn"><span className="nw">`424 favoriters_`</span><wbr />`unavailable`</span>. The message names the post's retweeters path

**New**

- `GET /x/tweets/search` takes `topic` & keeps only posts about it, such as <span className="cn">`the Rust programming language`</span>. Each kept post carries its `topicScore`, & `topicFilter` states the <span className="nw">0.5 cutoff</span>. Each kept post costs <span className="nw">2 credits</span>. MCP's `searchTweets` takes it too
- <span className="cn">`POST /x/users/{id}/block`</span> blocks a user from a connected X account, & `DELETE` unblocks. <span className="cn">`POST /x/users/{id}/mute`</span> mutes, & `DELETE` unmutes. Each call costs <span className="nw">10 credits</span>
- <span className="cn">`POST /x/tweets/`<wbr />`{id}/`<wbr />`bookmark`</span> bookmarks a post from a connected X account, & `DELETE` removes the bookmark. Each call costs <span className="nw">10 credits</span> like other writes, & MCP clients get both through `execute`
- <span className="cn">`POST /x/media/download`</span> takes `imageShows` & saves only posts whose photos show it. Each saved post costs <span className="nw">2 credits</span>, on top of the save price
- `POST /extractions` takes `topic` or `imageShows` on tools that return posts. It stores only the posts that match. Each stored post costs <span className="nw">2 credits</span> instead of its read price. A dropped post costs nothing. The job's `topicFilter` or `imageFilter` states the cutoff & counts
- <span className="cn">`GET /x/users/{id}/tweets`</span>, `/replies` & `/media` take `imageShows` & keep only posts whose photos show it. Send `charts`, `screenshots`, `product_photos`, `memes`, `people` or your own words. They take `topic` too, & search takes `imageShows`. Each kept post costs <span className="nw">2 credits</span>
- AI analysis now reads each post's images with its text, at no extra cost
- Send <span className="cn">`analysis.images: false`</span> to analyze the text alone. Images of posts X marks sensitive stay unread
- <span className="cn">`contextAvailability.`<wbr />`media`</span> is `images` when the AI read a post's images. An <span className="nw">image-only</span> post now gets answers
- <span className="cn">`GET /x/users/`<wbr />`{id}/`<wbr />`shadowban`</span> checks <span className="nw">1 X</span> account. It looks for a search ban, a search suggestion ban & reply deboosting. It also says if the account is active, protected or suspended
- Each check answers `pass`, `fail` or `unknown` with its reason. It also names the posts, suggestions or replies it read. It costs <span className="nw">1 credit</span> per profile, post, suggestion & reply in the answer. Guest keys can call it
- Sentiment analysis adds `emotion`, the main emotion of each post, at the same price. It answers `joy`, `anger`, `sadness`, `fear`, `surprise`, `disgust` or `none`
- `GET /radar` search trend items add `volumes`. It lists each search volume change with its time
- Each search trend news story adds its `imageUrl` & `publishedAt` when the story has them
