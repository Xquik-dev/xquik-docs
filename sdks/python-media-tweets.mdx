## Workflow to post media tweets and DM attachments

Use this workflow to post a media tweet or reply. Use it too to DM 1 uploaded media item.

{"\n"}

Tweet and reply media posts use public media URLs directly on `client.x.`<span className="cn"><wbr />`tweets.`<wbr />`create`</span>. Send up to 4 image URLs or exactly 1 MP4 video URL. The video can be up to 100 MB. Do not mix video with other media. Do not upload first when the media URL is already public.

```python
import json
import sys
from typing import Any

from x_twitter_scraper import XTwitterScraper

client = XTwitterScraper()

def create_tweet_handoff(
    action: dict[str, Any],
    base: dict[str, Any],
) -> dict[str, Any]:
    result = action.get("result") or {}
    return {
        "status": action["status"],
        "terminal": action["terminal"],
        "safe_to_retry": action["safeToRetry"],
        "write_action_id": action["id"],
        "request_hash": action["request"]["hash"],
        "tweet_id": result.get("id") or action.get("tweetId"),
        "charged": action["billing"]["charged"],
        "charged_credits": action["billing"]["chargedCredits"],
        "poll": None if action["terminal"] else action["statusUrl"],
        **base,
    }
```

Use `with_raw_`<span className="cn"><wbr />`response.`<wbr />`create`</span> to capture the durable write action. Send a unique `Idempotency-Key`. Store `id`, `request.hash`, `billing`, `result`, and `statusUrl`. Poll while `terminal` is false. Retry only when `safeToRetry` is true, using a new key.

```python
response = client.x.tweets.with_raw_response.create(
    account="@username",
    text="New demo video is live.",
    media=["https://example.com/product-demo.mp4"],
)
payload = response.json()

tweet_handoff = create_tweet_handoff(
    payload,
    {
        "account": "@username",
        "media": ["https://example.com/product-demo.mp4"],
    },
)

sys.stdout.write(json.dumps(tweet_handoff, ensure_ascii=False) + "\n")
```

To post an image reply, add `reply_to_tweet_id`.

```python
response = client.x.tweets.with_raw_response.create(
    account="@username",
    text="Here is the requested screenshot.",
    reply_to_tweet_id="1893704267862470862",
    media=["https://example.com/export-preview.png"],
)
payload = response.json()

reply_handoff = create_tweet_handoff(
    payload,
    {
        "account": "@username",
        "reply_to_tweet_id": "1893704267862470862",
        "media": ["https://example.com/export-preview.png"],
    },
)

sys.stdout.write(json.dumps(reply_handoff, ensure_ascii=False) + "\n")
```

For DM attachments, upload the local file first. Then pass the returned `media.media_id` as the only `media_ids` item.

```python
import json
import sys
from pathlib import Path

media = client.x.media.upload(
    account="@username",
    file=Path("./handoff.png"),
)

dm = client.x.dm.send(
    user_id="44196397",
    account="@username",
    text="Here is the asset.",
    media_ids=[media.media_id],
)

dm_handoff = {
    "status": "sent",
    "message_id": dm.message_id,
    "media_id": media.media_id,
    "account": "@username",
    "user_id": "44196397",
}

sys.stdout.write(json.dumps(dm_handoff, ensure_ascii=False) + "\n")
```

`client.x.`<span className="cn"><wbr />`tweets.`<wbr />`create`</span> returns `tweet.tweet_id` for confirmed posts. Raw create responses can also include the pending write fields above while confirmation runs. `client.x.`<span className="cn"><wbr />`media.`<wbr />`upload`</span> returns `media.media_id` for DM attachments. `client.x.dm.send` returns `dm.message_id` for support tickets, CRM records, queue jobs, or agent memory.

{"\n"}

Keep DM body text in private systems. Shared logs, public artifacts, queue status, and agent handoffs should omit full DM bodies. They should store `message_id`, optional `media_id`, `account`, `user_id`, and send status. Leave `reply_to_message_id` unset even if generated SDK types expose it. The REST endpoint rejects DM reply threading.

{"\n"}

`client.x.dm.`<span className="cn"><wbr />`delete_`<wbr />`message`</span> [deletes a DM](/api-reference/x-write/delete-dm).

{"\n"}

Text-only tweet and reply writes cost 30 credits. Tweet media adds 2 credits per started MB across attached files. Uploading media costs 10 credits. Sending the DM costs 10 credits. Do not pass uploaded `media.media_id` values to `client.x.`<span className="cn"><wbr />`tweets.`<wbr />`create`</span>. That method uses `media` with public media URLs.
