## Basic example

Search tweets and write durable JSON Lines handoff rows.

```php
<?php

use XTwitterScraper\Client;

$client = new Client(
  apiKey: getenv('X_TWITTER_SCRAPER_API_KEY') ?: 'xq_YOUR_KEY_HERE'
);

$page = $client->x->tweets->search(
  q: 'from:username webhook OR SDK',
  limit: 10,
);

foreach ($page->tweets as $tweet) {
  $row = [
    'tweet_id' => $tweet->id,
    'text' => $tweet->text,
    'author_username' => $tweet->author?->username,
    'created_at' => $tweet->createdAt,
  ];

  echo json_encode($row, JSON_THROW_ON_ERROR) . PHP_EOL;
}
```

## Tweet replies workflow to CSV, JSON, or XLSX

Use this workflow when a PHP worker needs every reply on a public tweet. The worker needs them in a durable file. The file can feed moderation review or customer support triage. It can also feed an analyst export or a warehouse loader.

{"\n"}

`$client->`<span className="cn"><wbr /><span className="nw">`extractions->`</span><wbr />`estimateCost()`</span> and `$client->`<span className="cn"><wbr /><span className="nw">`extractions->`</span><wbr />`run()`</span> map to the extraction workflow. For tweet replies, use `ToolType::`<span className="cn"><wbr />`REPLY_`<wbr />`EXTRACTOR`</span>. `reply_extractor` requires `targetTweetID`. `$client->`<span className="cn"><wbr /><span className="nw">`extractions->`</span><wbr />`retrieve()`</span> returns `results`, `hasMore`, and `nextCursor` for pagination. `$client->`<span className="cn"><wbr /><span className="nw">`extractions->`</span><wbr />`exportResults()`</span> returns the completed job as a string. It supports `CSV`, `JSON`, and `XLSX` export formats.

{"\n"}

Reuse the polling, JSON Lines pagination, and export structure from the follower workflow. Only the tool type, target field, and filenames change.

```php
$targetTweetID = '1893704267862470862';
$estimate = $client->extractions->estimateCost(
  toolType: EstimateToolType::REPLY_EXTRACTOR,
  targetTweetID: $targetTweetID,
);

if (!$estimate->allowed) {
  throw new RuntimeException('Insufficient credits for reply extraction.');
}

$job = $client->extractions->run(
  toolType: RunToolType::REPLY_EXTRACTOR,
  targetTweetID: $targetTweetID,
);

// Run the same polling loop and JSONL pagination loop from the follower workflow.
// Set the JSON Lines destination to fopen('xquik-replies.jsonl', 'wb').

file_put_contents(
  'xquik-replies.csv',
  $client->extractions->exportResults($job->id, format: ExportFormat::CSV),
);
file_put_contents(
  'xquik-replies.json',
  $client->extractions->exportResults($job->id, format: ExportFormat::JSON),
);
file_put_contents(
  'xquik-replies.xlsx',
  $client->extractions->exportResults($job->id, format: ExportFormat::XLSX),
);
```

The cost is 1 credit per reply extracted or returned. Store `$job->id` on the queue job, ticket, or warehouse batch before polling. With that ID, another worker can resume by calling `$client->`<span className="cn"><wbr /><span className="nw">`extractions->`</span><wbr />`retrieve()`</span>. Keep `$page->nextCursor` as the checkpoint. Pass it back as `cursor` when you stream replies to JSON Lines. Use `xquik-replies.jsonl` for queue replay or warehouse loads, and `xquik-replies.json` for app ingestion. Use `xquik-replies.csv` for CRM import and `xquik-replies.xlsx` for analyst handoff.

## Error handling

The SDK throws subclasses of `XTwitterScraper\`<span className="cn"><wbr />`Core\`<wbr />`Exceptions\`<wbr />`APIException`</span>.

| Response                                          | Exception                      |
| ------------------------------------------------- | ------------------------------ |
| <span className="nw">400 Bad</span> request       | `BadRequestException`          |
| <span className="nw">401 Unauthorized</span>      | `AuthenticationException`      |
| <span className="nw">403 Permission</span> denied | `PermissionDeniedException`    |
| <span className="nw">404 Not</span> found         | `NotFoundException`            |
| <span className="nw">422 Validation</span> error  | `UnprocessableEntityException` |
| <span className="nw">429 Rate</span> limited      | `RateLimitException`           |
| 5xx server error                                  | `InternalServerException`      |

```php
<?php

use XTwitterScraper\Core\Exceptions\APIConnectionException;
use XTwitterScraper\Core\Exceptions\APIStatusException;

try {
  $account = $client->account->retrieve();
} catch (APIConnectionException $e) {
  fwrite(STDERR, "Connection failed\n");
} catch (APIStatusException $e) {
  fwrite(STDERR, $e->getMessage() . PHP_EOL);
}
```

## Pagination

Paginated responses expose fields such as `hasNextPage`. Pass the endpoint's cursor fields when requesting more pages.

```php
<?php

$page = $client->x->tweets->search(q: 'xquik', limit: 20);

if ($page->hasNextPage) {
  fwrite(STDERR, "More results are available\n");
}
```
