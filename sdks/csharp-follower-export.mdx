## Follower export workflow to CSV, JSON, or XLSX

This workflow is for a .NET worker, console job, or ASP.NET background service. Use it when that code needs an owned follower list. It feeds CRM imports, warehouse loads, analyst CSVs, XLSX workbooks, or resumable JSON handoffs.

{"\n"}

`client.`<span className="cn"><wbr />`Extractions.`<wbr />`EstimateCost`</span> and `client.`<span className="cn"><wbr />`Extractions.Run`</span> map to the extraction workflow. For follower exports, set `ToolType` to `FollowerExplorer` in both calls, as the code below does. `follower_explorer` requires `TargetUsername`. `client.`<span className="cn"><wbr />`Extractions.`<wbr />`Retrieve`</span> returns `Results`, `HasMore`, and `NextCursor` for pagination. `client.`<span className="cn"><wbr />`Extractions.`<wbr />`ExportResults`</span> returns an `HttpResponse`. Read CSV and JSON as strings, and copy XLSX from the response stream.

<Info>

`client.`<span className="cn"><wbr />`Extractions.Run`</span> returns the queued `202 Accepted` receipt from `POST /extractions`. C# exposes REST `id`, `toolType`, and `status: "running"` as `job.ID`, `job.ToolType`, and `job.Status`. Store `job.ID` immediately, then poll `client.`<span className="cn"><wbr />`Extractions.`<wbr />`Retrieve`</span> before reading pages or calling `client.`<span className="cn"><wbr />`Extractions.`<wbr />`ExportResults`</span>. Credit reservation happens after the job starts. Available credits can change after `EstimateCost`. If they did, the run can fetch only the affordable count before export. In that case it can instead mark the job `failed` with `insufficient_credits`.

</Info>

```csharp
using System;
using System.IO;
using System.Text.Json;
using System.Threading.Tasks;
using XTwitterScraper;
using XTwitterScraper.Core;
using XTwitterScraper.Models.Extractions;

XTwitterScraperClient client = new();

string targetUsername = "username";
ExtractionEstimateCostResponse estimate = await client.Extractions.EstimateCost(
    new ExtractionEstimateCostParams
    {
        ToolType = ExtractionEstimateCostParamsToolType.FollowerExplorer,
        TargetUsername = targetUsername,
    }
);

if (!estimate.Allowed)
{
    throw new InvalidOperationException("Insufficient credits for follower export.");
}

ExtractionRunResponse job = await client.Extractions.Run(
    new ExtractionRunParams
    {
        ToolType = ExtractionRunParamsToolType.FollowerExplorer,
        TargetUsername = targetUsername,
    }
);

while (true)
{
    ExtractionRetrieveResponse statusPage = await client.Extractions.Retrieve(
        job.ID,
        new ExtractionRetrieveParams { Limit = 1 }
    );

    string? status = statusPage.Job.TryGetValue("status", out JsonElement statusValue)
        ? statusValue.GetString()
        : null;

    if (status == "completed")
    {
        break;
    }

    if (status == "failed")
    {
        throw new InvalidOperationException("Follower export failed.");
    }

    await Task.Delay(TimeSpan.FromSeconds(10));
}

string? cursor = null;
using StreamWriter writer = File.CreateText("xquik-followers.jsonl");

do
{
    ExtractionRetrieveResponse page = await client.Extractions.Retrieve(
        job.ID,
        new ExtractionRetrieveParams { Cursor = cursor, Limit = 1000 }
    );

    foreach (var follower in page.Results)
    {
        await writer.WriteLineAsync(JsonSerializer.Serialize(follower));
    }

    cursor = page.HasMore ? page.NextCursor : null;
} while (!string.IsNullOrEmpty(cursor));

using HttpResponse csvResponse = await client.Extractions.ExportResults(
    job.ID,
    new ExtractionExportResultsParams { Format = Format.Csv }
);
await File.WriteAllTextAsync("xquik-followers.csv", await csvResponse.ReadAsString());

using HttpResponse jsonResponse = await client.Extractions.ExportResults(
    job.ID,
    new ExtractionExportResultsParams { Format = Format.Json }
);
await File.WriteAllTextAsync("xquik-followers.json", await jsonResponse.ReadAsString());

using HttpResponse xlsxResponse = await client.Extractions.ExportResults(
    job.ID,
    new ExtractionExportResultsParams { Format = Format.Xlsx }
);
using Stream xlsxStream = await xlsxResponse.ReadAsStream();
using FileStream xlsxFile = File.Create("xquik-followers.xlsx");
await xlsxStream.CopyToAsync(xlsxFile);
```

The cost is 1 credit per follower extracted or returned. Store `job.ID`, `targetUsername`, `estimate.`<span className="cn"><wbr />`EstimatedResults`</span>, and `estimate.Source` before polling. With them, a queue retry can resume the same follower export. So can a Windows service restart or worker restart. Keep `page.NextCursor` as the checkpoint when you stream followers to JSON Lines. Map exported `User ID` or row `xUserId` as the CRM unique key. Use `xquik-followers.`<span className="cn"><wbr />`jsonl`</span> for queue replay or warehouse loads and `xquik-followers.json` for app ingestion. Use `xquik-followers.csv` for CRM import and `xquik-followers.xlsx` for analyst handoff. Exports are free after the extraction job exists.
