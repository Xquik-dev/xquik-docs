The Xquik ChatGPT app reads public X data in a ChatGPT chat. It lists 8 read
tools from the [API MCP server](/mcp/overview). Each result uses your Xquik
credits.

## Connect Xquik

1. In ChatGPT on the web, open **Settings > Security and login**. Turn on **Developer mode**.
2. Open [chatgpt.com/plugins](https://chatgpt.com/plugins) and select **+**.
3. Enter `https://xquik.com/mcp?app=chatgpt`, then select **Create**.
4. Sign in to Xquik and approve access.
5. In a new chat, select **+ > More**, then select Xquik. Ask in plain words, such as "Find popular posts about the Artemis launch."

Developer mode works on the web for Plus, Pro, Business, Enterprise and Edu
plans. Workspace admins can turn it off. Link Xquik on the web first, then use
it on mobile. For posting, monitors and every other operation, enter
`https://xquik.com/mcp` instead.

ChatGPT uses Xquik OAuth and cannot present a custom API key. If ChatGPT's
labels change, follow [OpenAI's setup guide](https://developers.openai.com/plugins/deploy/connect-chatgpt).

## Tools

| Tool              | What it does                              |
| ----------------- | ----------------------------------------- |
| `searchTweets`    | Searches posts with X search filters      |
| `lookupTweet`     | Reads 1 post and its author               |
| `getTweetReplies` | Lists replies to a post                   |
| `getTweetThread`  | Reads a conversation thread               |
| `getUser`         | Looks up a profile by username, ID or URL |
| `searchUsers`     | Finds accounts by name or username        |
| `getUserTweets`   | Reads recent posts from 1 account         |
| `getXTrends`      | Gets trending topics for a region         |

The tools only read. None of them posts, follows or changes your account.

## Results

- **Posts** keep `id`, `url`, `text`, `created`, `lang`, `in_reply_to_username`, the like, repost, reply, quote, view and bookmark counts, `possibly_sensitive`, `media`, `author`, `quoted_tweet` and `retweeted_tweet`.
- **Authors in posts** keep `username`, `name`, `verified` and `followers`.
- **Profiles** keep `id`, `username`, `name`, `description`, `followers`, `following`, `verified`, `is_blue_verified`, `verified_type`, `location`, `url`, `created`, `statuses_count`, `profile_picture` and `protected`.
- **Media** keeps `type`, `media_url` and `expanded_url`.

A page holds up to 20 rows. Ask for more, and ChatGPT reads the next page with
`next_cursor`. The [REST API](/api-reference/overview) returns complete records.

## Credits

Results cost the prices in [Billing](/guides/billing). When your balance can't
cover a request, the app answers "Your Xquik credits can't cover this request."
with a link to plans. Add credits in your Xquik dashboard, then ask again.

## Troubleshooting

- **Sign-in fails.** Remove the app, add it again, then sign in.
- **A tool is missing.** Open the app in [chatgpt.com/plugins](https://chatgpt.com/plugins) and select **Refresh**.
- **ChatGPT reports invalid tool input.** Ask for 20 or fewer results at a time.
